# content-hub

เนื้อหา (หนังสือ บทสรุป ข้อสอบ) ของแอป **KnowledgeQuizApp** — ไฟล์ทั้งหมดเข้ารหัส AES แอปดาวน์โหลดไปถอดรหัสในเครื่อง

- `manifest.json` — รายการไฟล์ + เวอร์ชัน (แอปอ่านไฟล์นี้ก่อน)
- `x/` บทเรียน · `e/` ข้อสอบ · `p/` ตำแหน่งงาน · `book/` PDF · `image/` รูป

📘 **วิธีเพิ่มเนื้อหาและข้อสอบ: [GUIDE.md](GUIDE.md)**
