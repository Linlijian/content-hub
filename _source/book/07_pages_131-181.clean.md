# บทที่ 5 ฮาร์ดแวร์ (Hardware)

ฮาร์ดแวร์ (Hardware)
หมายถึง ส่วนกายภาพของเครื่องคอมพิวเตอร์ (Device)
ทุกๆ ส่วน ที่ทำงานแบบผสมผสานและพึ่งพาซึ่งกันและกัน ตัวอย่าง
ของฮาร์ดแวร์ได้แก่ เครื่องมือ เครื่องจักร ชิ้นส่วน และอุปกรณ์ต่อพ่วง
ต่างๆ ที่สามารถมองเห็น และจับต้องได้ เช่น ซีพียู แรม จอภาพ
ฮาร์ดดิสก์ ชิปเซ็ต เมนบอร์ด รวมถึงพอร์ตและสายต่อเชื่อมสัญญาณ
ประเภทต่างๆ ด้วย
สามารถแบ่งออกเป็นส่วนต่าง ๆ ตามลักษณะการทำงานได้ 5 หน่วย โดยอุปกรณ์แต่ละหน่วยมีหน้าที่
การทำงานแตกต่างกัน

1\. หน่วยรับข้อมูล Input Unit

2\. หน่วยประมวลผลกลาง CPU : Central Processing Unit

3\. หน่วยความจำหลัก Main Memory Unit

4\. หน่วยเก็บข้อมูลสำรอง Secondary Storage Unit

5\. หน่วยแสดงผล Output Unit
ฮาร์ดแวร์ไม่สามารถทำงานได้ด้วยตัวเองเพราะต้องอาศัยซอฟต์แวร์ (Software) ในการสั่งงาน โดย
อาจอาศัยชุดคำสั่งใน ROM ของฮาร์ดแวร์นั้นๆ เอง หรือคำสั่งจากระบบปฏิบัติการ คำสั่งจากโปรแกรม
ขับเคลื่อน (Driver) หรือชุดคำสั่งจากโปรแกรมประยุกต์ (Application) ก็ได้
เมื่อทราบภาพรวมของฮาร์ดแวร์แล้ว ไปเจาะลึกฮาร์ดแวร์ทั้ง 5 หน่วยนี้กับครูผู้ช่วยวันธรรมดา ชาวนา
วันหยุดครับ

1\. หน่วยรับข้อมูล (Input Unit)
หน่วยรับข้อมูล คือ อุปกรณ์ที่จะช่วยป้อนคำสั่งและข้อมูลต่างๆ เข้าสู่คอมพิวเตอร์เพื่อให้คอมพิวเตอร์
นำไปประมวลผลแล้วนำมาจัดเก็บไว้ที่หน่วยความจำหลักหรือหน่วยความจำสำรอง โดยข้อมูลอาจเป็นตัวเลข
ภาพ เสียง หรือวีดีโอ เป็นต้น โดยจะแปลงข้อมูลให้อยู่ในรูปของสัญญาณไฟฟ้าที่คอมพิวเตอร์สามารถเข้าใจได้
และใช้ประมวลผลได้ อุปกรณ์หน่วยรับข้อมูลที่นิยมใช้ในปัจจุบันมีหลากหลายประเภท ซึ่งจำแนกได้โดยสังเขป
ดังนี้

### 1.1 หน่วยวัดประสิทธิภาพของอุปกรณ์ Input ที่สำคัญ มีดังนี้

1\. เมาส์ - DPI
DPI หรือ Dots Per Inch คือ มาตรฐานในการวัด
ความไวในการเคลื่อนไหวของเมาส์ โดยมีหน่วยในการวัดเป็น
จุดต่อนิ้วเชิงเส้น ซึ่งหมายความว่า ยิ่งจำนวนค่าของ DPI มาก
เท่าไหร่ ความไวในการเคลื่อนไหวของเมาส์ก็จะมากตามไป DPI (dot per inch)
https://th.garynevillegasm.com
ด้วย DPI ยังเป็นหน่วยวัดความละเอียดของ Printer อีกด้วย

2\. หน้าจอสัมผัส
มีวิธีการนำเข้าข้อมูล 2 แบบ คือ

1\. หน้าจอแบบ Resistive ใช้อะไรสัมผัสก็ได้
ความแตกต่างระหว่าง Capacitive กับ Resistive
ภาพจาก https://www.electronicproducts.com/resistive-vs-capacitive-touchscreens/

2\. หน้าจอแบบ Capacitive ใช้มือหรือปากกา Stylus ในการสัมผัส ประสิทธิภาพ
ดีกว่าแบบ Resistive นิยมใช้ในอุปกรณ์พกพาต่างๆ เช่น สมาร์ทโฟน และ แท็ปเล็ต
เป็นต้น

3\. สแกนเนอร์ - PPM และ IPM เป็นหน่วยในการวัดความเร็วของเครื่องสแกน
PPM: Page per minute หรือ หน้าต่อนาที หรืออาจใช้
IPM: Image per minute หรือ ภาพต่อนาที

4\. กล้องเว็บแคม กล้องดิจิทัล – Pixel
Pixel เป็นคำที่มีที่มาจากคำว่า “Picture” ที่แปลว่ารูปภาพ และ
“Element” ที่แปลว่า องค์ประกอบ ในการแสดงผลบนหน้าจอ Pixel ที่มี
ลักษณะเป็นรูปสี่เหลี่ยมจำนวนมากจะเรียงต่อกันเป็นตาราง โดย Pixel
แต่ละจุดก็จะมีค่าสีที่แตกต่างกันออกไป เนื่องจาก Pixel นั้นมีขนาดที่เล็ก
มาก สายตาของเราจึงแยกมันไม่ออกว่ามันเป็นก้อนสี่เหลี่ยมเรียงชิดติดกัน
เห็นแค่เพียงภาพบนหน้าจอที่สวยงาม ในการแสดงผล ยิ่งมีจำนวน Pixel
สูงมากเท่าไหร่ ความคมชัดของภาพก็จะยิ่งสูงขึ้นเท่านั้น
Pixel
ภาพจาก https://www.bigstockphoto.com/

2\. หน่วยประมวลผลกลาง CPU : Central Processing Unit
CPU คือหน่วยประมวลผลกลางของคอมพิวเตอร์
ทำหน้าที่ประมวลผลข้อมูลเชิงตรรกะและควบคุมอุปกรณ์
ภายในเครื่องทั้งหมด โดยมีกระบวนการพื้นฐานคือ อ่าน
ชุดคำสั่ง (Fetch) ตีความชุดคำสั่ง (Decode) ประมวลผล
ชุดคำสั่ง (Execute) และเขียนข้อมูล/ส่งผลการประมวล
กลับ (Store) ยุคปัจจุบัน CPU จะผลิตออกมาเป็นชิปวงจร
รวม หรือที่เรียกว่า ไมโครโพรเซสเซอร์ (Microprocessor)
CPU เปรียบเหมือนสมองที่คอยทำ
หน้าที่ในการตัดสินใจหรือคำนวณข้อมูลคำสั่ง
ที่ได้รับมา และเป็นหัวใจหลักในการ
ประมวลผล
CPU มีตัวเลขที่บ่งบอกประสิทธิภาพ
อยู่ 4 ค่าหลักๆ คือ Core, Thread, Speed
Clock และ Cache

1\. Core คือ หน่วยประมวลผลอิสระ หรือ “สมอง” ที่ทำหน้าที่อ่านและประมวลผลคำสั่ง
จำนวนคอร์ส่งผลโดยตรงต่อความสามารถในการทำงานหลายงานพร้อมกัน (Multitasking) และการ
รันโปรแกรมที่รองรับการประมวลผลแบบขนาน (Parallel Processing) ทำให้ยิ่งมีจำนวนคอร์มาก
CPU ก็ยิ่งสามารถจัดการกับหลายแอปพลิเคชันหรือกระบวนการที่ซับซ้อนได้ดีขึ้น เช่น การเรนเดอร์
วิดีโอ การจำลองทางวิทยาศาสตร์ หรือการเปิดเบราว์เซอร์พร้อมกันหลายสิบแท็บ
แตใ่ นปัจจุบัน ผู้ผลิตชั้นนำอย่าง Intel และ AMD ไม่ได้จำกัดอยู่แค่การใช้คอร์ประเภทเดียว
อีกต่อไป แต่ได้พัฒนารูปแบบคอร์ที่หลากหลาย (Heterogeneous Architecture) เพื่อเพิ่ม
ประสิทธิภาพสูงสุดต่อการใช้พลังงาน ซึ่งอธิบายได้ดังต่อไปนี้

1\. Intel สถาปัตยกรรมประสิทธิภาพแบบไฮบริด (P-Core และ E-Core)
Intel นำเสนอสถาปัตยกรรมแบบไฮบริด (Hybrid Architecture) ตั้งแต่ Core รุ่นที่ 12 เป็น
ต้นมา โดยแบ่งคอร์ออกเป็นสองประเภทที่ทำงานร่วมกัน ได้แก่

### 1.1 P-Core (Performance-core) คอร์ประสิทธิภาพสูง คอร์เหล่านี้ถูกออกแบบมาเพื่อ

ความเร็วสัญญาณนาฬิกา (Clock Speed) สูงสุด และรองรับ Hyper-Threading โดยเฉพาะสำหรับ
งานที่ต้องการพลังการประมวลผลเดี่ยวมากที่สุด (Single-Thread) เช่น การเล่นเกม หรือการ
ประมวลผลหลักของโปรแกรมหนักๆ เช่น การเรนเดอร์ภาพ และการเข้ารหัสวีดีโอ เป็นต้น
1.2 E-Core (Efficient-core) คอร์ประหยัดพลังงาน คอร์เหล่านี้มีขนาดเล็กกว่า ใช้พลังงาน
น้อยกว่า และมักไม่รองรับ Hyper-Threading
ถูกออกแบบมาเพื่อจัดการกับงานที่ทำงานอยู่
เบื้องหลัง (Background Tasks) และงานที่
ต้องการการประมวลผลหลายเธรด (Multi-
Thread) ระดับปานกลาง การแยกงานไปให้ E-
Core ช่วยให้ P-Core ว่างและพร้อมสำหรับ
งานหนักที่ผู้ใช้กำลังใช้งานอยู่จริง งานที่ทำเช่น
งานจัดการซิงค์ข้อมูล การฟังเพลง อัปเดตระบบ
สแกนไวรัสเบื้องหลัง เป็นต้น

2. AMD การเพิ่มประสิทธิภาพผ่านสถาปัตยกรรมคอร์และแคช
AMD ยังคงใช้แนวคิดคอร์หลัก (Homogeneous Cores) ที่มีสถาปัตยกรรม Zen เดียวกัน
ในชิป Ryzen ส่วนใหญ่ แต่ได้มีการเสริมเทคโนโลยีเฉพาะทางเพื่อเพิ่มประสิทธิภาพ ได้แก่
Zen Core (R3, R5, R7, R9) คอร์ทั้งหมดเป็นคอร์ประสิทธิภาพสูงที่เน้นความสมดุลระหว่าง
Single-Thread และ Multi-Thread
3D V-Cache เป็นเทคโนโลยีเฉพาะที่เพิ่ม L3 Cache ขนาดใหญ่พิเศษซ้อนทับบนคอร์หลัก
เพื่อเพิ่มความเร็วในการเข้าถึงข้อมูลอย่างมหาศาล ซึ่งมีประสิทธิภาพสูงเป็นพิเศษในงานที่ต้องการ
ความหน่วงต่ำ เช่น การเล่นเกม

3. AI Core (NPU) หน่วยประมวลผลเอไอ ใน Intel Core Ultra และ AMD Ryzen AI
นอกจาก P-Core และ E-Core แล้ว CPU รุ่นใหม่ในโน้ตบุ๊กประสิทธิภาพสูงได้เพิ่ม AI Core
หรือที่เรียกว่า NPU (Neural Processing Unit) เข้ามาเป็นองค์ประกอบที่สามของชิปประมวลผล
เพื่อเร่งการประมวลผลงานของ ปัญญาประดิษฐ์ (AI) และ Machine Learning โดยการใช้งานทั่วไป
ได้แก่ การเบลอพื้นหลังวิดีโอ (Video Background Blur) การปรับปรุงคุณภาพเสียง (Noise
Cancellation) หรือฟีเจอร์ AI ของระบบปฏิบัติการ ข้อได้เปรียบของการใช้ NPU ในการประมวลผล

งาน AI คือทำให้ประหยัดพลังงานได้อย่างมาก เมื่อเทียบกับการใช้ CPU หรือ GPU หลักในการ
คำนวณแบบเดียวกัน

2. Thread เปรียบเหมือนการจำลองคอร์ของ CPU ให้เพิ่มขึ้น อย่างเช่น AMD Ryzen 9
9900X เป็นซีพียู 12 คอร์ ที่มี 24 เทรด หมายความว่าแม้ CPU จะมีสมอง 12 ก้อน แต่เหมือนจำลอง

คอร์เดียวสามารถจัดการกับ 2 เธรด พร้อมกันได้

3. Clock Speed คือ ความถี่ในการทำงานของ CPU หน่วยเป็นกิกะเฮิรตซ์ (GHz) บ่งบอกถึง
จำนวนรอบการทำงานพื้นฐานที่ CPU สามารถทำได้ใน 1 วินาที (1 GHz = 1 พันล้านรอบต่อวินาที)
ความเร็วนาฬิกาส่งผลโดยตรงต่อประสิทธิภาพงานเดี่ยว (Single-Core Performance) ยิ่งความเร็ว
Clock Speed สูง CPU ก็ยิ่งทำงานพื้นฐานแต่ละอย่างได้เร็วขึ้น

4. ความจุของ Cache คือ หน่วยความจำความเร็วสูงมากที่อยู่ภายในตัว CPU มีหลายระดับ
(L1, L2 และ L3 หรือ L4) ทำหน้าที่เก็บข้อมูลและคำสั่งที่ถูกใช้งานบ่อยที่สุด ทำให้สามารถลดเวลา
แฝง (Latency) ในการเข้าถึงข้อมูลได้ ทำให้การประมวลผลโดยรวมรวดเร็วขึ้นอย่างเห็นได้ชัด
CPU ที่เราใช้กันอยู่ในปัจจุบัน เมื่ออ่านคุณสมบัติก่อนซื้อจะพบตัวเลข 6/12 หรือ 12/24

### 2.1 สถาปัตยกรรมของซีพียู (CPU Architecture)

สถาปัตยกรรม (Architecture) หมายถึง การออกแบบในส่วนต่างๆ ที่สำคัญของซีพียู ไม่ว่าจะเป็น
โครงสร้าง จำนวน Register หน้าที่ที่จำเป็นของ Control Unit และ Arithmetic Unit การออกแบบ
สถาปัตยกรรมของซีพียู แบ่งออกเป็น 2 แบบ คือ

1. CISC ย่อมาจาก Complex Instruction Set Computer คือ CPU ที่มีชุดคำสั่งซับซ้อนและมี
จำนวนมาก 1 คำสั่งสามารถสั่งให้ CPU ทำงานได้หลากหลายรูปแบบ วงจรภายในซับซ้อนมาก อาจทำงาน 1
คำสั่งเสร็จภายใน Cycle เดียว หรืออาจใช้หลาย Cycle ต่อ 1 คำสั่ง ทำให้มีความร้อนและการบริโภคพลังงาน
สูง ตัวอย่าง CPU ที่ใช้สถาปัตยกรรมพื้นฐานแบบ CISC คือ CPU ของ Intel x86/x64 (เช่น Intel Core i5,
Pentium) และ AMD x86-64 (เช่น AMD Ryzen 7) ซึ่งปัจจุบันมีการทำงานแบบ Micro-operations (μOps)
คล้าย RISC ภายใน

2. RISC ย่อมาจาก Reduced Instruction Set Computer เป็น CPU ที่เกิดขึ้นภายหลัง CISC โดย
การออกแบบจะเน้นที่ชุดคำสั่งที่ง่ายและน้อยลง ถูกออกแบบให้ซีพียูทำงานในวงรอบสัญญาณนาฬิกา (Cycle)
ที่แน่นอน คือ 1 Cycle ต่อ 1 คำสั่ง ระบบการทำงานของ RISC จะเน้นความเร็วและความสม่ำเสมอในการ
ประมวลผล โดยผู้สร้างจะป้อนชุดคำสั่งง่าย ๆ หลายชุดเพื่อทำภารกิจที่ซับซ้อน เทียบได้กับการป้อน 1 คำสั่ง
ต่อ 1 งานพื้นฐาน ตัวอย่างของ CPU ประเภท RISC ที่มีชื่อเสียงคือ ตระกูล ARM (เช่น Apple M-series,
Qualcomm Snapdragon, Huawei Kirin และ MediaTek Dimensity) ซึ่งเป็นสถาปัตยกรรมหลักในสมาร์ท
โฟนและแท็บเล็ต

### 2.2 หน่วยย่อยใน CPU

หน่วยย่อยใน CPU ประกอบไปด้วย หน่วยควบคุม (CU: Control Unit) หน่วยคำนวณและตรรกะ
(Arithmetic Logic Unit) และหน่วยความจำหลัก (Memory Unit) ซึ่งได้แก่ Register และ Cache ที่มีไว้เพื่อ
จัดเก็บข้อมูลระหว่างการประมวลผล

1\. หน่วยควบคุม (Control Unit)
หน้าที่ควบคุมลำดับขั้นตอนการประมวลผลและการทำงานของทุกๆ หน่วยในซีพียู รวมถึงอุปกรณ์ต่อ
พ่วง ให้ทำงานประสานกันอย่างมีประสิทธิภาพ

2\. หน่วยคำนวณและตรรกะ (ALU: Arithmetic and Logic Unit)
ทำหน้าที่ในการคำนวณทางคณิตศาสตร์ (arithmetic) เช่น การคูณ ลบ บวก หาร เปรียบเทียบข้อมูล
ทางตรรกศาสตร์ (logical) ว่าเป็นจริงหรือเท็จ อาศัยตัวปฏิบัติการเปรียบเทียบพื้นฐาน 3 ค่า คือ มากกว่า
น้อยกว่าและ เท่ากับ

3\. รีจิสเตอร์ (Register)
เป็นส่วนประกอบหนึ่งของ CPU ทำหน้าที่ในการเก็บพัก
ข้อมูล ชุดคำสั่ง ผลลัพธ์ และข้อมูลที่เกิดขึ้นขณะที่ซีพียูประมวลผล
เพียงชั่วคราว ถือเป็นหน่วยความจำขนายย่อยที่เก็บผลจากการ
คำนวณ โดยแยกพื้นที่ส่วนหนึ่งของหน่วยความจำภายใน CPU มาใช้
นั่นคือ Register เป็นหน่วยความจำส่วนหนึ่งใน CPU รับส่งข้อมูล
ด้วยความเร็วสูงที่สุด และมีขนาดเล็กที่สุดด้วยเช่นกัน
รีจิสเตอร์ที่สำคัญโดยทั่วไป (อาจแตกต่างกันออกไปตามรุ่นของซีพียู) มีดังนี้

1\. Accumulate Register ใช้เก็บผลลัพธ์ที่ได้จากการคำนวณ

2\. Storage Register เก็บข้อมูลและคำสั่งชั่วคราวที่ผ่านจากหน่วยความจำหลัก หรือรอส่งกลับ
ไปที่หน่วยความจำหลัก

3\. Instruction Register ใช้เก็บคำสั่งในการประมวลผล

4\. Address Register บอกตำแหน่งของข้อมูลและคำสั่งในหน่วยความจำ

4. แคช (Cache)
หน่วยความจำแคช (Cache Memory) เป็นหน่วยความจำขนาดเล็กที่อยู่ภายในซีพียู ทำหน้าที่เก็บพัก
ข้อมูลที่จะต้องประมวลผลไว้ล่วงหน้าและเก็บพักข้อมูลที่ประมวลผลแล้วรอการส่งออก ทำให้ซีพียูทำงานเร็ว
ขึ้น โดย L1 และ L2 Cache จะมีอยู่ในแต่ละ Core ของ CPU มีเพียง L3 Cache เท่านั้นที่ไม่ได้อยู่ใน Core

### 2.4 ความเร็วของ CPU

ความเร็วของ CPU วัดตามจำนวน Machine Cycle เช่น เฮิรตซ์ (Hertz: Hz) หมายถึง จำนวน
Machine Cycle ที่ดำเนินการได้ต่อ 1 วินาที (อีกนัยหนึ่งอาจคิดกลับกันได้ว่า ในหนึ่งวินาที CPU ทำงานได้กี่
รอบ) เนื่องจากจำนวนวงรอบที่ดำเนินการได้มีจำนวนมากจึงมักจะใช้หน่วยใหญ่ในการวัด เช่น การดำเนินการ
1 ล้านรอบต่อวินาที นับเป็น 1 เมกะเฮิรตซ์ (Megahertz: MHz) และการดำเนินการ 1 พันล้านรอบต่อวินาที
นับเป็น 1 กิกะเฮิรตซ์ (Gigahertz: GHz)
ซีพียูยุคเก่า การทำคำสั่งแต่ละคำสั่งจะต้องทำวงรอบคำสั่งให้จบก่อน จากนั้นจึงทำวงรอบคำสั่งของ
คำสั่งต่อไป สำหรับซีพียูในยุคปัจจุบันได้มีการพัฒนาให้ทำงานได้เร็วขึ้น โดยมีการแบ่งวงรอบคำสั่งนี้เป็นวงรอบ
ย่อยๆ อีก มีการนำเทคนิคการทำงานแบบสายท่อ (pipeline) มาใช้ โดยขณะที่ทำวงรอบคำสั่งแรกอยู่ ก็มีการ
อ่านรหัสคำสั่งของคำสั่งถัดไปเข้ามาด้วย ซึ่งจะทำให้การทำงานโดยรวมของซีพียูเร็วขึ้นมาก
ปัจจุบัน (2025) ความเร็วของ CPU จะประมวลผลได้สูงสุดได้ในหน่วย GHz (Gigahertz) ยังไม่
สามารถไต่ระดับจนไปถึง THz หรือตอนนี้ยังไปไม่ถึง 50 GHz ด้วยซ้ำ เนื่องจากติดปัญหาด้านเทคโนโลยี และ
ปัญหาหลักอีกด้านหนึ่งคือปัญหา “ความร้อน”

### 2.6 ความแตกต่างของ CPU 64 bit (x64) และ 32 bit (x86)

นับแต่อดีตถึงปัจจุบันปริมาณข้อมูล ที่ใช้ในการประมวลผลต่อ 1 รอบสัญญาณนาฬิกา
(Cycle) มีจำนวนมากขึ้น อย่างไม่มีที่สิ้นสุด จนทำให้มีการเปลี่ยนแปลงสถาปัตยกรรมจาก 16 เป็น
32 bit และ 64 bit ในปัจจุบัน การเปลี่ยนแปลงเหล่านี้ได้สร้างปรากฎการณ์ใหม่ให้กับโลก
คอมพิวเตอร์ได้อย่างมากมาย ในอดีตการประมวลผล 1 รอบ (Cycle) ส่งข้อมูลได้ 16 bit แต่ใน
ปัจจุบันการประมวลผล 1 รอบ (Cycle) ส่งข้อมูลได้ถึง 64 bit
เปรียบเสมือนในการขนส่งผลไม้ เช่น มีผลไม้ 128 กิโลกรัม เรามีรถเล็กๆ คันหนึ่งจะขนผลไม้
ได้ 16 กิโลกรัมต่อเที่ยว ทำให้เราต้องใช้จำนวนเที่ยวในการขนส่งจากปลายทางไปยังต้นทางถึง 8 รอบ
ด้วยเหตุนี้ เราจึงมีการปรับปรุงรถโดยการเพิ่มความกว้างของกระบะ เพิ่มสมรรถนะรถให้สามารถ

บรรทุกได้หนักขึ้น โดยการเพิ่มครั้งนี้ทำให้สามารถขนผลไม้ได้ 32 กิโลกรัม ทำให้ต้องมีการขนส่งถึง 4
เที่ยวถึงจะส่งผลไม้หมด เราคิดว่ามันยังขนส่งช้าอยู่และใช้จำนวนรอบมาก จึงอยากลดต้นทุนและ
อยากขนผลไม้ให้เสร็จไวขึ้น จึงเพิ่มกระบะและเพิ่มสมรรถนะรถอีกจนสามารถขนผลไม้ได้ 64 กิโลกรัม
ทำให้มีการขนส่งผลไม้ 128 กิโลกรัม สามารถทำได้เพียง 2 เที่ยวเท่านั้น เป็นต้น

อุปกรณ์อื่นๆ ต้องปรับเปลี่ยนตามไปด้วย

ถ้าจะเปรียบเทียบกับการขนผลไม้ข้างต้น ในการขนผลไม้จำนวน 64 กิโลกรัมต่อเที่ยว
จำเป็นต้องมีการสร้างหรือขยายถนนให้กว้าง ประตูทางเข้า

การบรรทุกของที่หนักขึ้นถึง 2 เท่า เป็นต้น

386, 486 ซึ่งเป็นพัฒนาการเวอร์ชันต่างๆ ของซีพียูของค่ายอินเทล (Intel) เรียกเป็นรหัสย่อๆ ว่า
x86 ซึ่งความสามารถของตัวเลขนี้จะอยู่ในระดับ 32 bit ดังนั้น x86 ก็คือสถาปัตยกรรม CPU ขนาด
32 bit รองรับแรม (RAM) ได้เพียง 4 GB เท่านั้น
x64 ตัวเลขนี้เป็นตัวเลข ก็คือ 64 bit นั่นเอง ซึ่งเป็นความสามารถในการประมวลผลที่เร็วขึ้น
ของซีพียู กล่าวคือในการทำงาน 1 รอบสัญญาณนาฬิกา สามารถถ่ายโอนข้อมูลได้มากกว่าเดิมถึงสอง
เท่า พร้อมทั้งรองรับแรมได้ถึง 192 GB
เมื่อมีการติดตั้งระบบปฏิบัติการ หรือมีการดาวน์โหลดโปรแกรมไปใช้งาน จะพบตัวเลข x86
กับ x64 อยู่เสมอ

### 2.7 บัส (Bus)

คอมพิวเตอร์มีการประมวลผลและเก็บข้อมูลเป็นชุดของบิต (มีค่า 0 หรือ 1) เมื่อมีการประมวลผล ชุด

เป็นถนนให้บิตวิ่งจากจุดหนึ่งไปยังเป้าหมายได้ เปรียบเทียบได้คือ บิต (รถ) วิ่งไปตามบัส (ถนน) นั่นเอง

- ใช้บรรจุโปรแกรมสำคัญที่ใช้ในการสตาร์ตอัป เครื่อง (Boot เครื่อง)

- เข้าถึงข้อมูลเป็นแบบสุ่ม

### 1.2 ประเภทของรอม

1. ROM: Read Only Memory
เป็นต้นแบบของหน่วยความจำประเภทนี้ มีคุณสมบัติที่อ่านได้อย่างเดียว การเขียนโปรแกรม
เข้าไปในตัวรอมนี้จะต้องทำจากโรงงานที่ผลิตโดยตรง ในอดีตนิยมใช้ทำเป็น BIOS แต่ปัจจุบัน BIOS
ใช้หน่วยความจำแบบ FEPROM (Flash) ที่จะกล่าวในข้อต่อๆไป

2. PROM: Programmable Read Only Memory
เป็นหน่วยความจำที่ถูกพัฒนาขึ้นมาแทน ROM เปิดสิทธิให้แก่ผู้ใช้ ให้ทำการติดตั้งโปรแกรม
หรือเขียนข้อมูลได้ด้วยตนเอง แต่การทำเช่นนี้จะกระทำได้เพียงครั้งเดียวเท่านั้น และจะไม่สามารถลบ
หรือเปลี่ยนแปลงได้อีก

3. EPROM: Erasable Programmable Read Only Memory เป็นหน่วยความจำที่มี
ความสามารถที่ดีกว่า PROM โดยสามารถที่จะโปรแกรมข้อมูลลงไป และเปลี่ยนแปลงหรือลบก็
สามารถทำได้ ด้วยการใช้แสงอัลตราไวโอเลตส่องไปที่กระจกบนตัว EPROM ทำให้ว่างเปล่า จากนั้น

### 2.1 หน้าที่ของแรม

มีหน้าที่หลักในการรับข้อมูลหรือชุดคำสั่งของโปรแกรมเพื่อส่งต่อไปประมวลผลที่
CPU นอกจากนี้แรมยังมีหน้าที่

1. ทำหน้าที่เก็บข้อมูลที่รับเข้ามาจากหน่วยรับข้อมูลเพื่อนำไปประมวลผล

2. ทำหน้าที่เก็บผลลัพธ์ที่ได้ขณะทำการประมวลผลซึ่งยังไม่ใช่ผลลัพธ์สุดท้าย

3. ทำหน้าที่เก็บผลลัพธ์ที่ได้จากการประมวลผลซึ่งเป็นผลลัพธ์สุดท้าย

4. ทำหน้าที่เก็บชุดคำสั่งต่างๆ ขณะที่เรากำลังทำงานอยู่กับเครื่องเพื่อใช้ในการ
ประมวลผล

5. เป็นหน่วยความจำที่เก็บข้อมูลหรือโปรแกรมไว้ชั่วคราว สร้างขึ้นเพื่อผู้ใช้โดยตรง

กับวัตถุประสงค์การใช้งานและลักษณะของอุปกรณ์จัดเก็บข้อมูล จากหัวข้อที่ 3 และ 4 ที่ผ่านมา สามารถ
จำแนกวิธีการเข้าถึงข้อมูลในหน่วยความจำได้ ดังนี้

1. การเข้าถึงแบบเรียงลำดับ (Sequential access) ได้แก่ การค้นหาข้อมูลเรียงลำดับตั้งแต่
จุดเริ่มต้น ไล่ไปจนถึงจุดสิ้นสุด ไม่สามารถข้ามไปยังจุดใดจุดหนึ่งได้ การเข้าถึงข้อมูลลักษณะนี้ ได้แก่ เทป
แม่เหล็ก (นึกถึงภาพ ม้วนเทป หรือ ม้วนวีดีโอสมัยก่อน)

2. การเข้าถึงโดยตรง (Direct access) ได้แก่ การเข้าถึงหน่วยความจำแบบตรง กระบวนการนี้
สามารถข้ามไปยังจุดใดจุดหนึ่งที่ข้อมูลอยู่ได้ เปลี่ยนตำแหน่งสลับไปมาได้ตลอดที่ ได้แก่ ฮาร์ดดิสก์ หรือ แผน
ออปติคอลดิสก์ (แผ่นบลูเรย์ ดีวีดี ซีดี)

3. การเข้าถึงแบบสุ่ม (Random access) ได้แก่ การเข้าถึงหน่วยความจำแบบไม่มีลำดับ ตำแหน่ง
ในหน่วยความจำถูกกำหนดให้ไม่ซ้ำกัน ไม่มีก่อน ไม่มีหลัง ใช้ระยะเวลาเข้าถึงข้อมูลเท่ากันไม่ว่าข้อมูลจะอยู่จุด
ใดของหน่วยความจำ สามารถเข้าถึงตำแหน่งนั้นได้โดยตรง ตัวอย่างคือ หน่วยความจำหลัก ได้แก่ แรมและ
รอม (RAM และ ROM)
Random Access Method

4. การเข้าถึงแบบเดาล่วงหน้า (Associative) จัดว่าเป็นการเข้าถึงหน่วยความจำแบบ Random
access แต่สามารถค้นหาตำแหน่งที่สอดคล้องกันล่วงหน้าได้ ใช้เวลาที่ใช้ในการเข้าถึงข้อมูลเท่ากันเหมือน
Random access จัดเป็นการเข้าถึงข้อมูลที่เร็วที่สุด ได้แก่ Cache

เครื่องพิมพ์ (Printer) เป็นอุปกรณ์ที่แสดงผลลัพธ์ในรูปข้อมูล รายงาน รูปภาพ ลงบนกระดาษ หรือ
เป็นวัตถุ 3D ซึ่งสามารถสัมผัส และเก็บรักษาไว้ได้นาน เครื่องพิมพ์อาจเรียกว่า หน่วยแสดงผลถาวร (Hard
copy) ในปัจจุบันเครื่องพิมพ์มีหลายชนิด ดังนี้

### 2.1 เครื่องพิมพ์แบบฉีดหมึก (Inkjet printer)

เครื่องพิมพ์ชนิดนี้ นิยมใช้กับเครื่องคอมพิวเตอร์ส่วนบุคคล เพราะมีราคาไม่แพงมากนัก
หลักการพิมพ์ใช้วิธีการฉีดพ่นหมึกเล็ก ๆ ให้ติดกับกระดาษ *สามารถพิมพ์เอกสารหรือภาพถ่ายได้
ด้วยความละเอียดดีที่สุด (ดีกว่าเครื่องพิมพ์ทุกประเภทในหัวข้อนี้)

### 2.2 เครื่องพิมพ์แบบเลเซอร์ (Laser printer)

ทำงานคล้าย ๆ กับเครื่องถ่ายเอกสาร โดยใช้แสงเลเซอร์สร้างประจุไฟฟ้าบวกบน
แผ่นกระดาษที่เคลื่อนผ่านผงหมึกที่มีประจุลบจะถูกดูดกับประจุบวก จากนั้นลูกกลิ้งร้อนจะช่วยให้
หมึกติดบนกระดาษ เครื่องพิมพ์แบบเลเซอร์มีความเร็วในการพิมพ์สูง และมีต้นทุนการพิมพ์เฉลี่ยต่อ

แผ่นถูกกว่าเครื่องพิมพ์แบบฉีดหมึก จึงเหมาะกับงานที่ต้องการพิมพ์ปริมาณมาก เช่น สำนักงาน
สถานศึกษา ร้านถ่ายเอกสาร

### 2.3 เครื่องพิมพ์ดอตแมทริกซ์ (Dot Matrix Printer)

เครื่องพิมพ์ดอตแมทริกซ์ใช้หลักการสร้างจุดลง
บน กระดาษโดยตรง หัวพิมพ์ของเครื่องพิมพ์ มีลักษณะ
เป็นหัวเข็ม (pin) เมื่อต้องการพิมพ์สิ่งใดลงบนกระดาษ
หัวเข็มที่อยู่ในตำแหน่งที่ประกอบกันเป็น ข้อมูลดังกล่าว
จะยื่นออกมาเหนือหัวเข็มอื่นไปกระแทกกับผ้าหมึก ก็จะ
ทำให้เกิดจุดขึ้นที่กระดาษ การพิมพ์แบบนี้จะมีเสียง
ค่อนข้างดัง คมชัดของข้อมูลบนกระดาษขึ้นอยู่กับจำนวน
เครื่องพิมพ์ดอตแมทริกซ์ (Dot Matrix Printer)
จุด ถ้าจำนวนจุดยิ่งมากข้อมูลที่พิมพ์ลงบนกระดาษก็ยิ่ง
http://www.printersiamzeerrangsit.com/
คมชัดมากขึ้น ความเร็ว ของเครื่องพิมพ์ดอตแมทริกซ์อยู่ระหว่าง 200 ถึง 300 ตัวอักษรต่อวินาที
หรือประมาณ 1 ถึง 3 หน้าต่อนาที เครื่องพิมพ์ดอตแมทริกซ์ เหมาะสำหรับงานที่พิมพ์แบบฟอร์มที่
ต้องการซ้อนแผ่นก๊อปปี้หลาย ๆ ชั้น เครื่องพิมพ์ชนิดนี้ ใช้กระดาษต่อเนื่องในการพิมพ์ ซึ่งกระดาษ
ประเภทนี้จะมีรูข้างกระดาษทั้งสองฝั่ง

### 2.4 เครื่องพิมพ์แบบเทอร์มอล (Thermal Printer)

เครื่องพิมพ์แบบเทอร์มอล (Thermal Printer) เป็น
เครื่องพิมพ์ใบเสร็จที่พบเห็นได้ตามห้าง ตามร้านสะดวกซื้อ
หรือตู้ ATM และเครื่องจ่ายบัตรคิว หลักการทำงานของ
เครื่องพิมพ์ชนิดนี้ จะใช้ความร้อนจากหัวพิมพ์ถ่ายเทไปยัง
กระดาษเทอร์มอล ซึ่งกระดาษเทอร์มอลนี้จะมีสารเคมีในตัวที่
จะเกิดสีดำขึ้นมาเมื่อโดนความร้อนที่เหมาะสม เครื่องพิมพ์ชนิด
เครื่องพิมพ์แบบเทอร์มอล (Thermal Printer)
นี้มีข้อดีที่คือทำงานรวดเร็วและเสียงเงียบ ราคาถูก

### 2.5 เครื่องพิมพ์ 3 มิติ (3D Printing)

เครื่องพิมพ์ 3 มิติ คือ นวัตกรรมการพิมพ์ที่ทำ
ให้งาน 3D ที่ออกแบบไว้ ถูกผลิตออกมาได้อย่างสมจริง
มีรูปลักษณ์ สามารถจับต้องได้ พร้อมทั้งสามารถ
นำไปใช้ประโยชน์ได้จริง เช่น ถ้าออกแบบการ์ตูน แล้ว
สั่งพิมพ์ออกมาจากเครื่องพิมพ์ 3 มิติ จะได้การ์ตูนเป็น
การสร้างชนิ้ งานจากเครื่องพิมพ์ 3 มิต ิ
รูปลักษณ์ตามที่ออกแบบไว้ทุกประการ นิยมใช้สำหรับ
ภาพจาก https://www.harn.co.th
ทำต้นแบบ (Prototyping) ในงานออกแบบและวิศวกรรม การผลิตชิ้นส่วนเฉพาะบุคคล และการ
สร้างโมเดลทางการศึกษาหรือการแพทย์

### 2.6 เครื่องพล็อตเตอร์ (Plotter Printer)

เป็นเครื่องพิมพ์ที่สร้างมาเพื่อพิมพ์ชิ้นงาน
ขนาดใหญ่โดยเฉพาะ โดยมีหลักการทำงานคล้าย
Inkjet แต่ถูกออกแบบมาให้พิมพ์บนม้วนกระดาษ
ขนาดใหญ่ (A0, A1, A2) ด้วยความละเอียดสูง นิยม
ใช้สำหรับพิมพ์แปลนอาคาร (พิมพ์โดยสถาปนิกและ
วิศวกร) โปสเตอร์ขนาดใหญ่ ป้ายโฆษณา แผนที่
และงานกราฟิกขนาดใหญ่

4. ลำโพง (Speaker)
ลำโพง (speaker) เป็นอุปกรณ์ที่แสดงผลลัพธ์รูปแบบเสียง
ซึ่งปัจจุบันมีหลากหลายประเภท ลำโพงปกติทั่วไปที่เราพบเห็น เช่น
ลำโพงคอมพิวเตอร์ธรรมดา หูฟังแบบมีสาย (เชื่อมต่อด้วยสาย AUX:
Auxiliary Port) หูฟังแบบไร้สาย (เชื่อมต่อด้วย Bluetooth) และ
ลำโพงอัจฉริยะ
ลำโพงอัจฉริยะ
ลำโพงอัจฉริยะ เป็น ลำโพงไร้สาย ซึ่งใช้ระบบ AI เช่น Google Assistant หรือ Alexa ในการ
ประมวลผล สามารถรับข้อมูลและแปลผลด้วยเสียงพูดของมนุษย์ได้ ควบคุมด้วยเสียงได้และ สามารถตอบ
คำถามเกี่ยวกับสภาพอากาศ สภาพการจราจร แปลภาษา ควบคุมเครื่องใช้ภายในบ้าน ตั้งปลุก เตือน
ความจำ เปิดเพลง ฟังวิทยุ และเล่านิทาน รวมถึงอ่านหนังสือให้ฟังได้

ลำโพงอัจฉริยะถือเป็นอุปกรณ์ IoT (Internet of Thing) มีสามารถเชื่อมต่ออุปกรณ์อัจฉริยะที่ใช้ Wi-
Fi หรือ Bluetooth และอุปกรณ์ไร้สายอื่น ๆ เช่น เครื่องปรับอากาศอัจฉริยะ โทรทัศน์ ตู้เย็น และกาต้มน้ำ

หูฟังไร้สาย

ข้างอาจยังมีสายเชื่อมติดกันอยู่ เช่น หูฟังแบบมีสายคล้องคอหรือหู

Microprocessor และ Microcontroller
ภาพจาก https://components101.com/articles/difference-between-microprocessor-and-microcontroller
ไมโครคอนโทรลเลอร์ (Microcontroller) และไมโครโปรเซสเซอร์ (Microprocessor) เป็นอุปกรณ์ที่
ใช้ในการประมวลผลข้อมูล แต่มีความแตกต่างกันในด้านการออกแบบและการใช้งาน ดังนี้

1\. ไมโครคอนโทรลเลอร์ (Microcontroller)
องค์ประกอบ

1\. มี CPU, RAM, ROM/Flash memory, และ I/O peripherals อยู่ในตัวเดียวกัน

2\. อาจมีการรวมฟังก์ชันอื่นๆ เช่น ADC (Analog to Digital Converter), DAC (Digital to
Analog Converter) และการสื่อสารแบบ Serial

การใช้งาน
ใช้ในงานที่ต้องการการควบคุมแบบเรียลไทม์ เช่น ระบบฝังตัว (embedded systems)
เครื่องใช้ไฟฟ้า อุปกรณ์ IoT รถยนต์ และอุตสาหกรรม
ประสิทธิภาพและความสามารถ
มีประสิทธิภาพที่เพียงพอสำหรับงานควบคุมทั่วไป
มีการบริโภคพลังงานต่ำ ทำให้เหมาะสำหรับอุปกรณ์ที่ใช้พลังงานจากแบตเตอรี่
การพัฒนาต่อยอด
ง่ายต่อการพัฒนาและการนำไปใช้ เนื่องจากมีองค์ประกอบหลายๆ อย่างในตัวเดียวกัน

2. ไมโครโปรเซสเซอร์ (Microprocessor)
องค์ประกอบ
ประกอบด้วย CPU เพียงอย่างเดียว ไม่มี RAM ROM หรือ I/O peripherals ในตัว
ต้องการหน่วยความจำและอุปกรณ์อินพุต/เอาต์พุตแยกต่างหาก
การใช้งาน
ใช้ในคอมพิวเตอร์ทั่วไป เซิร์ฟเวอร ์ และอุปกรณ์ที่ต้องการการประมวลผลข้อมูลที่ซับซ้อน เช่น สมาร์ท
โฟน คอมพิวเตอร์ส่วนบุคคล และอุปกรณ์ที่ต้องการประสิทธิภาพสูง
ประสิทธิภาพและความสามารถ
มีประสิทธิภาพสูง สามารถประมวลผลข้อมูลที่ซับซ้อนได้อย่างรวดเร็ว
เหมาะสำหรับงานที่ต้องการการคำนวณเชิงคณิตศาสตร์ การประมวลผลภาพ การประมวลผลเสียง
และงานที่ต้องการความเร็วสูง
การพัฒนาต่อยอด
ซับซ้อนกว่าไมโครคอนโทรลเลอร์ เนื่องจากต้องการองค์ประกอบเสริมอื่นๆ เช่น หน่วยความจำและ
อินพุต/เอาต์พุต
สรุปความแตกต่างที่สำคัญ
องค์ประกอบ ไมโครคอนโทรลเลอร์มีทุกอย่างรวมอยู่ในตัวเดียว ส่วนไมโครโปรเซสเซอร์มี
เฉพาะ CPU ต้องการส่วนประกอบเสริมแยกต่างหาก
การใช้งาน ไมโครคอนโทรลเลอร์ใช้ในงานควบคุมแบบเรียลไทม์และระบบฝังตัว ส่วน
ไมโครโปรเซสเซอร์ใช้ในคอมพิวเตอร์และงานที่ต้องการการประมวลผลสูง
ประสิทธิภาพ ไมโครโปรเซสเซอร์มีประสิทธิภาพสูงกว่าและเหมาะสำหรับงานที่ซับซ้อน ส่วน
ไมโครคอนโทรลเลอร์เน้นการใช้พลังงานต่ำและควบคุมงานทั่วไป

การเลือกซื้อและวิธีอ่านสเปค (Specification) คอมพิวเตอร์เบื้องต้น
การเลือกซื้อคอมพิวเตอร์ที่เหมาะสมกับความต้องการของเรานั้น ต้องพิจารณาจากองค์ประกอบ
หลักๆ (Hardware) เพื่อให้แน่ใจว่าเครื่องมีประสิทธิภาพเพียงพอต่อการใช้งานในชีวิตประจำวันหรือเพียงพอ
ต่อการทำงานประจำของเราด้วย ที่สำคัญคืองบประมาณในกระเป๋าของเราครับ
หัวข้อนี้ผมจะเพิ่มให้เนื่องจากเมื่อเราสอบติดแล้ว ไม่ว่าจะเป็นครูหรือนักวิชาการคอมพิวเตอร์ หรือ
ข้าราชการสังกัดใดๆ ก็จะหนีไม่พ้นการกำหนดสเปคคอมพิวเตอร์ หรือภาษาราชการ คือ “รายละเอียดจำเพาะ
ของคอมพิวเตอร์” หรือ “คุณลักษณะเฉพาะของคอมพิวเตอร์” ตอนที่หน่วยงานของเราจะต้องซื้อหรือเช่า
คอมพิวเตอร์ เมื่อเรียนจบหัวข้อนี้แล้วเราจะได้กำหนดสเปคเป็น ดูสเปคเป็น เพื่อเป็นประโยชน์ต่อทางราชการ
และเลี่ยงการที่จะถูกฟ้องเพราะล็อคสเปคคอมพิวเตอร์ ที่สำคัญมันก็จะเป็นประโยชน์ส่วนตัวของเราในการ
เลือกซื้ออุปกรณ์คอมพิวเตอร์ส่วนตัวด้วย ขนั้ ตอนโดยสังเขปมีดังนี้

1\. กำหนดงบประมาณและการใช้งาน จะใช้ทำอะไรเป็นหลัก เช่น งานเอกสาร ดูหนัง เล่นเกมหนัก และ
งาน 3D และมีงบประมาณเท่าไหร่

2\. เลือก CPU และ GPU กำหนดสองส่วนนี้ก่อน เพราะเป็นตัวกำหนดประสิทธิภาพหลัก

3\. เลือก Mainboard และ RAM เลือกเมนบอร์ดที่มี Socket ตรงกับ CPU และรองรับ RAM ความเร็ว
สูงตามทเี่ ราเลือก (ขั้นต่ำตอนนี้ไม่ควรต่ำกว่า 8 GB)

4\. เลือกหน่วยเก็บข้อมูลถาวร (Storage) ควรมี SSD NVMe M.2 เป็นไดรฟ์หลัก และเลือกความจุรวมที่
เพียงพอ

5\. เลือกแหล่งจ่ายไฟ (PSU) คำนวณกำลังไฟรวมของ CPU/GPU แล้วเลือก PSU ที่มีกำลังไฟสำรองและ

GPU หรือ การ์ดจอ ทำหน้าที่ประมวลผลภาพกราฟิก และงานที่ต้องใช้การคำนวณแบบขนาน เช่น

CPU กับ GPU ต่างกันอย่างไร
แม้ว่าทั้ง CPU (Central Processing Unit) และ GPU (Graphics Processing Unit) จะเป็นชิป
ประมวลผลที่สำคัญในคอมพิวเตอร์เหมือนกัน แต่ทั้งคู่ออกแบบมาเพื่อทำหน้าที่ที่แตกต่างกันโดยสิ้นเชิง โดยมี
ความแตกต่างหลัก ๆ ในด้าน สถาปัตยกรรม (Architecture) ความเร็ว (Speed) และวัตถุประสงค์การใช้งาน
(Purpose) แต่กล่าวโดยสรุปและเปรียบเทียบให้เห็นภาพคือ

6. แหล่งจ่ายไฟ (PSU: Power Supply Unit)
PSU (Power Supply Unit) เป็นอุปกรณ์สำคัญที่ทำหน้าที่แปลงไฟฟ้ากระแสสลับ (AC) จากไฟบ้าน
ให้เป็นไฟฟ้ากระแสตรง (DC) เพื่อจ่ายพลังงานที่เสถียรให้กับชิ้นส่วนคอมพิวเตอร์ต่าง ๆ การเลือกใช้
แหล่งจ่ายไฟที่มีคุณภาพสูงจึงช่วยลดความเสี่ยงที่อุปกรณ์ภายในจะเสียหายได้อย่างมาก

ส่วนประกอบ คำอธิบายและวิธีเลือก

(Wattage) 500W ควรเลือก PSU 650W หรือ 750W ขึ้นไป)
