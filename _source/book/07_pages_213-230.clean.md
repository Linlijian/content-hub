# บทที่ 7 OSI Model, Protocol และ Port

ก่อนเข้าเนื้อหาหลักคือ OSI Model (Open
Systems Interconnection Model) และ Protocol
ต่างๆ เราจำเป็นอย่างยิ่งที่จะต้องทราบที่มาที่ไปของการ
มี OSI Model เพื่อเชื่อมโยงความรู้และตกผลึกเป็น
ความเข้าใจ จุดเริ่มต้นของการมี OSI Model คือ
“องค์ประกอบของการสื่อสารข้อมูล” ซึ่งมีดังนี้

1\. องค์ประกอบของการสื่อสารข้อมูล
องค์ประกอบของการสื่อสารข้อมูล

องค์ประกอบของการสื่อสารข้อมูล มีอยู่ 5 องค์ประกอบ ผู้เขียนจะเขียนให้อยู่ในรูปของ SMMRP
ได้แก่

1\. ผู้ส่ง (Sender) ผู้ส่ง (Sender) เป็นอุปกรณ์ที่ใช้ในการส่งข่าวสาร (Message) เป็นต้นทางของการ
สื่อสารข้อมูลมีหน้าที่เตรียมสร้างข้อมูล เช่น ผู้พูด เมาส์ คีย์บอร์ด และรีโมทคอนโทรล เป็นต้น

2\. สื่อกลาง (Medium) หรือตัวกลาง เป็นเส้นทางการสื่อสารเพื่อนำข้อมูลจากต้นทางไปยังปลายทาง
สื่อส่งข้อมูลอาจเป็นแบบมีสาย (Wire) เช่น สายอีเทอร์เน็ต สายโคแอกเชียล สายใยแก้วนำแสง หรือแบบไม่มี
สาย (Wireless) เช่น คลื่นที่สง่ ผ่านทางอากาศ เช่น คลื่นไมโครเวฟ คลื่นวิทยุ และคลื่นอินฟาเรด

3\. ข้อมูลข่าวสาร (Message) คือสัญญาณอิเล็กทรอนิกส์ที่ส่งผ่านไปในระบบสื่อสาร เช่น ข้อความ
(Text) ตัวเลข (Number) รูปภาพ (Images) เสียง (Audio) และ วิดีโอ (Video)

4\. ผู้รับ (Receiver) เป็นปลายทางการสื่อสาร มีหน้าที่รับข้อมูลที่ส่งมาให้ เช่น ผู้ฟัง เครื่องพิมพ์ และ
เครื่องปรับอากาศที่รับคำสั่งจากรีโมทคอนโทรล เป็นต้น

5\. โพรโตคอล (Protocol) คือ วิธีการหรือกฎระเบียบที่ใช้ในการสื่อสารข้อมูลเพื่อให้ผู้รับและผู้ส่ง
สามารถเข้าใจกันหรือคุยกันรู้เรื่อง โดยทั้งสองฝั่งทั้งผู้รับและผู้ส่งได้ตกลงกันไว้ก่อนล่วงหน้าแล้ว ในระบบ
เครือข่าย โพรโตคอลจะอยู่ทั้งในส่วนของซอฟต์แวร์ที่มีหน้าที่ทำให้การดำเนินงาน ในการสื่อสารข้อมูลเป็นไป
ตามโปรแกรมที่กำหนดไว้ ตัวอย่างเช่น TCP/IP, UDP/IP เป็นต้น และจะอยู่ในส่วนของฮาร์ดแวร์ด้วย เช่น การ
สื่อสารตามมาตรฐาน WI-FI และ Ethernet เป็นต้น

### 1.1 ตัวอย่างของการสื่อสารข้อมูลทั่วไปในชีวิตประจำวันของมนุษย์

"นพพลคุยกับ Avril Lavigne เรื่องการเดินทางไปเที่ยวเนเธอแลนด์ผ่าน VDO Call" การคุยโทรศัพท์
ระหว่างนพพล และ Avril เป็นตัวอย่างหนึ่งของการสื่อสาร เขียนในรูปแบบ SMMRP ได้ดังนี้

S: Sender = ผสู้ ่งสาร คือ นพพล
M: Medium = โทรศัพท์มือถือ อุปกรณ์ต่างๆ ที่สื่อสารได้
M: Message = ข้อมูล คือ การไปเที่ยวเนเธอแลนด์
R: Receiver = ผู้รับสาร คือ Avril Lavigne
P: Protocol = โพรโตคอล คือ ภาษา เราทั้งสองคนอาจจะไม่สามารถสื่อสารให้เข้าใจกันและ
กันได้ เนื่องจากพูดคนละภาษา โปรโทคอลจึงเปรียบเสมือนการบังคับให้เราทั้งสองใช้ภาษากลาง ซึ่งอาจจะ
เป็นภาษาอะไรก็ได้ที่เราเข้าใจกันได้ทั้งค ู่ ดังนั้น นพพลเป็นคน
ไทย กับ Avril Lavigne เป็นคนแคนาดา มีให้เลือก 3 ภาษา
คือภาษาฝรั่งเศส ภาษาไทย และภาษาอังกฤษ เราทั้งคู่เลือก
สนทนาภาษาอังกฤษ เพราะว่าครูนพพลพูดภาษาฝรั่งเศส
ไม่ได้ และ Avril Lavigne พูดภาษาไทยไม่ได้ สรุปว่า
การสอื่ สารระหว่าง นพพล กับ Avril ภาษากลางที่เราจะคุยกันรู้เรื่องคือ ภาษาอังกฤษนั่นเอง

### 1.2 ตัวอย่างของการสื่อสารข้อมูลในระบบเครือข่ายคอมพิวเตอร์

"นพพลคุยกับ Avril Lavigne เรื่องการเดินทางไปเที่ยวเนเธอแลนด์ผ่าน VDO Call" เขียนในรูปของ
SMMRP คือ
S: Sender = ผู้ส่งสาร คือ อุปกรณ์ เช่น แท็บเล็ตของนพพล และตัวนพพลเอง
M: Medium = สื่อกลาง คือ สัญญาณอินเทอร์เน็ต สัญญาณเซลลูล่าร์ สายไฟเบอร์ออปติก และ
สัญญาณ WI-FI
M: Message = ข้อมูล คือ ภาพและเสียง ซึ่งถูกแปลงผ่าน OSI Model เป็น Segment Packet
Frame และ สัญญาณดิจิทัล (เลขฐานสอง) ที่วิ่งไปตามสื่อกลาง
R: Receiver = ผู้รับสาร คือ อุปกรณ์ เช่น โทรศัพท์มือถือของ Avril Lavigne และตัว Avril เองด้วย
P: Protocol = โพรโตคอล คือ TCP/IP (Transmit Control Protocol/ Internet Protocol) ที่จะ
ทำให้ทั้งนพพล และ Avril สามารถสื่อสารผ่านวีดีโอคอลถึงกันและกันได้โดยภาพและเสียงไม่สูญ
หายระหว่างทาง
จะสังเกตได้ว่า โพรโตคอลช่วยให้ระบบคอมพิวเตอร์สองระบบที่แตกต่างกันสามารถสื่อสารกันอย่าง
เข้าใจได้ ดังนั้น โพรโตคอลก็คือข้อตกลงที่กำหนดเกี่ยวกับการสื่อสารระหว่างเครื่องคอมพิวเตอร์ต่างๆ เช่น
วิธีการส่งและรับข้อมูล รวมถึงวิธีการตรวจสอบข้อผิดพลาดของการส่งและรับข้อมูล โพรโตคอลจึงมี
ความสำคัญมากในการสื่อสารบนเครือข่าย หากไม่มีโพรโตคอลแล้ว การสื่อสารบนเครือข่ายจะไม่สามารถ
เกิดขึ้นได้ เพื่อไม่ให้เกิดความซ้ำซ้อนและเข้าใจยาก ผู้เรียบเรียงจะอธิบายอย่างละเอียดในหัวข้อ “Protocol”
ในเรื่องท้ายๆ ของบทน ี้

### 1.3 ทิศทางการส่งข้อมูล (Transmission Mode)

ทิศทางการสื่อสาร แบ่งการสื่อสารข้อมูลตามทิศทางการส่งข้อมูลได้เป็น 3 รูปแบบ ดังนี้

1. การสื่อสารข้อมูลทิศทางเดียว (Simplex Transmission) เป็นการสื่อสารข้อมูลที่มีผู้ส่งข้อมูล
ทำหน้าที่ส่งแต่เพียงผู้เดียว และผู้รับทำหน้าที่ รับข้อมูลแต่เพียงอย่างเดียว เช่น การส่งอีเมล การใช้บริการรับ
ฝากข้อความ ข้อดีคือ ไม่มีข้อจำกัดทางด้านเวลา แต่ผลเสียคือผู้รับข้อมูลอาจไม่ได้รับข้อมูลที่ส่งไป และผู้ส่ง
ข้อมูลจะไม่ทราบว่าผู้รับได้รับหรือไม่ ตัวอย่างการสื่อสารข้อมูลทิศทางเดียวในชีวิตประจำวัน เช่น การฟังวิทยุ
การดูโทรทัศน์ การดูถ่ายทอดสดผ่าน Live Stream และการฟังเสียงประกาศ ตัวอย่างของการสื่อสารข้อมูลใน
คอมพิวเตอร์ก็จะเป็น การสื่อสารระหว่างคอมพิวเตอร์และปริ้นเตอร์ และการสื่อสารจากคีย์บอร์ดไปสู่
คอมพิวเตอร์

2. การสื่อสารข้อมูลสองทิศทางสลับกัน (Half-Duplex Transmission) เป็นการสื่อสารข้อมูลที่ผู้
สื่อสารจะผลัดกันเป็นผู้รับและผู้ส่งข้อมูล โดยในขณะที่
มีการสื่อสารข้อมูล ผู้รับข้อมูลจะต้องรอให้ผู้ส่งส่งข้อมูล
เสร็จสิ้นก่อนจึงจะสามารถส่งข้อมูลได้ การสื่อสารข้อมูล
ประเภทนี้ นิยมใช้ในเฉพาะกลุ่ม ได้แก่ วิทยุสื่อสาร
(Radio Communication) และอุปกรณ์กระจาย
Full Duplex VS Half Duplex
สัญญาณแบบฮับ (Hub)
https://www.youtube.com/watch?v=LMRSS7ZYM50

3. การสื่อสารข้อมูลสองทิศทางพร้อมกัน (Full-Duplex Transmission) ผู้สื่อสารสามารถส่ง
ข้อมูลโต้ตอบกันได้ทันทีโดยไม่ต้องรอให้ผู้ส่งข้อมูลเสร็จก่อน ตัวอย่างการสื่อสารข้อมูลสองทิศทางพร้อมกัน
เช่น การคุยโทรศัพท์ การวีดีโอคอล และการแชต (Instant Message) เป็นต้น

### 1.4 ชนิดของสัญญาณในการสื่อสารข้อมูล

สัญญาณข้อมูล (Data Signal) แบ่งเป็น 2 ประเภท ดังนี้

1. สัญญาณแอนะล็อก (Analog Signal) มีลักษณะเป็นสัญญาณต่อเนื่อง (Continuous Data) ใน
รูปแบบคลื่น คล้ายๆ คลื่นในทะเล มีขนาดของสัญญาณไม่
คงทสี่ ามารถแทนลักษณะของสัญญาณได้ด้วยรูปกราฟคลื่น
ไซน์ (Sine Wave) โดยการส่งสัญญาณแบบแอนะล็อกจะ
ถูกรบกวนให้มีการแปลความหมายผิดพลาดได้ง่าย ตัวอย่าง
ของสัญญาณแอนะล็อก เช่น สัญญาณเสียงในสายโทรศพั ท์
สัญญาณเสียงจากสถานีวิทยุ และสัญญาณที่ใช้ใน
ไมโครโฟน เป็นต้น

2. สัญญาณดิจิทัล (Digital Signal) มีลักษณะ สัญญาณแอนะล็อกและสัญญาณดิจิทัล (Analog and Digital Signal)
ภาพจาก www.obsmoscou.net/หัวข้อ-สัญญาณ-analog-กบั -digital-แตกต่/
เป็นสัญญาณไม่ต่อเนื่อง (Discrete Data) ในรูปแบบกราฟ
สี่เหลี่ยม (Square Graph) มีคุณภาพและแม่นยำกว่า สัญญาณแอนะล็อก เพราะมีขนาดแน่นอน ซึ่งขนาด
ดังกล่าวอาจกระโดดไปมาระหว่างค่าสองค่าคือสถานะเป็น "0" และ "1" หรืออาจจะมีหลายสถานะแล้วแต่
เกณฑ ์ (Threshold) ที่ตั้งไว้

เมื่อเรามคี วามรู้เบื้องต้นเกี่ยวกับองค์ประกอบของการสื่อสารแล้ว ต่อจากนี้คือเรื่อง OSI Model ที่จะ
ทำให้เข้าใจวิธีการทำงานอย่างสอดคล้องกันขององค์ประกอบของการสื่อสารทั้ง 5 ส่วน (SMMRP:
Sender,Medium,Message,Reciever และ Protocol) ว่ามันทำงานสัมพันธ์และสอดคล้องกันอย่างไร ใครมี
หน้าที่ทำอะไร มีวิธีการอย่างไร แล้วผ่านอะไรบ้าง

2\. OSI Model คืออะไร?
OSI Model (Open Systems Interconnection
Model) คือรูปแบบการรับส่งข้อมูลระหว่างอุปกรณ์
อิเล็กทรอนิกส์ผ่านระบบเครือข่าย ซึ่งเป็นมาตรฐานการ
ทำงานภายในของระบบการสื่อสาร โดยกำหนดรูปแบบของผู้
ส่งข้อมูล (Sender) และ ผู้รับข้อมูล (Receiver)
OSI Model ได้มีการแบ่งการทำงานของระบบ
เครือข่ายเป็นชั้นต่างๆ เพื่อให้การทำงานของระบบสื่อสารนั้น
เป็นไปอย่างมีประสิทธิภาพมากยิ่งขึ้น เนื่องจากได้มีการแบ่ง
OSI Model ทั้ง 7 ขั้น (Layer)
ส่วนการทำงานต่างๆ อย่างชัดเจน โดยจะแบ่งการทำงาน ภาพจาก https://www.ablenet.co.th/2020/08/28/what-is-osi-model
ออกเป็น 7 ชั้น (เลเยอร์ : Layers)
ลักษณะการทำงานของ Layer 1-3 จะเน้นที่การสื่อสารในระดับ Hardware เป็นหลัก ทำหน้าที่
เชื่อมต่อคอมพิวเตอร์ของผู้ใช้ทั้งสองฝั่ง (Senders และ Receivers) ผ่านระบบเครือข่ายทั้งแบบมีสายและไร้
สาย โดยจะเกี่ยวข้องกับ Hardware เป็นหลัก เราจะเรียกว่า “Network-dependent Layers” ได้แก ่

1\. Physical Layer

2\. Data link Layer

3\. Network Layer
ลักษณะการทำงานของ Layer 4-7 จะเน้นไปที่การติดต่อกับผู้ใช้ (Sender และ Receiver) ผ่าน
Software เป็นหลัก เราจะเรียกว่า “Application-oriented layers” ได้แก ่

4\. Transport Layer

5\. Sesion Layer

6\. Presentation Layer

7\. Application Layer
โดยแต่ละชั้น (Layer) จะมีบทบาท หน้าที่และหลักการทำงานที่แตกต่างกันแต่จะทำงานร่วมกับ
Layer ที่อยู่ติดกัน ดังนี้

### 2.1 ชั้น (Layer) ของ OSI Model

ผู้เรียบเรียง จะเรียงลำดับการอธิบาย OSI Model เริ่มจากชั้นบนสุดคือชั้นที่ 7 ก่อน เพื่อทำความ
เข้าใจอย่างเป็นลำดับจากเรื่องที่ใกล้ตัวเรามากกว่าไปจนถึงเรื่องไกลตัวกว่า ทำให้ได้เห็นภาพชัดเจนยิ่งขึ้น ดังนี้
Layer 7: Application Layer เป็นชั้นที่อยู่ใกล้กับ
ผู้ใช้ (User) มากที่สุด เน้นการติดต่อกับผู้ใช้ และอนุญาตให้ผู้ใช้

Layer 5: Session Layer เป็นชั้นที่มีการซิงค์ข้อมูล (Data Sync) โดยทำหน้าที่ควบคุมจังหวะใน
การรับส่งข้อมูลของทั้ง 2 ฝั่ง (จากต้นทางหรือ “ผู้ส่ง” ไปยังปลายทางหรือ “ผู้รับ”) ให้มีความสอดคล้องกัน
(Synchronization) กล่าวอีกนัยหนึ่งคือ ทำหน้าที่ซิงค์ข้อมูลระหว่างเครื่องต้นทางกับเครื่องปลายทางให้ข้อมูล
ตรงกัน ซึ่งต้องทำให้เสร็จภายในระยะเวลาที่กำหนด เช่น ผู้ใช้ต้องการขอใช้บริการบางอย่างจากเครื่อง
ปลายทางเป็นเวลา 20 วินาที ผ่าน port 99 เครื่องปลายทางก็จะส่งข้อความอนุญาตให้ผู้ใช้ดังกล่าวใช้บริการ
ผ่าน port 99 ได้ เป็นเวลา 20 วินาที หาก Session ที่ขอใช้งานเกิดหมดเวลา ก็จะไม่สามารถใช้บริการนั้นได้

ของแอป) เช่น กรณีเราเข้าแอปธนาคาร ช่วงที่กำลังเชื่อมต่ออยู่นั้นจะเป็นช่วงที่ทำงานใน Session Layer ซึ่ง
จะแสดงผลให้ทราบว่าจะเข้าสู่แอปได้หรือไม่ ถ้าเข้าสู่แอปไม่ได้ เราจะเรียกติดปากกันวา “แอปล่ม” คือติดต่อ
กับเซิร์ฟเวอร์ของธนาคารไม่ได้นั่นเอง

ช่อง (Port) ต่างๆ ที่กำหนด ทำให้ในกรณีที่โพรเซส (Process) ในเครื่องเดียวกัน หรือโพรเซสของแอปเดียวกัน

### 3.2 ชั้นการประยุกต์ใช้งาน (Application Layer)

ชั้นการประยุกต์ใช้งาน เทียบได้กับชั้นที่ 5 ถึง 7 ในโครงสร้างแบบ OSI จะครอบคลุมบริการที่
เกี่ยวข้องกับการรักษาความปลอดภัย การเข้ารหัส การเชื่อมต่อระหว่างโปรแกรมประยุกต์ และเป็นชั้นที่
โปรแกรมประยุกต์ใช้งานโดยตรง โดยโปรโทคอลที่อยู่บนชั้นนี้จะถูกออกแบบให้เหมาะสำหรับประเภทของ
โปรแกรมประยุกต์เฉพาะทาง เช่น โปรแกรมอีเมลใช้โปรโทคอล SMTP สำหรับส่งอีเมล ใช้โปรโทคอล POP3
สำหรับรับและเรียกดูอีเมล, ส่วนโปรแกรมเว็บเบราว์เซอร์ใช้โปรโทคอล HTTP สำหรับเรียกดูเว็บเพจ เป็นต้น
โพรโตคอลใน Application Layer

1. HTTP ( HyperText Transfer Protocol ) และ HTTPS (HTTP Secure) ใช้ในการติดต่อรับส่ง
ข้อมูลชนิดไฮเปอร์เท็กซ์ (Hypertext) ระหว่างเครื่องลูกข่าย (Client) กับ WWW Server โดยเอกสารส่วน
ใหญ่จะเขียนในภาษา HTML (HyperText Markup Language) ส่วน HTTPS เป็นเวอร์ชันที่ปลอดภัยกว่า
HTTP โดยมีการเข้ารหัสข้อมูล (Encryption) ระหว่างเครื่องลูกข่ายและเซิร์ฟเวอร์ด้วยโพรโตคอล TLS/SSL
ทำให้ข้อมูลที่ส่งผ่าน เช่น รหัสผ่าน ข้อมูลบัตรเครดิต ไม่สามารถถูกผู้ไม่หวังดีดักจับไปอ่านได้

2. FTP ( File Transfer Protocol ) ใช้ในการรับ-ส่งแฟ้มข้อมูลระหว่างเครื่องลูกข่ายและเครื่อง
Server โดยที่เครื่อง Server จะต้องมีโปรแกรมให้บริการ FTP (FTP Server) ติดตั้งและทำงานอยู่ เพื่อให้
เครื่องลูกข่ายที่รันโปรแกรม FTP Client สามารถเข้ามาขอใช้บริการได้

3. DNS (Domain Name System) คือระบบตั้งชื่อให้แต่ละโฮสต์ให้จำง่าย แทนการใช้หมายเลขไอพี
(IP Address) ที่จำยาก ทำหน้าที่คล้ายกับสมุดโทรศัพท์ โดยจะแปลงชื่อโดเมน (เช่น www.google.com) ให้
เป็น IP Address ที่คอมพิวเตอร์เข้าใจ

4. SMTP (Simple Mail Transfer Protocol) คือ โพรโตคอล ที่ใช้ในการส่งจดหมายอิเล็กทรอนิกส์
(Email) จากเครื่องเราไปสู่เครือข่ายอินเทอร์เน็ต โดยเมื่อเรากดส่งอีเมล SMTP จะทำหน้าที่เอาเมลไปส่งต่อ
เป็นทอด ๆ จนถึงเซิร์ฟเวอร์ผู้รับ

5. POP3 (Post Office Protocol) คือ EMail Protocol ที่ใช้วิธีการให้ผู้ใช้บริการดงึ อีเมลจาก Mail
Server เมอื่ ดึงเสร็จแล้วจะลบอีเมลที่อยู่ใน Server ออก ปัจจุบันไม่นิยมใช้แล้ว

6. IMAP (Internet Message Access Protocol) คือ EMail Protocol ที่ใช้วิธีการให้ผใู้ ช้บริการดงึ
อีเมลจาก Mail Server แต่ไม่ได้ลบข้อมูลออกจาก Server เหมือน POP3 นิยมใช้ที่สุดในยุคนี้แทบ 100%

Packet นั้นไปเลย ทำให้ไม่ต้องทำ Handshaking ซึ่งทางผู้ใช้ต้องยอมรับว่าข้อมูลจะไม่สามารถเชื่อถือลำดับได้

### 3.4 ชั้นอินเทอร์เน็ต (Internetwork Layer)

ชั้นอินเทอร์เน็ต เทียบได้กับชั้นที่ 3 ซึ่งคือ Network Layer ใน OSI Model เป็นชั้นที่มีหน้าที่ส่งข้อมูล
จากจุดเริ่มต้นไปยังปลายทางที่ข้อมูลจะใช้เดินทางผ่านเครือข่ายหนึ่งไปยังอีกเครือข่ายหนึ่งจนกระทั่งถึง
ปลายทาง โดยใช้อัลกอริทึมในการหาเส้นทางที่ใกล้ที่สุดหรือสะดวกที่สุด
โพรโตคอลใน Internetwork Layer
โพรโตคอลสำคัญที่ทำงานในเลเยอร์นี้ คือ IP, ARP และ ICMP

1. IP (Internet Protocol)
โปรโทคอลที่ใช้ในชั้นนี้คือ Internet Protocol หรือ IP จะทำหน้าที่จัดการเกี่ยวกับการรับส่งแพ็กเก็ต
หรือบางทีก็เรียกว่า “ดาต้าแกรม (Datagram)” คือหน่วยของข้อมูลที่รับมาจากโพรโตคอลที่อยู่ในเลเยอร์ที่สูง
กว่าอย่าง TCP และ UDP
สรุปให้เข้าใจง่ายคือ IP เปรียบเสมือนกระดาษปะหน้ากล่องพัสดุซึ่งระบุถึงที่อยู่ของต้นทางและ
ปลายทาง โดยมีพนักงานทำหน้าที่จัดส่งพัสดุตามกระดาษปะหน้าพัสดุในนามของบริษัทขนส่ง เพื่อจัดส่งพัสดุ
ไปยังพื้นที่ต่างๆ จนถึงจุดหมายปลางทาง กล่องพัสดุเปรียบเหมือน แพ็กเก็ต (Packet) กระดาษปะหน้า
เปรียบเหมือน หมายเลขไอพี บริษัทขนส่ง เปรียบเหมือน เราเตอร์ (Router) ที่ทำหน้าที่ค้นหาเส้นทางที่
เหมาะสมเพื่อส่งข้อมูลไปตามสายส่งจนกระทั่งถึงปลายทาง

2. ARP (Address Resolution Protocol)
โพรโตคอล ARP ทำหน้าที่ค้นหมายเลข Mac Address ของเครื่องที่มีหมายเลขไอพีที่ต้องการ

หลักการทำงานของ ARP คือ โฮสต์ (Host) ที่ต้องการทราบหมายเลข Mac Address ของเครื่องที่มี
หมายเลขไอพีนั้น จะบอร์ดคาสต์ (Broadcast) แพ็กเก็ตไปยังคอมพิวเตอร์ทุกเครื่องที่อยู่ในเครือข่ายเดียวกัน
ถ้ามีเครื่องที่มีหมายเลขไอพีดังกล่าว เครื่องนั้นก็จะตอบกลับมาพร้อมหมายเลข Mac Address ของเครื่องนั้น
หลังจากนั้นเครื่องส่งก็สามารถสื่อสารกับเครื่องปลายทางได้โดยตรง

3. ICMP (Internet Control Message Protocol)
โพรโตคอล ICMP ทำหน้าที่รายงานข้อผิดพลาดต่างๆ ที่เกิดขึ้นในระหว่างที่มีการส่งแพ็กเก็ตใน
เครือข่าย ICMP ใช้การส่งแบบคอนเน็กชันเลส (Connectionless) ซึ่งหมายถึงการรับส่งข้อมูลที่ฝ่ายรับและ
ฝ่ายส่งไม่ได้ประสานกันก่อน กล่าวคือฝ่ายรับจะไม่ทราบว่าจะมีแพ็กเก็ตส่งมาหาตัวเอง ดังนั้นโอกาสที่แพ็กเก็ต
จะส่งมาไม่ถึงปลายทางจึงเป็นไปได้สูง
ฟังก์ชันที่สำคัญของโพรโตคอลนี้ คือ ประกาศข้อผิดพลาดของเครือข่าย ประกาศความคับคั่งของ
เครือข่าย ช่วยในการค้นหาข้อผิดพลาด และประกาศการหมดเวลาเชื่อมต่อ โดยฟังก์ชันต่างๆของ ICMP จะมี
ประโยชน์มากสำหรับการวิเคราะห์และค้นหาจุดเสียของระบบ

### 3.5 ชั้นการเชื่อมต่อ หรือ Link layer

มีหลายชื่อเรียก เช่น Physical Layer หรือ Network Access หรือ Network Interface
ชั้นการเชื่อมต่อ หรือ Link layer สามารถเทียบได้กับชั้นที่ 1 และ 2 ในโครงสร้างแบบ โอเอสไอ เป็น
ลำดับชั้นที่ไม่ได้เกี่ยวข้องกับระบบอินเทอร์เน็ตโดยตรง แต่เป็นระบบพื้นฐานของการเชื่อมต่อที่ระบบ
อินเทอร์เน็ตใช้ส่งข้อมูลภายในเครือข่ายโดเมน
หน้าที่ของชั้นนี้สำหรับการส่งข้อมูลทำหน้าที่เหมือนกับ Layer 1 และ 2 ใน OSI Model
โพรโตคอลใน Link layer
โพรโตคอลสำคัญที่ทำงานในเลเยอร์นี้ คือ Ethernet, Wi-Fi, PPP และ Token Ring (ไม่ใช้กันแล้ว)

1. Ethernet คือเทคโลยีในเครือข่าย Lan ชนิดแบบมีสาย (Wire) ชนิดหนึ่ง ซึ่งปัจจุบันมีความเร็ว
มากกว่า 40 Gbps (สาย CAT 8 ทำความเร็วได้ถึง 40 Gbps และมีแบนด์วิธสูงถึง 2,000 MHz เร็วกว่าสายรุ่น
ก่อนหน้าเป็นอย่างมาก) และสายที่เราใช้ในทุกๆวันอย่าง Cat5e ก็มีควาเร็วถึง 1 Gbps แล้ว Ethernet เป็นสิ่ง
ที่เราทุกคนใช้กันทุกๆวัน (รายละเอียดจะกล่าวในบทต่อไป)

2. WI-FI คือ เทคโนโลยีในเครือข่าย Lan ชนิดหนึ่งแบบไร้สาย (Wireless) ชนิดหนึ่ง ซึ่งปัจจุบัน
พัฒนาไปมาก โดยปัจจุบัน (2025) เป็น WI-FI7 มาตรฐาน IEEE 802.11be แต่ในปลายปี 2028 จะเปิดตัว
WIFI8 (IEEE802.11bn) คาดว่าจะมีความเร็วสูงสุด 100 Gbps (รายละเอียดจะกล่าวในบทที่ 8)

3. PPP คือ Point to Point Protocol ปัจจุบันใช้เป็น PPPoE คือ Point to Point Protocol over
Ethernet ซง่ึ พัฒนาต่อมาจาก PPP หรือ 56kb เดิม ทำให้มีความเร็วอินเทอร์เน็ตมากขึ้น และมีความปลอดภัย
มากขึ้นกว่าเดิม
ส่วนใหญ่ผู้ให้บริการอินเทอร์เน็ตจะใช้วิธีนี้ในการขายแพ็กเกจอินเทอร์เน็ตให้กับลูกค้า เพราะวิธีนี้ทำ
ลูกค้าหลายรายสามารถเชื่อมต่อกับเซิร์ฟเวอร์เดียวกันกับลูกค้ารายอื่นๆ ในการใช้บริการอินเทอร์เน็ตจาก ISP
(Internet Service Provider) ลูกค้าจะได้รับการเข้าถึงอินเทอร์เน็ตในเวลาเดียวกันแบบขนาน

ผู้ให้บริการอินเทอร์เน็ต (ISP) สามารถตั้งค่าการปล่อยสัญญาณอินเทอร์เน็ต ตามแพ็คเกจที่ลูกค้าซื้อ
ทำให้ขายแพ็คเกจได้หลายแบบ และลูกค้าก็สามารถเข้าถึงอินเทอร์เน็ตได้หลายแบบด้วยเช่นกัน
ไขข้อข้องใจ Mac Address VS IP Address
MAC Address หรือ Physical Address เป็น Address ที่ฝังมากับอุปกรณ์นั้นโดยผู้ผลิต ไม่สามารถ
เปลี่ยนเองได้ MAC Address เป็นตัวเลขขนาด 6 byte, 3 byte แรกจะได้รับการจัดสรรโดยองค์กรกลาง IEEE
ให้กับผู้ผลิตแต่ละราย ส่วนตัวเลข 3 byte หลังทางผู้ผลิตจะเป็นผู้กำหนดเอง ทำงานในเลเยอร์ที่ 2 Datalink
Layer ใน OSI Model เปรียบเหมือนเลขบัตรประจำตัวประชาชน เปลี่ยนไม่ได้!
ส่วน IP Address ย่อมาจาก Internet Protocol Address เป็นค่าที่ Network Layer กำหนดขึ้นมา
เพื่อใช้อ้างอิงถึงอุปกรณ์ต่างๆ ในขณะที่เชื่อมต่ออุปกรณ์เข้ากับระบบเครือข่าย จึงเรียกได้อีกอย่างว่าเป็น
Logical Address ทำงานในเลเยอร์ที่ 3 Network Layer ใน OSI Model เปรียบเสมือนรหัสประจำตัว
นักศึกษา/นักเรียน ถ้าย้ายสถาบันจะได้เลขใหม่ เปลี่ยนไปได้!
Logical Address หรือ IP Address จะไม่เหมือนเดิมถ้าหากนำอุปกรณ์ไปเชื่อมต่อกับ Network

### 3.6 ขั้นตอนการรับส่งข้อมูลผ่านโครงสร้างแบบทีซีพี/ไอพี

1. ที่ชั้นโปรแกรมประยุกต์ (Application Layer) จะส่งผ่านข้อมูลซึ่งก็คือโปรโทคอลที่ตนใช้งานเช่น
HTTP หรือ SMTP ผ่านไปยังลำดับชั้นต่างๆของ โครงสร้างแบบ TCP/IP

2. เริ่มต้นที่ชั้นขนส่ง (Transport Layer) ซึ่งโปรแกรมประยุกต์จะต้องกำหนดหมายเลขพอร์ต (Port
Number) ของตนว่าจะใช้หมายเลขใด เพื่อให้ข้อมูลที่ใช้รับส่งสามารถส่งถึงโปรแกรมประยุกต์ที่เรียกใช้งานได้
ถูกต้อง ที่ชั้นนี้ข้อมูลจะถูกแบ่งเป็นส่วนๆเรียกว่า “Segment” จากนั้นจะส่งผ่านไปยังชั้นเครือข่าย

3. ในชั้นเครือข่าย (Internetwork Layer) จะมีหมายเลขไอพี (IP address) เป็นที่อยู่ของอุปกรณ์
หรือเครื่องคอมพิวเตอร์ที่ใช้งานโปรแกรมประยุกต์อยู่ ข้อมูลจาก Segment จะถูกห่อหุ้มและส่งในรูปแบบของ
“Packet” โดยที่ Packet ต่างๆจะถูกกำหนดเส้นทางที่จะเริ่มต้นส่งออกไปยังระบบเครือข่าย ซึ่งข้อมูลนี้จะถูก
กำหนดอยู่ในส่วนหัวของ Packet เรียกว่า Packet Header สุดท้ายข้อมูลจะถูกส่งไปชั้นสุดท้ายคือชั้นการ
เชื่อมต่อ

4. ชั้นการเชื่อมต่อ (Link Layer) ซึ่งหมายถึงการเชื่อมต่อของ
คอมพิวเตอร์หรืออุปกรณ์ต่างๆภายในเครือข่าย โดยแต่ละจุดเชื่อมต่อจะ
เรียกว่าโหนด (Node) ข้อมูลจะอยู่ในรูปแบบ “Frame” และจะถูกส่งไป
ยังโหนดต่างๆที่มีการเชื่อมต่อจากโหนดเริ่มต้นไปยังโหนดต่อไปและต่อไป
เรื่อยๆจนกระทั่งถึงโหนดปลายทาง
สรุป โพรโตคอลต่างๆ ที่ทำงานใน OSI Model
