# บทที่ 2 ไฟล์และนามสกุลไฟล์

ไฟล์ (File) คือ ข้อมูลต่างๆ ที่ถูกจัดเก็บใน
รูปแบบดิจิทัลภายในเครื่องคอมพิวเตอร์ ข้อมูลซึ่งเก็บเป็น
ไฟล์นั้นจะมีหลายชนิด เช่น ข้อมูลประเภทเอกสาร รูปภาพ
เสียงเพลง และวีดีโอ เป็นต้น
นามสกุลไฟล์ (File Extension, File Type)
คือ การแบ่งแยกประเภทของไฟล์ที่ใช้ในคอมพิวเตอร์
โทรศัพท์ แทปเล็ต และอุปกรณ์อื่นๆ ว่าเป็นไฟล์ประเภทใด สามารถใช้แอปพลิเคชันอะไรเปิดได้บ้าง ซึ่งมีทั้งทั้ง
ไฟล์ประเภทรูปภาพ ไฟล์เอกสาร ไฟล์วิดีโอ เป็นต้น ยกตัวอย่างเช่น .docx .pdf .png และ .mp4 เป็นต้น
การเรียนรู้ หรือเข้าใจประเภทของไฟล์ต่าง ๆ ย่อมจะมีส่วนช่วยให้เราสามารถทำงานได้อย่างมีประสิทธิภาพ
มากขึ้น
โดยนามสกุลของไฟล์มีรูปแบบคือ ชื่อไฟล์(จุด)นามสกุลไฟล์ เช่น apple.jpg music.mp3 และ
musicvdo.mp4 เป็นต้น ในคอมพิวเตอร์สามารถตั้งค่าให้แสดงนามสกุลไฟล์หรือไม่แสดงก็ได้ ซึ่งค่าเริ่มต้น
ของระบบปฏิบัติกการจะปิดการแสดงนามสกุลไฟล์เพื่อง่ายต่อการใช้งานและดูสบายตา
ประเภทของไฟล์ที่เห็นกันบ่อยๆ แบ่งเป็น 4 แบบ ได้แก่ ไฟล์รูปภาพ ไฟล์เอกสาร ไฟล์บีบอัด และ
ไฟล์วิดีโอและเพลง

1\. ไฟล์รูปภาพหรือไฟล์กราฟิก
ประเภทของรูปภาพหรือไฟล์กราฟิกมี 2 ประเภท คือ

1\. ไฟล์กราฟกิ ประเภท Raster based

2\. ไฟล์กราฟกิ ประเภท Vector based
ภาพตัวอย่างของกราฟิกไฟล์ทั้งสองประเภท
ภาพขยายใหญ่ในแบบ raster
สังเกตได้ว่าภาพจะแตกเป็นเสี่ยงๆ เพราะ ว่าภาพเกิดขึ้น
จากจุดเล็กๆ มาเรียงกัน
ภาพขยายใหญ่ในแบบ vector
ภาพยังเฉียบคมแม้จะขยายเป็นพันๆ พันเท่า
ไฟลก์ ราฟิกประเภท Raster based
หรือที่เรียกกันทั่วไปว่า “bitmap” ซึ่งเกิดจากการนำเอาจุดสีเล็กๆ หลายๆ จุดมารวมกันเพื่อให้เกิดภาพ
ซึ่งจะมีความกว้างยาว X pixel และ Y pixel และความลึกคือ Z pixel

Raster Bitmap and Pixel คืออะไร?
Raster หรือที่เรียกอีกชื่อว่า Bitmap คือภาพกราฟิกรูปแบบหนึ่ง ที่เกิดจากการเรียงตัวของช่อง
สี่เหลี่ยมเล็กๆจำนวนมาก โดยใช้หลักการประมวลผลแบบอาศัยการอ่านค่าสีในแต่ละช่อง เก็บค่าข้อมูลเป็น 0
และ 1 ในแต่ละช่องจะมีคารเก็บค่าสีที่เจาะจงในแต่ละตำแหน่ง ซึ่งช่องสีเหลี่ยมนั้นเรียกว่า pixel (พิกเชล)
อธิบายง่ายๆ คือ ภาพประเภทนี้ จะประกอบด้วยจุดสีจำนวนมากที่ตายตัว เรียงตัวจนเกิดเป็นภาพที่มีความ
ละเอียดแตกต่างกันไป เหมือนกับที่เราเคยได้ยินในเรื่องของกล้อง 20 ล้านพิกเซล 26 ล้านพิกเชล ยิ่งตัวเลข
pixel มาก ภาพก็จะยิ่งมีความละเอียดสูง ซึ่งเราสามารถสังเกตเห็น pixel ได้จากการซูมรูปภาพ
ข้อดีคือ โปรแกรมสำหรับจัดการภาพประเภทนี้ มีอยู่หลากหลายและมีความเข้าใจได้ง่าย และ
นามสกุลไฟล์สามารถนำไปใช้ประโยชน์และเข้าถึงไฟล์ได้ง่าย ซึ่งไฟล์ของรูปภาพที่เกิดจากการประมวลผลแบบ
Raster จะมีนามสกุลเป็น BMP .PCX .TIF .JPG .GIF .MSP PNG .PCT จะเห็นได้ว่ามีสกุลไฟล์ที่เราคุ้นเคย
และถูกใช้อย่างแพร่หลาย ส่วนโปรแกรมจัดการภาพประเภทนี้ ได้แก่ Photoshop, Photoscape,
Lightroom, Gimp และอีกมากมาย

ถ่ายรูปโดยตรง

2) ไฟลก์ ราฟิกประเภทเวกเตอร์ (Vector based)
คือไฟล์กราฟิกที่เกิดจากการ ผลคำนวณทางคณิตศาสตร์เพื่อให้เกิดได้ทั้งภาพนิ่งและภาพเคลื่อนไหว
หรือเราจะเรียกไฟล์ชนิดนี้ได้อีกอย่างหนึ่งว่า ไฟล์ประเภท “Postscript” ไฟล์ชนิดนี้บางประเภทก็ยังสามารถ
เก็บภาพ bitmap เอาไว้ในตัวได้อีกด้วย ส่วนใหญ่แล้ว ไฟล์ประเภทเวกเตอร์นี้จะถูกแบ่งแยกโดยโปรแกรม
ประยุกต์ที่ใช้ในการแก้ไขไฟล์นั้นๆ
Vector คืออะไร
Vector คือภาพกราฟิกอีกรูปแบบหนึ่งที่โดดเด่นใช้กันอย่างแพร่หลาย เป็นภาพที่มีการประมวลผลใน
ลักษณะให้แต่ละส่วนของภาพเป็นเส้นอิสระต่อกัน โดยแยกชิ้นส่วนของภาพทั้งหมดออกเป็นรูปแบบของ
เส้นตรง รูปทรง หรือ ส่วนโค้ง โดยอาศัยการคำนวณความสัมพันธ์ทางคณิตศาสตร์ สีและตำแหน่งของสีชัดเจน
แน่นอน ไม่ว่าจะเคลื่อนย้ายหรือย่อขยายก็จะไม่เสียรูปทรงและความละเอียดของภาพ ทำให้ภาพคงคุณภาพ

2. ไฟล์เอกสาร
ไฟล์เอกสารถือเป็นหัวใจของการ
สื่อสารและจัดเก็บข้อมูลในโลกธุรกิจและ
การศึกษา ปัจจุบันมีการใช้มาตรฐานหลัก
ๆ เพื่อวัตถุประสงค์ที่แตกต่างกัน โดยมี
ไฟล์ตระกูล Open XML อย่าง DOCX,
XLSX และ PPTX ของ Microsoft ที่เน้น
การทำงานขั้นสูง และไฟล์ PDF ที่เน้นความเที่ยงตรงของการแสดงผลข้ามแพลตฟอร์ม
การทำความเข้าใจความแตกต่างของไฟล์เหล่านี้จึงสำคัญอย่างยิ่งต่อการเลือกใช้เครื่องมือที่เหมาะสม
กับภารกิจ ตัวอย่างนามสกุลไฟล์ได้แก่
ไฟล์ ชื่อเต็ม ลักษณะการใช้งาน
DOCX Document ไฟล์เอกสารมาตรฐานของ Microsoft Word ตั้งแต่ปี 2007 เป็นต้นมา รองรับ
Open XML คุณสมบัติขั้นสูง (SmartArt, Equation Editor, 3D Models) และการทำงาน
ร่วมกันบน Cloud “X” หมายถึงการใช้ XML Schema ซึ่งช่วยให้แลกเปลยี่ น
ข้อมูลกับแพลตฟอร์มอื่นได้ง่ายและมีขนาดไฟล์ที่เล็กลง
XLSX Excel Open ไฟล์ตารางข้อมูลมาตรฐานของ Microsoft Excel ตั้งแต่ปี 2007 เป็นต้นมา รองรับ
XML การคำนวณที่ซับซ้อน, Pivot Tables, Power Query, และการวิเคราะห์ข้อมลู
ขนาดใหญ่ XML Schema ช่วยให้การส่งผ่านข้อมูลระหว่างระบบมีความยืดหยุ่นสูง
PPTX PowerPoint ไฟล์นำเสนอมาตรฐานของ Microsoft PowerPoint ตั้งแต่ปี 2007 เป็นต้นมา เน้น
Open XML การนำเสนอที่มีสื่อมลั ตมิ ีเดีย (Video, Animation, Transitions) และการทำงาน
ร่วมกับ AI เช่น Copilot เพื่อช่วยสร้างสไลด ์
PDF Portable ไฟล์เอกสารข้ามแพลตฟอรม์ ที่เนน้ ความเที่ยงตรง ของการแสดงผล
Document (Preservation of Layout) ยากต่อการแก้ไขโดยไม่ตั้งใจ เหมาะสำหรับงาน
Format เอกสารทางกฎหมาย การส่งงานพิมพ์ และการเก็บถาวร (ปัจจุบันแกไ้ ขไดด้ ้วย
โปรแกรมเฉพาะทาง) รองรับการตั้งรหัสผ่านและความปลอดภัยสูง
TXT Text File ไฟล์ข้อความธรรมดา (Plain Text) ท ี่ไม่มีการจดั รูปแบบ (No Formatting) ใด ๆ
ใช้สำหรับบันทึกข้อมูลพื้นฐาน โคด้ โปรแกรม Log Files หรือการแลกเปลยี่ นข้อมูล
พื้นฐานที่ต้องใช้ความเข้ากันได้สูงสุด
Google Docs Google Drive ระบบคลาวด์เนทีฟ (Cloud-Native) ที่เน้นการทำงานร่วมกันแบบ Real-Time
(ไม่มีนามสกลุ Document โดยอัตโนมัติ ไม่ต้องกังวลเรื่องการบันทึกหรือเวอร์ชัน เป็นคู่แข่งสำคัญของ DOCX
ไฟล์) ในการทำงานร่วมกัน

ข้อแตกต่างระหว่าง doc กับ docx (หรือ xls กับ xlsx)
DOCX และ XLSX เป็นรูปแบบไฟล์ที่ใช้ใน Microsoft Office 2007 เป็นต้นมา โดยมี “X” ต่อท้าย
มาจาก XML Schema ซึ่งทำให้ไฟล์มีโครงสร้างแบบเปิด (Open Standard) ทำให้โปรแกรมอื่น ๆ สามารถ
อ่านและเข้าถึงข้อมูลภายในได้ง่ายขึ้น ตรงกันข้าม DOC และ XLS เป็นรูปแบบไฟล์ไบนารีแบบเก่าที่ใช้สำหรับ
Office 2003 และเวอร์ชันก่อนหน้า การเปลี่ยนไปใช้ XML ทำให้ไฟล์ยุคใหม่จัดการข้อมูลได้ดีขึ้นและมีขนาด
เล็กลง แต่ไฟล์ DOCX/XLSX จะเปิดได้เฉพาะในโปรแกรม Office 2007 ขึ้นไปเท่านั้น หากต้องการนำไปแก้ไข
ในเวอร์ชันเก่ากว่าจะต้องบันทึกไฟล์กลับเป็น DOC/XLS

3. ไฟล์บีบอัด
ไฟล์บีบอัด (Compression File) มีบทบาท
สำคัญในการลดขนาดไฟล์สำหรับการจัดเก็บ การ
ส่งผ่านข้อมูลทางอินเทอร์เน็ต และการรวมไฟล์หลาย
ๆ ไฟล์ไว้ในที่เดียว แม้ว่าจะมีรูปแบบไฟล์ที่เก่าแก่
อย่าง ZIP แต่ก็มีการพัฒนาเทคโนโลยีใหม่ ๆ อย่าง
ZIPX, 7Z, และ ZST ที่เน้นประสิทธิภาพการบีบอัดที่
สูงกว่า รวมถึงฟังก์ชันการตรวจสอบความถูกต้องและความปลอดภัยที่เข้มงวดมากขึ้น
ไฟล์แต่ละประเภทมีจุดเด่นและวัตถุประสงค์การใช้งานที่แตกต่างกัน ดังนี้
ชื่อเต็ม
ไฟล์ คุณสมบัติ
และผู้พัฒนา
เป็นมาตรฐานสากล ถูกรองรับโดยระบบปฏิบตั ิการทุกชนิด (Windows
.ZIP Zip Explorer, macOS Finder) โดยไม่ต้องติดตั้งโปรแกรมเสริม เข้ารหสั ด้วย
AES-128 และ AES-256 เป็นรูปแบบที่เก่าแก่และใช้งานง่ายที่สุด
ประสิทธภิ าพสูงกว่า ZIP ใช้ประโยชน์จากอัลกอริทึมที่ทันสมัยกว่าเพื่อให้
.ZIPX Zipx (Corel) ได้อัตราการบีบอดั ที่ดีกว่า ZIP ธรรมดา แตต่ ้องใช้โปรแกรมเฉพาะ เช่น
WinZip ในการสร้างและเปดิ
เน้นความเสถียร มจี ุดเด่นคือระบบตรวจสอบความผดิ พลาด (Recovery
.RAR Roshal Archive Record) และการแบ่งไฟล์ (Multi-Volume Archiving) เพื่อกู้คืนขอ้ มูล
ที่เสียหายได้ มีการเข้ารหสั AES-256
อัตราการบีบอดั สูงสดุ เป็นโอเพ่นซอร์ส เน้นการบีบอัดให้ไฟล์มีขนาดเล็ก
.7Z 7-Zip (Igor Pavlov) ที่สุด แม้จะแลกมาด้วยความเร็วในการเข้ารหสั ที่ช้าลง เป็นมาตรฐาน
Open Source และมีตัวเลือกการเข้ารหสั AES-256
มาตรฐาน Unix/Linux ใช้โดยการรวมไฟล์หลายไฟล์ด้วย TAR ก่อน แล้ว
.TAR.GZ (TGZ) Tape Archive + Gzip บีบอัดด้วย Gzip อีกที (Double Compression) นิยมใช้ในการแจกจ่าย
ซอฟต์แวร์บนระบบปฏิบตั ิการ Unix และ Linux

โคเดค (Codec)
Codec ย่อมาจาก Coder-Decoder คืออัลกอริทึมที่ใช้ในการเข้ารหัส (บีบอัด) และถอดรหัสข้อมูล
วิดีโอหรือเสียง เพื่อลดขนาดไฟล์ในการจัดเก็บหรือส่งผ่านข้อมูล ถือเป็นหัวใจสำคัญมาก ๆ ของไฟล์วิดีโอและ
เสียง เพราะเมื่อเราพูดถึงการเรียนรู้เรื่องไฟล์วิดีโอและเสียง สิ่งที่เราต้องเข้าใจถ่องแท้คือ โคเดค (Codec) ซง่ึ
จะบีบอัดข้อมูลขนาดใหญ่ให้เล็กลง เช่น จากไฟล์วิดีโอขนาด Gigabytes ให้เหลือเพียงหลัก Megabytes และ
เมื่อเปิดเล่นไฟล์ โคเดคจะถอดรหัสข้อมูลที่บีบอัดนั้นกลับมาเพื่อให้เราสามารถดูภาพและฟังเสียงได้ (ถอดรหัส
โดยใช้การประมวลผลของ CPU)
ดังนั้น หากกำลังศึกษาไฟล์วิดีโอหรือเสียงการรู้จักและเข้าใจว่าโคเดคต่าง ๆ เช่น MP3, AC-3, H.264,
หรือ HEVC ทำงานอย่างไร จึงเป็นสิ่งสำคัญที่สุด เพราะโคเดคคือตัวกำหนดคุณภาพและขนาดของไฟล์นั่นเอง

2. โคเดค (Codec ย่อมาจาก Coder-Decoder) คือ อัลกอริทึม (Algorithm) หรือ วิธีการที่ใช้ในการ
