# บทที่ 4 ซอฟต์แวร์ (Software)

ภาพจาก https://tips.thaiware.com/1322.html
ซอฟต์แวร์ คือชุดคำสั่งที่นักเขียนโปรแกรม (Programmer) เขียนขึ้นเพื่อสั่งให้ฮาร์ดแวร์ทำงาน หากไม่มี
ซอฟต์แวร์ คอมพิวเตอร์จะไม่สามารถทำงานได้เลย นอกจากนี้ซอฟต์แวร์ยังทำหน้าที่เป็นตัวเชื่อมระหว่างฮาร์ดแวร์
กับผู้ใช้งาน (User) ให้สามารถสื่อสารกันได้อีกด้วย

1\. ความหมายของซอฟต์แวร์
ซอฟต์แวร์ โปรแกรม และแอปพลิเคชั่น มีความเหมือนกันหรือแตกต่างกันดังนี้

1\. ซอฟต์แวร์ คือ คำกล่าวเรียกโดยรวมของโปรแกรมและแอปพลิเคชั่นต่างๆ

2\. โปรแกรม คือ ชุดคำสั่งซึ่งเขียน
ขึ้นมาจากภาษาคอมพิวเตอร์เพื่อให้คอมพิวเตอร์ทำงาน
ตามคำสั่งเป็นลำดับขั้นตอน โปรแกรมหนึ่งๆ อาจมีส่วน
ติดต่อกับผู้ใช้งาน (User Interface) หรือไม่มีก็ได้ บาง
โปรแกรมอาจจะทำงานในเบื้องหลัง (Background
Working) ที่ไม่ต้องติดต่อกับผู้ใช้งานเลย

3\. แอปพลิเคชันคือโปรแกรมชนิดหนึ่ง
ที่ต้องมีส่วนติดต่อกับผู้ใช้งาน (User Interface)
กล่าวคือต้องมีหน้าตาโปรแกรมให้ผู้ใช้สามารถใช้งานได้
อย่างสะดวก

2\. ส่วนติดต่อกับผู้ใช้งาน (UI : User Interface) และประสบการณ์ผู้ใช้งาน (UX: User Experience)
มีคำสองคำที่เราควรรู้จักเนื่องจากเป็นพื้นฐานในการติดต่อระหว่างคอมพิวเตอร์กับผู้ใช้ ซึ่งการพัฒนา
ซอฟต์แวร์ขึ้นมานั้นวัตถุประสงค์หลักเป็นที่แน่นอนว่า ต้องมีไว้ให้ผู้ใช้ “ใช้” โปรแกรมได้สะดวก มีประสิทธิภาพ
สวยงาม และสามารถอำนวยความสะดวกในชีวิตประจำวันแก่ผู้ใช้ได้นั่นเอง
UI: User Interface ส่วนติดต่อกับผู้ใช้งานในที่นี้ คือ ส่วนของซอฟต์แวร์ที่เปิดโอกาสให้ผู้ใช้งานได้สื่อสาร
ไปยังคอมพิวเตอร์เพื่อสั่งการให้คอมพิวเตอร์ทำงานตามความต้องการ นอกจากนี้ยังทำหน้าที่แสดงผลการปฏิบัติงาน
ความต้องการ และคำสั่ง ให้แก่ผู้ใช้งาน (User) แบ่งออกเป็น 2 ประเภทได้แก ่

1\. Command-Line Interface : CLI คือ ส่วนติดต่อกับผู้ใช้งานที่ต้องอาศัยการป้อนบรรทัดคำสั่ง
(ตัวอักษรและสัญลักษณ์ต่างๆ) ในการสั่งการคอมพิวเตอร์ การสั่งการคอมพิวเตอร์ด้วยวิธีนี้ต้องใช้
ความจำและความเข้าใจในคำสั่ง จึงจะสามารถสั่งการให้คอมพิวเตอร์ทำงานได้ ตัวอย่าง
ระบบปฏิบัติการที่ใช้ CLI ได้แก่ ระบบปฏิบัติการ MS DOS, Unix, Linux, และ Ubuntu เป็นต้น

2\. Graphic User Interface : GUI คือ ส่วนติดต่อกับผู้ใช้งานที่ใช้กราฟิก เช่น ภาพ แสง สี และเสียง
เป็นต้น ทำให้ผู้ใช้งานทั่วไปสามารถใช้งานคอมพิวเตอร์ได้ง่าย ไม่ต้องจดจำและทำความเข้าใจบรรทัด
คำสั่งอีกต่อไป เพียงแค่ใช้เมาส์ในการคลิก หรือใช้นิ้วมือในการสัมผัสหน้าจอ ก็สามารถใช้งาน
คอมพิวเตอร์หรือสมาร์ทโฟนได้แล้ว ตัวอย่างระบบปฏิบัติการที่ใช้ GUI ได้แก่ ระบบปฏิบัติการ
Windows 11, Android, iOS, macOS, Linux และ Ubuntu เป็นต้น
โดยมากแล้ว ระบบปฏิบัติการที่เป็นที่นิยม มักจะมีส่วนติดต่อกับผู้ใช้งานทั้ง 2 แบบ เพื่อรองรับการใช้งานที่
หลากหลาย เช่น ระบบปฏิบัติการ Windows, macOS, FreeBSD, Linux และ Ubuntu เป็นต้น
ส่วนติดตอ่ ผู้ใช้งานแบบ CLI : Command Line Interface ของระบบปฏิบัติการ MS DOS และ UBUNTU
สว่ นตดิ ต่อผู้ใช้งานแบบ GUI: Graphic User Interface (Windows 12)

UX: User Experience หมายถึง ประสบการณ์ของผู้ใช้งาน ซึ่งมักจะใช้คู่กับคำว่า UI เสมอ โดย UX นั้น
ออกแบบมาโดยมีวัตถุประสงค์คือ “สร้างประสบการณ์ที่ดีให้แก่ผู้ใช้ให้ได้มากที่สุด” โดยผู้ใช้เมื่อได้รับประสบการณ์
จากการใช้งานซอฟต์แวร์แล้ว มักจะแสดงออกหรือตอบสนองต่อการใช้งานซอฟต์แวร์ว่า ดี ไม่ดี ใช้ยาก ใช้ง่าย ใช้
แล้วหัวร้อน หรือใช้แล้วมีความสุข เป็นต้น
การจะพัฒนา UX ให้มีประสิทธิภาพ ในบริษัทใหญ่ๆ มักมีการวิจัยเป็นเรื่องเป็นราว รวมถึงมีแบบสอบถาม
หรือการขออนุญาตเก็บข้อมูลจากผู้ใช้ เพื่อนำไปพัฒนา UX ให้ดีที่สุด ให้ผู้ใช้สามารถใช้ซอฟต์แวร์ได้ง่ายที่สุด ดังนั้น
การจัดวางปุ่มกด การจัดวางเมนูในการเข้าใช้ การจัดหน้าเว็บแอปพลิเคชัน ต้องมีการวิจัยมาอย่างดี เพื่อให้ผู้ใช้ได้
ประสบการณ์ที่ดีที่สุด เพื่อกลุ่มเป้าหมายหรือลูกค้าจะได้เข้ามาใช้บริการบ่อยๆ จนส่งผลต่อกำไรของบริษัท

3\. ประเภทของซอฟต์แวร์
ซอฟต์แวร์นั้นแยกออกเป็น 2 ประเภทใหญ่ๆ คือ ซอฟต์แวร์ระบบ และซอฟต์แวร์ประยุกต์

1\. ซอฟต์แวร์ระบบ (System Software)
ซอฟต์แวร์ระบบ (System Software) คือ ซอฟต์แวร์ที่ควบคุมการทำงานของฮาร์ดแวร์ให้สามารถ
ตอบสนองต่อคำสั่งของผู้ใช้งานได้ ซอฟต์แวร์ระบบมีหน้าที่แตกต่างกันไป ดังนี้

### 1.1 ระบบปฏิบัติการ (OS : Operating System)

ระบบปฏิบัติการ หรือ โอเอส (OS) เป็นซอฟต์แวร์ที่ทำหน้าที่บริหารจัดการฮาร์ดแวร์และซอฟต์แวร์เพื่อให้
สามารถทำงานร่วมกันได้ ทำหน้าที่อำนวยความสะดวกให้แก่ผู้ใช้งาน (User) ในทุกๆด้าน เราอาจกล่าวได้ว่า
ระบบปฏิบัติการเป็นซอฟต์แวร์ที่มีความใกล้ชิดกับผู้ใช้ และในขณะเดียวกันก็ทำงานใกล้ชิดกับฮาร์ดแวร์ (Hardware)
และซอฟต์แวร์ประยุกต์ (App : Application) ด้วยเช่นกัน

1\. หน้าที่ของระบบปฏิบัติการ ระบบปฏิบัติ มีหน้าที่หลักที่สำคัญ ดังนี้

1\. ติดต่อกับผู้ใช้ (User Interface) ทำหน้าที่โต้ตอบกับผู้ใช้งานเพื่อให้ผู้ใช้งานป้อนคำสั่งทางคีย์บอร์ด เมาส์
หรือสั่งการด้วยวิธีการอื่น ได้แก่ การสั่งงานด้วยเสียง (Voice Control) การควบคุมจากระยะไกล (Remote Access)
และสั่งงานด้วยอุปกรณ์ไร้สาย (Wirless Device) นอกจากรับคำสั่งแล้ว ระบบปฏิบัติการยังแสดงผลการทำงานให้กับ
ผู้ใช้ทราบด้วย โดยแสดงผลออกมาในรูปแบบ เสียงเตือน ข้อความและรูปภาพ เป็นต้น

2\. ควบคุมการทำงานของซอฟต์แวร์ประยุกต์ (Application Control) ทำหน้าที่เป็นตัวกลางระหว่าง
ซอฟต์แวร์ประยุกต์กับฮาร์ดแวร์ กล่าวคือ อำนวยความสะดวกให้กับซอฟต์แวร์ประยุกต์ ทำให้ซอฟต์แวร์ประยุกต์ไม่
ต้องจัดการกับฮาร์ดแวร์ด้วยตัวเอง เพียงแค่เรียกใช้บริการจากระบบปฏิบัติการเท่านั้น ทำให้โปรแกรมเมอร์พัฒนา
ซอฟต์แวร์ประยุกต์ได้ง่ายขึ้น ส่งผลทำให้ผู้ใช้มีซอฟต์แวร์ประยุกต์ให้เลือกใช้มากขึ้น

3\. ควบคุมการทำงานของฮาร์ดแวร์ (Hardware Control) ทำหน้าที่ควบคุม ดูแล และประสานงานระหว่าง
ฮาร์ดแวร์แต่ละชิ้น เพื่อให้การทำงานของระบบเป็นไปได้อย่างถูกต้องและสอดคล้องกัน

4\. จัดสรรทรัพยากรต่างๆ ในระบบให้สามารถใช้งานร่วมกัน (Sharing Resources) ทรัพยากรสำคัญที่ต้อง
ใช้งานร่วมกันได้แก ่

1\. หน่วยประมวลผลกลาง หรือ ซีพียู (CPU: Central Processing Unit)

2\. หน่วยความจำ (Memory)

3\. อุปกรณ์รับและแสดงผลข้อมูล (Input/Output Device)
อุปกรณ์ข้างต้นมีอยู่อย่างจำกัด โดยเฉพาะซีพียู ถ้าหากโปรแกรมหลายโปรแกรมเรียกใช้ซีพียูเข้ามาพร้อมกัน
ระบบปฏิบัติการจะต้องจัดสรรคิว (Queue Manages) แบ่งเวลา (Time Slices) ให้โปรแกรมนั้นๆตามลำดับ
ความสำคัญ (Priority) และปล่อยคิวเมื่อเลิกใช้เพื่อให้โปรแกรมอื่นๆ ต่อไป ดังนั้น ถ้าระบบปฏิบัติการจัดสรร
ทรัพยากรได้ดี ก็จะทำให้ระบบคอมพิวเตอร์ทำงานได้มีประสิทธิภาพด้วย สำหรับการทำงานของซีพียูโดยละเอียดจะ
อยู่ในบททกี่ ล่าวถึงฮาร์ดแวร์ เดี๋ยวเล่าให้ฟังสนุกๆครับ
ระบบปฏิบัติการที่เป็นที่นิยมในคอมพิวเตอร์ส่วนบุคคลและในอุปกรณ์เคลื่อนที่ ได้แก่ Microsoft
Windows, MacOS, Chrome OS, iOS, Android, HarmonyOS และ Linux นอกจากนี้ ยังมีระบบปฏิบัติการ
ตระกูลยูนิกซ์ (Unix) ซึ่งได้รับความนิยมในเครื่องเซิร์ฟเวอร์ (Server) ที่ใช้กันในหน่วยงาน ระบบปฏิบัติการตระกูล
ยูนิกซ์ที่เป็นที่รู้จักกันดี ได้แก่ ยูนิกซ์ตระกูล บีเอสดี (BSD) เอไอเอกซ์ (AIX) และโซลาริส (Solaris) และรวมถึงลินุกซ์
ซึ่งพัฒนาโดยอาศัยหลักการเดียวกันกับยูนิกซ์
ในอุปกรณ์อื่นๆ ที่ควบคุมด้วยระบบคอมพิวเตอร์ ก็อาจมีระบบปฏิบัติการด้วย เช่น ระบบปฏิบัติการ Tizen
ในเครื่องใช้ไฟฟ้าตามบ้าน, tvOS ของ Apple TV, Amazon Fire TV และ Web OS ของ LG เป็นต้น

วิวัฒนาการของระบบปฏิบัติการ Windows ของบริษัท Microsoft ตั้งแต่ 1985 จนถึง 2025
2 แพลตฟอร์มของระบบปฏิบัติการ (Operating System Platform)
คำว่า Platform เป็นคำในภาษาอังกฤษ แปลว่า ฐาน หรือ แท่น
ถ้าใช้พูดถึงฮาร์ดแวร์ หมายถึง ฐานที่รองรับระบบปฏิบัติการ เช่น ฮาร์ดแวร์ในเครื่อง iMac หรือ MacBook
มีสถาปัตยกรรมเฉพาะเพื่อรองรับระบบปฏิบัติการ MacOS เท่านั้น ในขณะเดียวกัน ฮาร์ดแวร์ในคอมพิวเตอร์ส่วน
บุคคล (PC : Personal Computer) ที่มีทั่วไปในท้องตลาดมากที่สุด ก็มีสถาปัตยกรรมที่สามารถรองรับ
ระบบปฏิบัติการหลากหลาย เช่น Windows, Linux, Ubuntu, CentOS, ORACLE Linux, OpenSUSE Linux และ
Ubuntu เป็นต้น ซึ่งระบบปฏิบัติการบนพีซีทั่วไปที่ได้รับความนิยมสูงสุดได้แก่ Windows (เวอร์ชันปัจจุบันคือ
Windows 11 ส่วน 12 ยังเป็นข่าวลือว่าจะเปิดตัวในปลายปี 2025 หรือต้นปี 2026)
ใช้ถ้าพูดถึงการเล่นเกม หมายถึง ฐานที่รองรับของเกม (Game) ซึ่งก็คือเครื่องที่ใช้เล่น เช่น เครื่อง PC, PS3,
PS4 และ Xbox เกมบางเกมอาจเล่นได้เฉพาะใน Xbox หรือเกมบางเกมเล่นได้ทั้งใน PC, PS4 และ Xbox เป็นต้น
ถ้าใช้พูดถึงระบบปฏิบัติการ จะหมายถึงฐานที่รองรับซอฟต์แวร์ประยุกต์หรือแอป (Application) กล่าวคือ
แอปแต่ละแอป ต้องออกแบบมาทำงานเฉพาะเจาะจงในระบบปฏิบัติการตัวนั้น แต่ถ้าบุคคลหรือบริษัทที่พัฒนาแอป
มีความพร้อมก็สามารถพัฒนาแอปให้เข้ากับหลาย ๆ ระบบปฏิบัติการได้ เช่น แอป Microsoft Office ใช้งานใน
ระบบปฏิบัติการ Windows iOS หรือ Android ก็ได้ แอป Photoshop ใช้ในระบบปฏิบัติการ Windows หรือ

4\. Kernel และ Shell
เคอร์เนล (Kernel) ระบบปฏิบัติการ Linux

1\. CPU: Central Processing Unit

ละตัวจะใช้หน่วยประมวลผลเมื่อใด คอร์ใด เป็นต้น

2\. RAM: Random Access Memory
ทำหน้าที่ควบคุมจัดการโปรแกรมที่มาใช้แรม ซึ่งโดยปกติจะมีโปรแกรมจำนวนมากเข้ามาใช้งานตลอดเวลา
เคอร์เนลมีหน้าที่ตัดสินใจว่าหน่วยความจำส่วนไหนที่จะสามารถใช้งานได้ และควรทำอย่างไรเมื่อพื้นที่ใน
หน่วยความจำไม่เพียงพอ

3\. IO Devices (Input/Output Devices)
ทำหน้าที่ควบคุมการสื่อสารระหว่าง Application และ Hardware ที่เกี่ยวกับอุปกรณ์ I/O เช่น คีย์บอร์ด

3\. ประเภทของระบบปฏิบัติการ
ระบบปฏิบัติการแบ่งออกเป็น 4 ประเภท คือ

1\. ระบบปฏิบัติการแบบเดี่ยว (Stand-alone Operating System)
ระบบปฏิบัติการแบบเดี่ยว เป็นระบบปฏิบัติการที่ใช้กับเครื่องคอมพิวเตอร์ที่ให้บริการแก่ผู้ใช้เพียงคนเดียว
เช่น การใช้เครื่องคอมพิวเตอร์ภายในบ้าน หรือเครื่องคอมพิวเตอร์ภายในสำนักงาน ในการพิมพ์เอกสาร การดูหนัง
ฟังเพลง หรือการนำไปเชื่อมต่อระบบอินเทอร์เน็ต เป็นต้น ระบบปฏิบัติการที่นิยมใช้ เช่น Windows 11, iOS,
iPadOS, Android, ChromeOS และ macOS เป็นต้น

2\. ระบบปฏิบัติการแบบเครือข่าย (Network Operating System)
ระบบปฏิบัติการแบบเครือข่าย เป็นระบบปฏิบัติการ
ที่รองรับการทำงานของระบบเครือข่ายคอมพิวเตอร์ มีรูปแบบ

4\. คุณสมบัติการทำงานของระบบปฏิบัติการ
ระบบปฏิบัติการโดยทั่วไปจะมีคุณสมบัติในการทำงานต่างๆ ดังนี้
คุณสมบัติ ความหมาย เน้นท ี่

1\. แบบหลายผู้ใช้ อนุญาตให้ 2 คนขึ้นไปใช้โปรแกรมบนระบบเดียวกันได้พร้อมกัน การจัดการผู้ใช้ (User)
(Multi-user) (โดยเฉพาะ Mainframe หรือ Minicomputer) และทรัพยากร

2\. แบบมัลติโพรเซสซิ่ง ระบบใช้ CPU มากกว่า 1 ตัว ในการประมวลผลพร้อมกัน (Parallel การใช้ฮารด์ แวร์ (CPU)
(Multiprocessing) Processing) หลายตัว

3\. แบบมัลติทาสกิ้ง อนุญาตให้ 1 ผู้ใช้รันหลายโปรแกรมได้พร้อมกัน (โดย CPU จะแบ่งเวลา การรันโปรแกรม
(Multitasking) ทำงาน) (Process) หลายตัว

4\. แบบมัลติเทรดดิ้ง การทำงานภายใน
อนุญาตให้ส่วนย่อย (Thread) ภายในโปรแกรมเดยี วกันทำงานพร้อมกัน
(Multithreading) โปรแกรม (Thread)

5\. แบบเรียลไทม์ รับประกันการตอบสนองต่อคำสั่ง/เหตุการณ์ภายในเวลาที่กำหนดอย่าง เวลา (Time)
(Real-time) แน่นอน (Deterministic Response Time) และความแม่นยำ
คุณสมบัติเหล่านี้สามารถซ้อนทับกันได้ เช่น ระบบปฏิบัติการในปัจจุบันส่วนใหญ่จะเป็นแบบ Multitasking
และ Multithreading พร้อมกัน หรือคอมพิวเตอร์ส่วนใหญ่ (แม้แต่สมาร์ทโฟน) จะมีคุณสมบัติ Multiprocessing,
Multitasking และ Multithreading ด้วยเช่นกัน

5\. การทำงานของระบบปฏิบัติการ
เนื่องจากการทำงานของระบบ-
ปฏิบัติการ คือ การจัดการโปรแกรมต่าง ๆ ที่กำลัง
ทำงานให้มีการทำงานอย่างมีประสิทธิภาพ ซึ่ง
โปรแกรมต่างๆ ที่กำลังทำงานอยู่นั้น เรียกว่า
โพรเซส (Process)
โพรเซสแต่ละตัวจะถูกกำหนดความสำคัญ
ขึ้น (Priority) ในตอนที่โพรเซสถูกสร้างขึ้น แต่
สถานะของกระบวนการในระบบปฏิบัติการ
ความสำคัญนี้อาจเปลี่ยนแปลงได้โดยขึ้นอยู่กับ
https://www.researchgate.net/
ระบบปฏิบัติการ โพรเซสที่มีความสำคัญมากระบบปฏิบัติการจะให้สิทธิพิเศษมากกว่าโพรเซสที่มีความสำคัญน้อย
เช่น ให้เวลาในการครอบครองซีพียูได้นานขึ้น หรือว่าให้โพรเซสนั้น ๆ สามารถเข้าถึงหน่วยความจำ หรือจัดการกับ
ฮาร์ดแวร์ชิ้นไหนได้บ้าง เป็นต้น

ในขณะที่แต่ละโพรเซสกำลังทำงานอยู่ จะมีการเปลี่ยนแปลงสถานะของโพรเซสเกิดขึ้น โดยสถานะของโพ
รเซส (Process state) ที่สำคัญมี 5 สถานะ คือ5

1. สถานะสร้าง (New state) หมายถึง โพรเซสใหม่กำลังถูกสร้างขึ้นมา

2. สถานะพร้อม (Ready state) หมายถึง สถานะที่โพรเซสพร้อมจะทำงาน หากได้รับการจัดสรร
ซีพียูจากระบบปฏิบัติการ

3. สถานะการทำงาน (Running state) หมายถึง สถานะที่โพรเซสได้ครอบครองซีพียูและทำการ
ประมวลผล

4. สถานะรอ (Waiting state) หมายถึง สถานะที่โพรเซสรอเหตุการณ์บางอย่าง

5. สถานะเสร็จสิ้น (Terminate state / exit ) หมายถึง สถานะที่โพรเซสเสร็จสิ้นการทำงาน

### 1.2 ตัวแปลภาษาคอมพิวเตอร์ (Translator)

เราอาจได้เรียนรู้กันมาบ้างแล้วว่าตัวแปลภาษาทำหน้าที่แปลภาษาระดับสูง (High Level Computer
Languages) ให้เป็นภาษาเครื่อง (Machine Language) แต่ในความเป็นจริงตัวแปลภาษาไม่ได้มีหน้าที่แปลภาษา
ระดับสูงให้เป็นระดับต่ำเพียงอย่างเดียวเท่านั้น แต่ยังสามารถแปลภาษาคอมพิวเตอร์หนึ่งไปเป็นสิ่งที่มีความหมาย
เดียวกันในภาษาคอมพิวเตอร์อื่นๆได้ด้วยไม่ว่าจะเป็นภาษาระดับสูงหรือภาษาระดับต่ำ
ในการพัฒนาซอฟต์แวร์คอมพิวเตอร์นั้น นักเขียนโปรแกรม (Programmer) จะเขียนโปรแกรมด้วย
ภาษาคอมพิวเตอร์ระดับสูงหลากหลายภาษา ตามความชำนาญของแต่ละคน เช่น ภาษา C, C++, Java, Objective
C, C#, Python และ COBOL โปรแกรมที่เขียนเสร็จจะเรียกว่า ซอร์สโคด (Source Code) ซึ่งยังคงเป็นสิ่งที่มนุษย์
เข้าใจได้ แต่คอมพิวเตอร์ไม่สามารถเข้าใจได้ เพราะคอมพิวเตอร์เข้าใจเฉพาะภาษาเครื่อง (Machine Language) ที่
เป็นเลขฐานสอง (0,1) เท่านั้น จึงต้องมีตัวแปลภาษาคอมพิวเตอร์ (Translator) เพื่อแปลภาษาคอมพิวเตอร์ภาษา
ต่างๆ ให้เป็นภาษาเครื่องทคี่ อมพิวเตอร์สามารถเข้าใจได้
ตัวแปลภาษาคอมพิวเตอร์ที่สำคัญ เรียงลำดับตามความเร็วในการแปลภาษา ได้แก่

1. แอสเซมเบลอ (Assembler)
แอสเซมเบลอ เป็นตัวแปลภาษาแอสแซมบลีซึ่งเป็น
ภาษาระดับต่ำให้เป็นภาษาเครื่อง เนื่องจากเป็นภาษาระดับต่ำจึงทำ
ให้มีความเร็วในการแปลภาษามากที่สุด

2. คอมไพเลอร์ (Compiler)
คอมไพเลอร์ เป็นตัวแปลภาษาระดับสูงให้เป็นภาษาเครื่อง เช่น ภาษา C, C++, Java และ Pascal เป็นต้น
ทำงานโดยการตรวจสอบความผิดพลาดของโปรแกรม (Source Code) ตั้งแต่ต้นจนจบก่อน หากไม่พบข้อผิดพลาดก็
จะทำการแปลทั้งโปรแกรมให้เป็นออบเจกต์โค้ด .obj (Object File) จากนั้นก็ทำการแปลไฟล์ .obj ให้เป็น .exe เพื่อ
ทำงานต่อไป โดยไฟล์ .obj และ .exe ที่ได้สามารถนำไปใช้งานเมื่อใดก็ได้ตามต้องการ ไม่ต้องเสียเวลาในการแปล

3. อินเตอร์พรีเตอร์ (Interpreter)
อินเตอร์พรีเตอร์ เป็นตัวแปลภาษาระดับสูงไปเป็นภาษาเครื่อง โดยจะทำงานเป็นบรรทัดต่อบรรทัดจนจบ
โปรแกรม คือ อ่านโค้ดคำสั่งมาบรรทัดหนึ่งแล้วทำงานให้ผลออกมาทันที ทำให้การแก้ไขโปรแกรมทำได้สะดวกและ
ใช้เวลาไม่นาน แต่ข้อเสียคือจะไม่สามารถเก็บไฟล์ออกเจกต์โค้ด .obj (Object File) ไว้ใช้ใหม่ได้ ทำให้ต้อง
แปลภาษาใหม่ทุกครั้งที่รันโปรแกรม การแปลภาษาจึงช้ากว่าคอมไพเลอร์ ภาษาโปรแกรมที่ใช้การแปลภาษาแบบ
Interpreted ได้แก่ JavaScript, Lisp, Logo, Perl, PHP, Python, Smalltalk และ VBScript เป็นต้น
\*Compiler และ Interpreter ครูนพพลจะเล่าให้ฟังอย่างละเอียดในบทชื่อว่า “ภาษาที่ใช้ในการเขียนโปรแกรม” ต่อไป

### 1.3 ซอฟต์แวร์อรรถประโยชน์ (Utility Software)

ซอฟต์แวร์อรรถประโยชน์ หรือ ยูทิลิตี้ คือ เป็นซอฟต์แวร์ระบบชนิดหนึ่ง ทำหน้าที่ช่วยระบบปฏิบัติการใน
การทำงานพื้นฐาน มีคุณสมบัติการใช้งานนั้นค่อนข้างหลากหลาย ส่วนมากใช้เพื่อบำรุงรักษาและเพิ่มประสิทธิภาพ
การทำงานของคอมพิวเตอร์ เช่น ตรวจสอบ ปรับแต่ง ดูแลรักษาคอมพิวเตอร์และอุปกรณ์เคลื่อนที่ต่างๆ ให้อยู่ใน
สภาพสมบูรณ์พร้อมใช้งาน ช่วยสนับสนุน เพิ่ม หรือขยายขีดความสามารถของโปรแกรมที่ใช้งานให้มีประสิทธิภาพ
มากขึ้น โดยสามารถจัดการกับฮาร์ดแวร์ได้โดยตรง
แม้ว่าซอฟต์แวร์อรรถประโยชน์ส่วนใหญ่จะติดตั้งมาพร้อมระบบปฏิบัติการ แต่ผู้ใช้ก็สามารถติดตั้งเพิ่มเติม
ได้ด้วยตนเอง สามารถแบ่งออกได้เป็น 4 ประเภท ดังต่อไปนี้

1\. ไดร์เวอร์ (Device Drivers)
ไดร์เวอร์ คือ ซอฟต์แวร์ที่ช่วยขับเคลื่อนให้ฮาร์ดแวร์ในคอมพิวเตอร์สามารถทำงานได้อย่างเต็ม
ความสามารถ ทำหน้าที่เป็นตัวกลางในการเชื่อมต่อระหว่างฮาร์ดแวร์กับระบบปฏิบัติการ เพื่อให้ระบบปฏิบัติการ
สามารถสั่งการและใช้งานอุปกรณ์เหล่านั้นได้อย่างเต็มประสิทธิภาพ
ตัวอย่างเพื่อให้เข้าใจง่าย เช่น เมื่อผู้ใช้งานเพิ่มการ์ดจอ (Graphic Card) เข้าไปที่เครื่องคอมพิวเตอร์
ระบบปฏิบัติการรุ่นใหม่ๆ อย่าง Windows 11 สามารถสั่งการและใช้งานการ์ดจอได้ในฟังก์ชั่นการทำงานพื้นฐาน
เท่านั้น แต่จะยังไม่ทราบวิธีการใช้งานการ์ดจอนั้นให้เต็มความสามารถ ผู้ใช้จึงจำเป็นต้องติดตั้งไดร์เวอร์ของการ์ดจอ
นั้น เพื่อให้ไดร์เวอร์ทำหน้าที่แนะนำตัวเองว่ามีชื่อแซ่อะไร รุ่นไหน มีความสามารถอย่างไร พร้อมทั้งบอกวิธีใช้งาน
ตัวเองให้กับระบบปฏิบัติการได้ทราบ เมื่อระบบปฏิบัติการศึกษาและรู้จักการ์ดจอนั้นแล้ว ก็สามารถการและใช้งาน
การ์ดจออย่างถูกวิธีและเต็มความสามารถ เป็นต้น
ระบบปฏิบัติการในปัจจุบันเช่น Windows 11 มีไดร์เวอร์สำหรับอุปกรณ์พื้นฐานเก็บไว้เป็นจำนวนมาก
โดยเฉพาะผู้ผลิตฮาร์ดแวร์ยี่ห้อที่มีชื่อเสียงนั้น อุปกรณ์ส่วนใหญ่แทบไม่ต้องลงไดร์เวอร์เพิ่มเติมก็สามารถใช้งานได้ แต่
ผู้ใช้ก็มีหน้าที่สำรวจไดร์เวอร์และปรับปรุง (Update) ให้ใหม่อยู่เสมอ ปัจจุบันมีซอฟต์แวร์มากมายที่ทำหน้าที่สำรวจ
ไดร์เวอร์และแจ้งเตือนผู้ใช้ว่าควรปรับปรุงไดร์เวอร์ให้ใหม่ขึ้น

2\. ซอฟต์แวร์อรรถประโยชน์สำหรับดูแลระบบ (System Utilities)
ซอฟต์แวร์อรรถประโยชน์สำหรับดูแลระบบ คือ ซอฟต์แวร์ที่ทำหน้าที่ดูแลรักษาระบบ (System Maintain)
เชื่อมต่อเน็ตเวิร์คและอินเทอร์เน็ต (Network and Internet Connection) และจัดการกับหน่วยความจำ (Memory
Management) เช่น

1\. ไฟร์วอลล์ (Firewall) เป็นซอฟต์แวร์ที่ช่วยป้องกันบุคคลภายนอกเข้ามาในระบบโดยไม่ได้รับอนุญาต
ทั้งจากระบบเครือข่ายอินเทอร์เน็ตและเครือข่ายท้องถิ่น

2\. ซอฟต์แวร์แอนตี้ไวรัส (Anti Viruses) ทำหน้าที่สแกน (Scan) หน่วยความจำ (Memory and
Storage) ของคอมพิวเตอร์เพื่อตรวจหาและกำจัดไวรัสและภัยคุกคาม

2\. ซอฟต์แวร์จัดการคลิปบอร์ด (Clipboard managers) ช่วยในการคัดลอก (Copy) ตัด (Cut) และ
(Paste) วาง ไฟล์ต่างๆ และข้อความ

3\. ซอฟต์แวร์สำหรับตรวจสอบหน่วยความจำ (Memory testers) ช่วยในการตรวจสอบหาข้อผิดพลาด
ภายในหน่วยความจำ

4\. ซอฟต์แวร์สำหรับล้างหน่วยความจำ (Registry cleaners) ทำความสะอาดไฟล์ Registry ที่ไม่ได้ใช้งาน
แล้ว และทำให้หน่วยความจำอยู่ในสภาพสมบูรณ์พร้อมใช้งานอยู่เสมอ เช่น CCleaner เป็นต้น

5\. ซอฟต์แวร์แสดงภาพพักหน้าจอ (Screensavers) ทำหน้าที่แสดงภาพพักหน้าจอ เมื่อไม่ได้ใช้
คอมพิวเตอร์ตามระยะเวลาที่ตั้งค่าเอาไว้ ถือเป็นการช่วยรักษาความปลอดภัยและรักษาความลับ
นอกจากนี้ยังช่วยรักษาและช่วยยืดอายุการใช้งานจอภาพของคอมพิวเตอร์ด้วย

6\. ซอฟต์แวร์จัดการเครือข่าย (Network utilities) วิเคราะห์การเชื่อมต่อระบบเครือข่าย ตั้งค่าระบบ
เครือข่าย ตรวจสอบการรับส่งข้อมูล และตรวจสอบเหตุการณ์ความผิดปกติของเครือข่าย

7\. ซอฟต์แวร์สารสนเทศระบบ (System profilers) ช่วยในการตรวจสอบรายละเอียดของที่เกี่ยวข้องกับ
ซอฟต์แวร์ที่ติดตั้ง หรือฮาร์ดแวร์ที่อยู่ในคอมพิวเตอร์ เช่น CPU-Z เป็นต้น

8\. ซอฟต์แวร์ถอนการติดตั้งซอฟต์แวร์ (Uninstaller) เป็นซอฟต์แวร์ที่ใช้สำหรับยกเลิกการติดตั้ง
ซอฟต์แวร์เมื่อไม่ใช้งานแล้ว

3\. ซอฟต์แวร์อรรถประโยชน์สำหรับจัดการกับอุปกรณ์เก็บข้อมูล (Storage device management
utilities)

1\. ซอฟต์แวร์ตรวจสอบฮาร์ดดิสก์ (Disk Checkers) ตรวจสอบฮาร์ดดิสก์ว่าทำงานได้ปกติหรือไม่ มีความ
ผิดปกติทางกายภาพหรือไม่ (Bad Sector)

2\. ซอฟต์แวร์จัดเรียงข้อมูลในฮาร์ดดิสก์ (Disk defragmenters) เป็นโปรแกรมที่ใช้การจัดเรียงข้อมูลให้
เป็นระเบียบ ช่วยให้สามารถเข้าถึงข้อมูลในฮาร์ดดิสก์ได้อย่างรวดเร็ว

3\. ซอฟต์แวร์สำหรับล้างข้อมูลฮาร์ดดิสก์ (Disk formatters) ช่วยล้างข้อมูลในฮาร์ดดิสก์แบบหมดจด
เพื่อเตรียมที่จะนำฮาร์ดดิสก์ไปใช้ต่อไป หรืออาจล้างเฉพาะส่วนที่เลือกได้

4\. ซอฟต์แวร์แบ่งพื้นที่ในฮาร์ดดิสก์ (Disk partition editors) ช่วยในการแบ่งพื้นที่ในฮาร์ดดิสก์ออกเป็น
ส่วนๆ เพื่อให้ง่ายต่อการจัดการไฟล์ในเครื่อง เช่น Partition Magic เป็นต้น

4\. ซอฟต์แวร์อรรถประโยชน์สำหรับจัดการไฟล์ (File management utilities)

1\. ซอฟต์แวร์สำหรับแบ่งไฟล์ออกเป็นส่วน (Archivers) ช่วนในการแบ่งไฟล์ที่มีขนาดใหญ่เป็นส่วนๆ
เพื่อให้ง่ายต่อการอัพโหลด (Upload) สู่ระบบอินเทอร์เน็ต

2\. ซอฟต์แวร์สำรองข้อมูล (Backup software) ช่วยในการสำรองข้อมูลให้ปลอดภัย หากข้อมูลถูกทำลาย
ก็สามารถคืนค่าข้อมูลเดิมกลับมาใช้ใหม่ได้

3\. ซอฟต์แวร์สำหรับเข้ารหัสไฟล์ (Cryptographic) ช่วยในการเข้ารหัสและถอดรหัสไฟล์ เพื่อรักษาความ
ปลอดภัยของข้อมูลในกรณีที่มีข้อมูลที่เป็นความลับ

5\. ซอฟต์แวร์สำหรับบีบอัดไฟล์ (Data compression) ช่วยในการบีบอัดไฟล์ให้มีขนาดเล็กลง เพื่อช่วย
ประหยัดพื้นที่ใช้สอย หรือช่วยบีบอัดไฟล์หลายๆไฟล์เป็นไฟล์เดียว เพื่อให้เหมาะสมต่อการอัพโหลด
เข้าสู่ระบบอินเทอร์เน็ต

6\. ซอฟต์แวร์สำหรับซิงค์ข้อมู่ล (Data synchronization) ช่วยสำรองข้อมูลในคอมพิวเตอร์ให้เข้าไปสู่ที่
จัดเก็บข้อมูลในระบบอินเทอร์เน็ตโดยอัตโนมัติ เช่น Google Drive, Dropbox และ One Drive ทำ
ให้ข้อมูลทั้งในอินเทอร์เน็ต ในเครื่องคอมพิวเตอร์ หรือในอุปกรณ์เคลื่อนที่ในบัญชีผู้ใช้เดียวกัน เป็น
ข้อมูลเดียวกันทั้งหมด สามารถเข้าถึงได้จากหลากหลายอุปกรณ์ ถือเป็นความสะดวกสบายอย่างมาก
ในการรักษาไฟล์งาน รูปภาพ หรือวีดีโอที่มีความสำคัญ

2\. ซอฟต์แวร์ประยุกต์ (Application Software)
ซอฟต์แวร์ประยุกต์ (Application Software) หรือที่เราเรียกสั้นๆ
กันว่่า “แอป” คือ ซอฟต์แวร์สำหรับใช้งานด้านต่างๆ ตามที่ผู้ใช้ต้องการ
เป็นซอฟต์แวร์ที่ทำให้คอมพิวเตอร์สามารถทำงานได้หลากหลายงานและ
สามารถทำงานที่ซับซ้อนได้ โดยส่วนใหญ่แล้วระบบปฏิบัติการจะมีแอปติด
ตั้งมาให้บ้างแล้ว เช่น แอปสำหรับฟังเพลง ดูหนัง วาดรูป เกม และอื่นๆ แต่
จะไม่เพียงพอกับการทำงาน เราจึงจำเป็นต้องติดตั้งแอปเพิ่มเติมเพื่อให้
คอมพิวเตอร์หรืออุปกรณ์เคลื่อนที่ของเราสามารถทำงานได้หลากหลายมาก
ยิ่งขึ้น
คอมพิวเตอร์และอุปกรณ์เคลื่อนที่แต่ละเครื่องมักจะมีแอปที่แตกต่างกันไป เนื่องจากหน่วยงาน องค์กร หรือ
ผู้ใช้งานแต่ละคน มีภาระงานและภารกิจที่แตกต่างกัน จึงจำเป็นต้องติดตั้งแอปที่จำเป็นต่อการทำงานเพิ่มเติมด้วย

หากเราติดตั้งแอปที่ไม่ได้ใช้งานมากเกินไป อาจทำให้สิ้นเปลืองทรัพยากรของเครื่องคอมพิวเตอร์ ซึ่งมีส่วนทำให้
ระบบคอมพิวเตอร์ทำงานช้าลงด้วย ตัวอย่างแอป ได้แก่ ซอฟต์แวร์จัดการสำนักงาน (Microsoft Office หรือ
Google Workspace) ซอฟต์แวร์มัลติมีเดีย (Adobe Photoshop, Adobe Premier Pro) และซอฟต์แวร์สำหรับ
ท่องเว็บไซต์ (Web Browser) เป็นต้น
ซอฟต์แวร์ประยุกต์สามารถแบ่งออกได้เป็น 2 ประเภท ได้แก่ ซอฟต์แวร์ประยุกต์ทั่วไป (Gernaral
Purpose) และซอฟต์แวร์ประยุกต์เฉพาะงาน (Specific Purpose Application)
1 ซอฟต์แวร์ประยุกต์ทั่วไป หรือ ซอฟต์แวร์สำเร็จรูป (Gernaral Purpose Applications)
เป็นซอฟต์แวร์สำเร็จรูปที่สร้างขึ้นมาเพื่อนำไปประยุกต์ใช้ตามลักษณะงาน เช่น การดูหนังฟังเพลง การพิมพ์
การท่องเว็บไซต์ การออกแบบรูปภาพ การตัดต่อวีดีโอ และการเขียนโปรแกรมภาษาต่างๆ โดยซอฟต์แวร์ประยุกต์
ทั่วไปสามารถแบ่งได้เป็น 6 ประเภท ดังนี้

1. ซอฟต์แวร์จัดการฐานข้อมูล (Database Management Software) ทำหน้าที่สร้าง จัดการ และเรียกใช้
ข้อมูลปริมาณมากอย่างเป็นระบบ เช่น Microsoft Access OpenOffice Base, MySQL, Oracle, MongoDB,
PostgreSQL, Redis และ Amazon DynamoDB เป็นต้น ตัวอย่างซอฟต์แวร์ประเภทนี้และคำอธิบายอย่างละเอียด
ดูในเอกสารที่ 5 เรื่อง “ฐานข้อมูล”

2. ซอฟต์แวร์ประมวลผลคำ (Word Processing Software) ใช้สำหรับสร้าง แก้ไข และจัดรูปแบบเอกสาร
ข้อความ เช่น Adobe InDesign และ Microsoft Office Word, Google Document, Apache Open Office
Writer, Notion, Coda, iA Writer (เน้นการเขียน Markdown)

3. ซอฟต์แวร์ตารางคำนวณ (Spreadsheet Software) ใช้สำหรับการคำนวณ จัดการ และวิเคราะห์ข้อมูล
ในรูปแบบตาราง รวมถึงสร้างกราฟ เช่น OpenOffice Calc, Airtable, Tableau, Power BI, Microsoft Office
Excel และ Google Spreadsheet

4. ซอฟต์แวร์นำเสนอข้อมูล (Presentation Software) ใช้สำหรับสร้างสไลด์และสื่อนำเสนอเพื่อถ่ายทอด
ข้อมูลหรือความคิด เช่น Microsoft Office PowerPoint, Google Slide, Canva, Figma (ใช้สำหรับทำ
Prototype และ Presentation ได้), Prezi และ OpenOffice Impress

5. ซอฟต์แวร์ทางด้านกราฟฟิกและมัลติมีเดีย (Graphics and Multimedia Software) ใช้สำหรับสร้าง
แก้ไข และจัดการภาพนิ่ง ภาพเคลื่อนไหว หรือแบบจำลอง 3 มิต ิ รวมถึงใช้สำหรับบันทึก, แก้ไข, และผลิตสื่อวิดีโอ
และเสียง เช่น Adobe Photoshop, Ulead, Sony Vegas, VN, CapCut, Blender (3D), DaVinci Resolve (ตดั
ต่อวิดีโอระดับสูง), Midjourney, DALL-E (AI Image Generation) และ Paint เป็นต้น

6. ซอฟต์แวร์การติดต่อสื่อสารและการทำงานร่วมกัน (Communication and Collaboration Software)
ครอบคลุมโปรแกรมที่ใช้ในการท่องเว็บไซต์ การสนทนา และการประชุมทางไกล เช่น ซอฟต์แวร์ที่ใช้ในการท่อง
เว็บไซต์และซอฟต์แวร์สำหรับสนทนาออนไลน์ เช่น Google Chrome, Line, VK, Instagram, Discord (เน้นกลุ่ม
เฉพาะ), Microsoft Teams, Zoom (การประชุมทางวิดีโอ), Telegram และ Facebook Messenger เป็นต้น

1.1 การแบ่งซอฟต์แวร์ประยุกต์ทั่วไปตามเงื่อนไขการใช้งาน (Term of Uses หรือ Licenses)

1. Commercial Software คือ ซอฟต์แวร์สำเร็จรูปที่พัฒนามาเพื่อจำหน่าย หากจะใช้ต้องซื้อใบอนุญาต
ใช้งาน (License) เท่านั้น ซอฟต์แวร์ที่มีความสามารถมาก และมีความสำคัญต่อการใช้งานส่วนใหญ่เป็นซอฟต์แวร์
ประเภทนี้ เช่น Microsoft Office, Photoshop และ ProShow เป็นต้น ซอฟต์แวร์ประเภทนี้มักตกเป็นเหยื่อของ
แครกเกอร์ (Cracker) ซึ่งจะแสวงหาช่องโหว่ของซอฟต์แวร์แล้วโกงมาใช้ หรือแจกจ่ายไปตามเว็บไซต์ทั่วไปแบบฟรีๆ
ทำให้เจ้าของซอฟต์แวร์เสียหาย ทั้งนี้ ผู้ใช้ที่ดาวน์โหลดแอปที่แครกเกอร์แจกจ่าย อาจทำให้คอมพิวเตอร์เสียหายจาก
กับดักที่แครกเกอร์วางเอาไว้ เช่น การติดไวรัสคอมพิวเตอร์ และการโดนโจรกรรมข้อมูล เป็นต้น ก่อนติดตั้ง
ซอฟต์แวร์ประเภทนี้จะมี End-user license agreement (EULA) และ Terms of service agreement (TOS)
เป็นข้อตกลงการใช้โปรแกรม และถ้าเราละเมิดข้อตกลงเหล่านั้นก็ถือเป็นการทำผิดสัญญาอนุญาต หรือ ไลเซนส์ ที่
ได้รับนั่นเอง

2. Shareware คือ ซอฟต์แวร์ที่เปิดให้ทดลองใช้ก่อนตัดสินใจซื้อ สามารถใช้งานได้เรื่อยๆ เปิดให้ใช้
ความสามารถพื้นฐาน (Basic) ของซอฟต์แวร์ หรือเปิดให้เห็นฟังก์ชันการทำงานขั้นสูง (Advance) ว่าสามารถทำ
อะไรได้บ้าง แต่จะปิด (Disable) ไม่ให้ใช้ โดยมากมักจะมีโฆษณา นับถอยหลังก่อนใช้งาน หรือใส่ลายน้ำในผลงานที่
ปรากฎออกมาเพื่อเตือนว่าเรายังไม่ได้จ่ายเงินเพื่อซื้อใบอนุญาตการใช้งาน (License) ถ้าสนใจใช้ความสามารถเต็ม
รูปแบบและไม่มีโฆษณาและลายน้ำมารบกวนจิตใจ จะต้องซื้อใบอนุญาตการใช้งาน เช่นโปรแกรมตัดต่อวีดีโอใน
โทรศัพท์มือถืออย่าง VivaVideo และ KindMaster เป็นต้น

3. Trial Software คือ ซอฟต์แวร์สำหรับทดลองใช้ ซอฟท์แวร์ประเภทนี้จะใช้งานได้สมบูรณ์แบบเหมือน
Commercial Software ทุกประการ เพียงแต่จำกัดเวลาในการใช้หรือนับจำนวนครั้งในการใช้ เช่น 7 วัน 15 วัน
และ 30 วัน เป็นต้น หากผู้ใช้สนใจใช้ต่อไปก็จะต้องจ่ายเงินซื้อใบอนุญาตใช้งาน (License)

4. Demo Software จะมีลักษณะคล้ายกับ Trial Software แตกต่างกันที่ Demo Software จะถูกจำกัด
ความสามารถในการทำงาน (Function) ลงและไม่จำกัดระยะเวลาในการใช้ สมมติว่า เกมฟุตบอล Fifa2018 มีทีมให้
เลือกเล่นเพียงแค่ 4 ทีม จากทั้งหมด 200 ทีม หรือเกมปกติมี 10 ด่าน แต่ตัว Demo อาจจะออกมาให้เล่นเรียก
น้ำย่อยกันก่อนแค่ 2 ด่านแรก ถ้าหากต้องการใช้ความสามารถในการทำงานเต็มรูปแบบก็จะต้องจ่ายเงินซื้อ
ใบอนุญาตใช้งาน (License)

5. Beta Software คือซอฟต์แวร์ที่อยู่ในช่วงเริ่มต้นพัฒนาที่ปล่อยให้ผู้ใช้ทอดสอบการใช้งาน มีส่วนร่วมใน
การค้นหาข้อผิดพลาดของซอฟต์แวร์ แล้วรายงานผลการใช้งานแก่ผู้พัฒนาซอฟต์แวร์ เพื่อนำข้อผิดพลาดนั้นมา
ปรับปรุงแก้ไขซอฟต์แวร์ให้ดียิ่งขึ้น

6. Freeware คือซอฟต์แวร์ที่ให้ใช้ฟรี แต่มักจะแฝงโฆษณาหรือมีลายน้ำที่กวนใจผู้ใช้บ้างเล็กน้อยเช่น
CCleaner, FormatFactory และ GadwinPrintScreen เป็นต้น แต่ในขณะเดียวกัน บางซอฟต์แวร์ประกาศตัวเอง
เป็น Non-Commercial Freeware หมายถึง ไม่อนุญาติให้นำเอาไปใช้ในเชิงพาณิชย์ หรือการกระทำใดๆ ที่เป็นการ
แสวงผลกำไร โดยให้ใช้เฉพาะผู้ใช้ธรรมดาเช่น ครู นักศึกษา และประชาชนทั่วไปที่ไม่ได้สร้างผลงานแล้วนำไป
จำหน่าย เช่น TeamViewer และ Avast! Free Antivirus เป็นต้น

มีเหล่านักเขียนโปรแกรม (Programmer) มาช่วยกันพัฒนาต่อ

### 2.1 แพลตฟอร์มของแอปพลิเคชั่น (Application Platform)

แอปพลิเคชั่น หรือ แอป สามารถแบ่งออกเป็นประเภทย่อยๆ ตามแพลตฟอร์ม ได้แก่
– Desktop Application คือ แอปที่ทำงานบนเครื่องคอมพิวเตอร์ส่วนบุคคล เช่น Photoshop, Microsoft
Office, Safari และ Google Chrome เป็นต้น แบ่งออกได้เป็น 4 ประเภทใหญ่ๆ คือ

1\. แอปบนเครื่องพีซีที่ใช้ระบบปฏิบัติการ Windows

2\. แอปบนเครื่องพีซีที่ใช้ระบบปฏิบัติการ MacOS

3\. แอปบนเครื่องพีซีที่ใช้ระบบปฏิบัติการ Linux

4\. แอปบนเครื่องพีซีที่ใช้ระบบปฏิบัติการอื่นๆ
– Mobile Application คือ แอปที่ทำงานบนอุปกรณ์เคลื่อนที่ เช่น โทรศัพท์มือถือ แทปเล็ต
และอุปกรณ์พกพาอื่นๆ ตัวอย่างเช่น TikTok, Camera360, Facebook และ JOOX เป็นต้น แบ่งออกเป็น 3
ประเภทใหญ่ๆ คือ

2\. แอปบนอุปกรณ์พกพาที่ใช้ระบบปฏิบัติการ iOS/iPadOS

(Web Browser) ตัวอย่างเช่น Gmail, Canva, Google Docs และ Figma เป็นต้น

4\. คลาวด์คอมพิวติ้ง (Cloud Computing)
คลาวด์คอมพิวติ้ง คือ บริการประมวลผล
คอมพิวเตอร์ผ่านระบบอินเทอร์เน็ตที่ครอบคลุมถึงการ
ให้ใช้กำลังประมวลผล หน่วยจัดเก็บข้อมูล และระบบ
ออนไลน์ต่างๆจากผู้ให้บริการ ทำให้สามารถลดความ
ยุ่งยากในการติดตั้งและดูแลระบบคอมพิวเตอร์ ช่วย
ประหยัดเวลา และลดต้นทุนในการสร้างระบบ
คอมพิวเตอร์และเครือข่ายเอง
กล่าวง่ายๆ คือ คลาวด์คอมพิวติ้งคือการที่เรา
ใช้ซอฟต์แวร์ ระบบ และทรัพยากรของเครื่อง
คอมพิวเตอร์ของผู้ให้บริการผ่านทางอินเทอร์เน็ตแทน
การใช้คอมพิวเตอร์ของเราเอง โดยสามารถเลือกกำลัง
การประมวลผล เลือกจำนวนทรัพยากร ได้ตามความต้องการในการใช้งาน และให้เราสามารถเข้าถึงข้อมูลจากที่ไหน

ก็ได้โดยจะมีการสร้างระบบรักษาความปลอดภัยของข้อมูลไว้ด้วย กล่าวโดยสรุปคือ เป็นการเช่าใช้
ทรัพยากรคอมพิวเตอร์แบบจ่ายตามการใช้งาน (Pay-as-you-go) แทนการซื้อและเป็นเจ้าของนั่นเอง
จากภาพด้านบนนี้ จะเห็นว่าด้านในของกรอบที่เป็นก้อนเมฆก็คือทรัพยากรของผู้ให้บริการที่มีทั้ง
Hardware และ Software เราเองซึ่งเป็นผู้ใช้บริการเพียงแค่ต่อเชื่อมเข้าไปใช้ด้วยเว็บบราวเซอร์
หรือบนอุปกรณ์ต่างๆของตน เช่น สมาร์ทโฟนหรือแทปเล็ต เป็นต้น ก็สามารถเข้าใช้งานได้แล้ว

### 3.1 ข้อดีของการใช้ระบบคลาวด์คอมพิวติ้ง

1. ไม่ต้องลงทุนซื้อฮาร์ดแวร์หรือซอฟต์แวร์ทั้งระบบ กล่าวคือ ลงทุนซื้อเครื่องคอมพิวเตอร์ราคาถูกมา
ใช้งานแทนที่จะต้องซื้อคอมพิวเตอร์ราคาแพงเพื่อทำระบบ

2. ไม่ต้องดูแลระบบเอง ทำให้ประหยัดค่าใช้จ่ายมาก

3. ทุกคน (ที่ได้รับอนุญาต) สามารถเข้าถึงข้อมูลได้จากอินเทอร์เน็ต

4. จ่ายเงินตามจริงที่ใช้งานระบบ เราสามารถเลือกศักยภาพในการประมวลผลและเลือกขนาดพื้นที่
จัดเก็บข้อมูล เท่าที่เราใช้ หากต้องการขยายศักยภาพและพื้นที่จัดเก็บข้อมูลก็สามารถจ่ายเพิ่มได้เลย
ไม่ต้องทำระบบใหม่และไม่ต้องซื้ออุปกรณ์ใหม่
ดังนั้น ในปัจจุบันจึงมีหลากหลายหน่วยงานทั้งขนาดเล็กและขนาดใหญ่ที่เลือกใช้คลาวด์คอมพิวติ้ง เพื่อลด
ต้นทุนในการทำงาน แต่ประสิทธิภาพในการทำงานไม่ได้ลดลง จึงสามารถทำตามเป้าหมายขององค์กรโดยไม่ต้อง
คำนึงถึงถึงปัญหาและการดูแลระบบคอมพิวเตอร์อีกต่อไป

### 3.2 ประเภทของบริการคลาวด์คอมพิวติ้ง (Cloud Computing Service Models)

บริการของคลาวด์คอมพิวติ้ง แยกออกเป็นหลัก ๆ ได้ 3 บริการ คือ

1. Software as a Service (SaaS) คือ การใช้หรือให้เช่าใช้บริการซอฟต์แวร์ประยุกต์
(Application) ผ่านอินเทอร์เน็ต ส่วนใหญ่เป็นซอฟต์แวร์เฉพาะด้าน โดยประมวลผลบนระบบของ
ผู้ให้บริการ ผู้ใช้จะไม่มี Control ในการใช้งานเท่าไหร่ คือสามารถใช้งานได้เท่าที่ระบบกำหนดไว้
เท่านั้น ตัวอย่างเช่น Google Apps, Microsoft Office 365, More+, iCloud, Dropbox,
Mindmeister และ Canva เป็นต้น ซึ่งผู้ใช้สามารถเข้าใช้ระบบเหล่านี้โดยไม่ต้องติดตั้งอะไรบน
เครื่องคอมพิวเตอร์เลยแม้แต่น้อย เพียงแค่เข้าเว็บ หรือแอปพลิเคชัน จากนั้นก็ Login และใช้งาน
ได้เลย

2. Platform as a Service (PaaS) คือ การใช้หรือให้เช่าระบบฐานข้อมูล, Web Server, Runtime,
Software Library, Frameworks ต่างๆ โดยผู้ให้บริการจะเตรียมระบบพื้นฐานทั้ง Hardware,
Software, และชุดคำสั่งไว้บริการ ซึ่งทำให้สามารถพัฒนาซอฟต์แวร์ประยุกต์ (Application) ที่
ให้บริการคนทั่วทุกมุมโลกได้ในระยะเวลาเพียงสั้นๆ ตัวอย่างเช่น Google App Engine (GAE),

AWS Lambda (Serverless Compute), Microsoft Azure App Service และ Heroku เป็นต้น
ถือว่าเป็นรูปแบบของคลาวด์คอมพิวติ้งที่ซับซ้อนขึ้นมาเล็กน้อย เพราะจะเหมาะสำหรับนักพัฒนา
หรือ Developer ไว้ใช้สำหรับพัฒนาโปรแกรม หรือแอปพลิเคชัน ซึ่งผู้ให้บริการ PaaS ก็จะมีระบบ
รองรับ Software, Hardware และระบบคำสั่งอื่นๆ ที่จำเป็น ทำให้การพัฒนานั้นเป็นไปได้ง่าย
และมีประสิทธิภาพยิ่งขึ้น ผู้ใช้งานสามารถมี Control ในการแก้ไข พัฒนา ระบบได้มากขึ้น

3\. Infrastructure as a Service (IaaS) คือ การบริการโครงสร้างพื้นฐานทางคอมพิวเตอร์ โดยจะ
ครอบคลุมถึง CPU , RAM , DISK , Network , Server และ OS ตัวอย่างเช่น Amazon EC2
(AWS), Google Compute Engine (GCE), Microsoft Azure VMs และ DigitalOcean เป็นต้น
โดยการใช้งานก็จะรวมไปถึงด้าน Architecture, Migration หรือการย้ายข้อมูล IaaS จะค่อนข้างมี
ความยืดหยุ่นในการใช้งาน ผู้ใช้งานจะมีความสามารถในการ Control สูง สามารถขยายได้ตาม
ต้องการ
จากภาพจะสังเกตได้ว่า
IaaS นั้นผู้ใช้บริการจะเสียค่าใช้จ่าย
มากกว่าแบบอื่น เนื่องจากมี Service
ที่ผู้ใช้สามารถปรับแต่งเองได้ถึง 4
อย่างคือ ข้อมูล แอปพลิเคชัน รัน
ไทม์ และระบบปฏิบัติการ
ในขณะที่ PaaS ซึ่งเป็นการ
ให้บริการแพลตฟอร์มสำหรับพัฒนา
โปรแกรมประยุกต์ไว้ให้บริการได้
กว้างในระดับโลก ลูกค้าหรือผู้ใช้
สามารถปรับแต่งได้ 2 อย่างคือ ข้อมูลและแอปพลิเคชัน
สุดท้ายที่ SaaS หน่วยที่เล็กที่สุด จะให้บริการด้านข้อมูลโดยไม่ได้ยุ่งเกี่ยวกับระบบใดๆ คือ ผู้ใช้มีหน้าที่ใช้
อย่างเดียว จัดการกับข้อมูลต่างๆ ไม่ต้องยุ่งกับระบบหลังบ้าน เช่น การใช้บริการแต่งภาพด้วย CANVA, บริการสังคม
ออนไลน์ Facebook บริการเก็บข้อมูลด้วย Dropbox และ ค้นหาข้อมูลด้วย Google เป็นต้น
นอกจากนี้ยังสามารถแบ่ง Cloud ตามเกณฑ์รูปแบบการเป็นเจ้าของ (Ownership) และการเข้าถึง
ทรัพยากร (Access and Sharing) ได้ดังนี้คือ

1\. Public Cloud (คลาวด์สาธารณะ) ทรัพยากร (เช่น เซิร์ฟเวอร์ ที่เก็บข้อมูล) ถูกเจ้าของภายนอก
(Third-party provider) อย่าง AWS, Azure และ Google เป็นผู้ดูแลและบริหารจัดการ โดยจะแบ่งปัน
ทรัพยากร (Multi-tenant) ให้กับผู้ใช้และองค์กรจำนวนมากผ่านทางอินเทอร์เน็ต จุดเด่น คือ ความยืดหยุ่น
สูง (Scalability) ราคาถูก และไม่ต้องลงทุนด้านโครงสร้างพื้นฐานล่วงหน้า

2\. Private Cloud (คลาวด์ส่วนตัว) โครงสร้างพื้นฐานเป็นกรรมสิทธิ์และใช้งานสำหรับองค์กรเดียว
(Single-tenant) เท่านั้น สามารถตั้งอยู่ในศูนย์ข้อมูลขององค์กรเอง (On-premises) หรือให้ผู้ให้บริการ
ภายนอกดูแลให้ก็ได้ จุดเด่นคือ มีการควบคุม และดูแลความปลอดภัยของข้อมูลสูงสุด เหมาะสำหรับข้อมูล
ที่อ่อนไหวหรืออยู่ภายใต้ข้อกำหนดที่เข้มงวด

3\. Hybrid Cloud (คลาวด์แบบผสมผสาน) เป็นการรวมกันระหว่าง Private Cloud (สำหรับงาน
หลักที่อ่อนไหว) และ Public Cloud (สำหรับงานที่ต้องการความยืดหยุ่นหรือการประมวลผลตามความ
ต้องการ) โดยอนุญาตให้ถ่ายโอนข้อมูลและแอปพลิเคชันระหว่างสภาพแวดล้อมทั้งสองได้อย่างราบรื่น
จุดเด่นคือได้รับประโยชน์ทั้งด้านความปลอดภัยและการควบคุม (จาก Private) และความยืดหยุ่นและคุ้มค่า
(จาก Public) เป็นรูปแบบการใช้งานที่ได้รับความนิยมสูงสุดในระดับองค์กรเนื่องจากสามารถจัดสรรภาระ
งานให้เหมาะสมกับลักษณะงานได้

5\. มัลแวร์ (Malware) 7
Malicious Software หรือที่เรารู้จักกันว่ามัลแวร์ (Malware) เป็นชื่อเรียกโดยรวมของเหล่าโปรแกรม
คอมพิวเตอร์ทุกชนิดที่ถูกออกแบบมาเพื่อมุ่งร้ายต่อคอมพิวเตอร์และเครือข่าย ไม่ว่าจะเป็น Virus, Worm, Trojan,
Spyware, Keylogger, Downloader, Adware, Dialer, Hijacker, BHO, Toolbar บางอย่าง, Hack Tool,
Phishing, รวมไปถึง Zombie network และ Zero-day attack เป็นต้น
ลักษณะและพฤติกรรมการทำงานของมัลแวร์ในแต่ละประเภท
Virus: คือ โปรแกรมชนิดหนึ่งที่มีความสามารถในการสำเนา
ตัวเองเข้าไปติดอยู่ในเครื่องคอมพิวเตอร์มักจะแฝงตัวมากับโปรแกรม
คอมพิวเตอร์หรือไฟล์และสามารถแพร่กระจายไปยังเครื่องอื่น ๆ ได้โดย
แนบตัวเองไปกับโปรแกรมหรือไฟล์ดังกล่าว แต่ไวรัสจะทำงานก็ต่อเมื่อ
มีการรันโปรแกรมหรือเปิดไฟล์เท่านั้น จุดประสงค์การทำงานของไวรัส
แต่ละตัวขึ้นอยู่กับผู้เขียนโปรแกรมไวรัสนั้น เช่น อาจสร้างไวรัสให้ไป
ทำลายโปรแกรมหรือข้อมูลอื่นๆ ที่อยู่ในเครื่องคอมพิวเตอร์ หรือแสดง
ข้อความวิ่งไปมาบนหน้าจอคอมพิวเตอร์ เป็นต้น

Worm: มีลักษณะและพฤติกรรมคัดลอกตัวเองและสามารถส่งตัวเองไปยังคอมพิวเตอร์เครื่องอื่นๆได้อย่าง
อิสระ โดยอาศัยอีเมล์หรือช่องโหว่ของระบบปฏิบัติการ มักจะไม่แพร่เชื้อไปติดไฟล์อื่น สิ่งที่มันทำคือมักจะสร้างความ
เสียหายให้กับระบบเครือข่าย และเหมือนจะสร้างความเสียหายให้กับระบบเศรษฐกิจมากที่สุด
Trojan: หลอกล่อผู้ใช้ว่าเป็นโปรแกรมที่ปลอดภัย แต่จริง ๆ แล้วจะทำให้เกิดความเสียหายเมื่อผู้ใช้
หลงเชื่อนำไปติดตั้ง โดยที่ผู้ใช้ไม่รู้ตัวว่ามีโปรแกรมอื่นที่อันตรายแฝงตัวมาด้วย ถือเป็นมัลแวร์อีกชนิดที่พบเห็นการ
แพร่ระบาดได้ทั่วไป มีลักษณะและพฤติกรรมไม่แพร่เชื้อไปติดไฟล์อื่นๆ ไม่สามารถส่งตัวเองไปยังคอมพิวเตอร์เครื่อง
อื่นๆได้ ต้องอาศัยการหลอกผู้ใช้ให้ดาวน์โหลดเอาไปไว้ในเครื่องหรือด้วยวิธีอื่นๆ สิ่งที่มันทำคือเปิดโอกาสให้ผู้ไม่
ประสงค์ดีเข้ามาควบคุมเครื่องที่ติดเชื้อจากระยะไกล ซึ่งจะทำอะไรก็ได้ หรือมีจุดประสงค์เพื่อล้วงเอาความลับ

Backdoor: เปิดช่องทางให้ผู้อื่นเข้ามาใช้งานเครื่องคอมพิวเตอร์ของเราโดยไม่รู้ตัว
Rootkit: เปิดช่องทางให้ผู้อื่นเข้ามาติดตั้งโปรแกรมเพิ่มเติมเพื่อควบคุมเครื่อง พร้อมได้สิทธิ์ของ
ผู้ดูแลระบบ (Root)
Spyware: แอบดูพฤติกรรมและบันทึกการใช้งานของผู้ใช้ และอาจขโมยข้อมูลส่วนตัว เช่น บัญชี
ชื่อผู้ใช้งาน, รหัสผ่าน หรือข้อมูลทางการเงิน เป็นต้น พร้อมทั้งส่งข้อมูลดังกล่าวไปในเครื่องปลายทางที่ได้
ระบุเอาไว้อีกด้วย
Ransomware: ทำการเข้ารหัสหรือล็อกไฟล์ ผู้ใช้จะไม่สามารถเปิดไฟล์หรือคอมพิวเตอร์ได้

มาตรการป้องกันภัยจาก Malware

1\.  ต้องติดตั้งแพตช์ (Patch) และอัปเดตระบบปฏิบัติการ (OS) และแอปพลิเคชันทั้งหมดให้เป็นเวอร์ชันล่าสุด
อยู่เสมอ เพื่อปิดช่องโหว่ (Vulnerabilities) ของระบบ

2\.  ติดตั้งและเปิดใช้งานโปรแกรมป้องกันมัลแวร์ (Antivirus/Anti-malware) และไฟร์วอลล์ (Firewall) ที่
ทันสมัยและหมั่นสแกนระบบเป็นประจำ

3\. ตั้งรหัสผ่านที่คาดเดายาก (ยาว ผสมตัวอักษร ตัวเลขและสัญลักษณ์) และไม่ใช้รหัสผ่านซ้ำในหลายบัญชี
พร้อมเปิดใช้งานการยืนยันตัวตนแบบสองชั้น (2FA)

4\. สำรองข้อมูลสำคัญไปยังที่จัดเก็บภายนอกหรือระบบคลาวด์แยกต่างหาก และตรวจสอบให้แน่ใจว่าข้อมูลที่
สำรองมานั้นใช้การได้ เพื่อป้องกันความเสียหายจาก Ransomware หรือข้อมูลสูญหาย

5\. ตรวจสอบแหล่งที่มาของอีเมล ลิงก ์ และไฟล์ที่แนบมาเสมอ ไม่เปิดหรือดาวน์โหลดไฟล์จากแหล่งที่ไม่
น่าเชื่อถือ และระวังเทคนิค Phishing (การหลอกลวง) จากเหล่าสแกมเมอร์ (Scammer) ที่มีเทคนิคการ
หลอกลวงที่แพรวพราวมากในปัจจุบัน

6\. ไม่ควรใช้งานคอมพิวเตอร์ด้วยบัญชีผู้ดูแลระบบ (Administrator) ในชีวิตประจำวัน และจำกัดสิทธิ์ของ
โปรแกรมไม่ให้เข้าถึงข้อมูลสำคัญโดยไม่จำเป็น

7\. หลีกเลี่ยงการทำธุรกรรมสำคัญบนเครือข่าย Wi-Fi สาธารณะ หรือเลือกใช้ Virtual Private Network
(VPN) เพื่อเข้ารหัสการเชื่อมต่อ

8\. ดาวน์โหลดแอปพลิเคชันจากแหล่งที่มาอย่างเป็นทางการเท่านั้น (เช่น App Store, Play Store, เว็บไซต์
ผู้ผลิต) เพื่อหลีกเลี่ยงโทรจันและมัลแวร์แฝง

6\. Virtual Computer หรือ Virtual Machine (VM)
Virtual Computer หรือ Virtual Machine (VM) คือการจำลองคอมพิวเตอร์หนึ่งเครื่องขึ้นมาภายในระบบ
คอมพิวเตอร์จริง เพื่อให้สามารถรันระบบปฏิบัติการ (Operating System) และซอฟต์แวร์ต่าง ๆ ได้เหมือนกับการ
ทำงานบนคอมพิวเตอร์จริง

1\. คำนิยามและหลักการ
Virtualization คือ เทคนิคทางซอฟต์แวร์ที่ใช้ในการสร้างสภาพแวดล้อมจำลอง (Virtual Environment)
หรือทรัพยากรเสมือนจริง (Virtual Resources) ขึ้นมาบนฮาร์ดแวร์จริง (Physical Hardware) เพียงชุดเดียว โดยมี
เป้าหมายเพื่อเพิ่มประสิทธิภาพการใช้งานทรัพยากรและลดต้นทุน
Virtual Machine (VM) หรือ คอมพิวเตอร์เสมือน คือ เครื่องคอมพิวเตอร์จำลองที่สมบูรณ์แบบ ซึ่งมี
ระบบปฏิบัติการ (Guest OS) ทรัพยากร เช่น CPU RAM หรือ Disk และการตั้งค่าของตัวเองแยกต่างหาก โดย
ทั้งหมดนี้ถูกจำลองและทำงานอยู่บนเครื่องฮาร์ดแวร์จริงเพียงเครื่องเดียว

Hypervisor คือ ซอฟต์แวร์ระบบ (System Software) ที่ทำหน้าที่เป็นชั้นสื่อกลางในการจัดการ (Manage)
และจัดสรร (Allocate) ทรัพยากรฮาร์ดแวร์จริง เช่น CPU RAM หรือ Network ให้กับ Virtual Machine (VM)
ต่างๆ ที่ทำงานอยู่เหนือมัน

2. ประเภทของ Hypervisor
Hypervisor เป็นกุญแจสำคัญในการสร้าง Virtualization โดยแบ่งออกเป็น 2 ประเภทหลัก ตามลักษณะ
การติดตั้งและการทำงาน
2.1. Type 1 Hypervisor (Bare Metal) ติดตั้งและทำงานโดยตรงบนฮาร์ดแวร์ของเซิร์ฟเวอร์
กายภาพ (Host Hardware) โดยไม่มีระบบปฏิบัติการหลัก (Host OS) ขั้นกลาง จุดเด่นคือมีประสิทธิภาพ
สูงกว่า มีความเสถียรและความปลอดภัยสูง เหมาะสำหรับใช้งานในระดับองค์กรและศูนย์ข้อมูล (Data
Center) ข้อเสียคือความซับซ้อนในการติดตั้งและจัดการ (Complex Setup) และความเข้ากันได้ของ
ฮาร์ดแวร์ (Hardware Compatibility) กับซอฟต์แวร์ ตัวอย่างซอฟต์แวร์ได้แก่ VMware ESXi, Microsoft
Hyper-V และ KVM

2.2. Type 2 Hypervisor (Hosted) ติดตั้งและทำงานบนระบบปฏิบัติการหลัก (Host OS) อีกที
หนึ่ง Hypervisor จึงเป็นเหมือนแอปพลิเคชันหนึ่งบน Windows, macOS, หรือ Linux จุดเด่นคือใช้งาน
ง่าย เหมาะสำหรับการทดสอบ การพัฒนาซอฟต์แวร์ และการใช้งานส่วนบุคคล ส่วนข้อเสียคือประสิทธิภาพ
ต่ำกว่า (Lower Performance) และความเสถียรต่ำและความเสี่ยงด้านความปลอดภัยสูงกว่า (Lower
Stability & Security) ตัวอย่างการใช้งานเช่น Oracle VirtualBox และ VMware Workstation

3\. ประเภทและการใช้งาน Virtualization
เนื่องจากงานราชการมักเน้นการบริหารจัดการระบบและข้อมูล จึงควรรู้จักประเภทหลัก ๆ ที่ใช้ในองค์กร
ดังต่อไปนี้
ประเภท ชื่อเรียกภาษาอังกฤษ หน้าที่และวัตถุประสงค ์
แบ่งเซิร์ฟเวอร์กายภาพ 1 เครื่อง ให้เป็นเซิร์ฟเวอร์เสมือน

1\. เซิร์ฟเวอร์เสมือน Server Virtualization
หลายเครื่องเพื่อลดจำนวนฮาร์ดแวร์
จำลองเดสก์ท็อปผู้ใช้งานให้อยู่บนศูนย์ข้อมูล ทำให้ผู้ใช้

2\. เดสก์ท็อปเสมือน Desktop Virtualization (VDI) สามารถเข้าถึงหน้าจอทำงานจากอุปกรณ์ใดกไ็ ด้ (สำคญั
สำหรับงานสำนักงาน)
รวมพื้นที่จัดเก็บข้อมลู จากหลายแหล่งให้เป็นหน่วยจดั เก็บ

3\. คลังข้อมูลเสมือน Storage Virtualization
เสมือนหน่วยเดียวเพื่อง่ายต่อการบริหารจดั การ
สร้างเครือข่ายจำลองบนโครงสร้างเครือข่ายจริง เพื่อ

4\. เครือข่ายเสมือน Network Virtualization
แบ่งแยกการจราจรและเพิ่มความยืดหยุ่น

1\. เซิร์ฟเวอร์เสมือน (Server Virtualization)
คือการใช้ Hypervisor เพื่อแบ่งทรัพยากรของเซิร์ฟเวอร์กายภาพ (Physical Server) ประสิทธิภาพสูง 1
เครื่อง ให้สามารถรันเซิร์ฟเวอร์เสมือน (VMs) ได้หลายตัว แต่
ละ VM ทำงานแยกจากกันได้อย่างสมบูรณ์ มีระบบปฏิบัติการ
และแอปพลิเคชันเป็นของตัวเอง ทำให้สามารถลดจำนวน
ฮาร์ดแวร์ เพราะไม่ต้องซื้อเซิร์ฟเวอร์จริงหลายเครื่อง (Server
Consolidation) ประหยัดพลังงาน/พื้นที่ ทำให้ลดค่าใช้จ่าย
ด้านพลังงานและการใช้พื้นที่ในศูนย์ข้อมูล และเพิ่ม
ประสิทธิภาพทำให้การใช้ทรัพยากรของเซิร์ฟเวอร์จริงเป็นไป
อย่างเต็มท ี่

2\. เดสก์ท็อปเสมือน (Desktop Virtualization - VDI)
คือการจำลองสภาพแวดล้อม
เดสก์ท็อป (Desktop) ของผู้ใช้งาน ทั้ง
OS แอปพลิเคชัน และข้อมูล ให้อยู่บน
ศูนย์ข้อมูล (Data Center) ส่วนกลาง
ผู้ใช้จะเข้าถึงหน้าจอทำ งานเสมือนนี้
ผ่านอุปกรณ์ต่าง ๆ เช่น คอมพิวเตอร์
Thin Client แท็บเล็ต หรือสมาร์ทโฟน
ทำให้สามารถบริหารจัดการจากศูนย์กลางได้ ผู้ดูแลระบบสามารถจัดการ อัปเดต ติดตั้งโปรแกรม และแก้ไขปัญหา
เครื่องคอมพิวเตอร์ของผู้ใช้ทุกคนได้จากที่เดียว มีความปลอดภัยของข้อมูล เพราะข้อมูลทั้งหมดถูกเก็บไว้ที่ศูนย์
ข้อมูล ไม่ได้เก็บไว้บนอุปกรณ์ปลายทาง ทำให้ข้อมูลปลอดภัยหากอุปกรณ์สูญหาย ช่วยให้เจ้าหน้าที่รัฐหรือพนักงาน
สามารถทำงานจากระยะไกล (Work From Anywhere) ได้อย่างปลอดภัยและมีประสิทธิภาพ

3\. คลังข้อมูลเสมือน (Storage Virtualization)
เป็นการรวมพื้นที่จัดเก็บข้อมูล (Pooling) จากอุปกรณ์จัดเก็บข้อมูลทางกายภาพหลายแหล่ง เช่น Hard
Disks SAN หรือ NAS ให้กลายเป็นคลังข้อมูลเสมือน (Virtual Storage) ก้อนเดียว การใช้งานคือระบบปฏิบัติการ
และแอปพลิเคชันจะมองเห็นและใช้งานคลังข้อมูลเสมือนนี้ โดยไม่จำเป็นต้องรู้ว่าข้อมูลจริงถูกเก็บไว้บนอุปกรณ์

กายภาพใด (ข้อมูลจริงๆ อยู่ที่ไหน) ประโยชน์คือ ง่ายต่อการบริหารจัดการ เพราะผู้ดูแลระบบจัดการพื้นที่ได้ง่ายขึ้น
และมีความยืดหยุ่นในการเพิ่มหรือลดขนาดพื้นที่จัดเก็บ เพิ่มความต่อเนื่องทางธุรกิจเพราะช่วยให้การสำรองและกู้
คืนข้อมูลทำได้ง่ายและรวดเร็ว

4. เครือข่ายเสมือน (Network Virtualization)
คือการสร้างเครือข่ายจำลอง (Virtual
Network) ขึ้น มาบนโครงสร้างเครือข่ายทาง
กายภาพ (Physical Network) เดียวกัน โดยใช้
ซอฟต์แวร์ในการแบ่งแยกและกำหนดค่าการ
เชื่อมต่อ (Software-Defined Networking: SDN)
การใช้งานคือสามารถแบ่งแยกการจราจร (Traffic
Isolation) เพื่อสร้างเครือข่ายที่แตกต่างกันบนสาย
เคเบิลเดียวกัน เช่น สร้างเครือข่ายสำหรับระบบ
Production แยกจากเครือข่ายสำหรับระบบ
Testing ประโยชน์ที่สำคัญคือ ทำให้สามารถ
แบ่งแยกการจราจร (Segmentation) เพื่อเพิ่ม
ความมั่นคงปลอดภัยให้กับข้อมูล โดยการแยก
เครือข่ายระบบสำคัญออกจากเครือข่ายทั่วไป และ
เพิ่มความยืดหยุ่นของระบบ ช่วยให้การปรับเปลี่ยน
โครงสร้างเครือข่ายทำได้รวดเร็วผ่านซอฟต์แวรโ์ ดย
ไม่ต้องยุ่งกับฮาร์ดแวร์จริง
