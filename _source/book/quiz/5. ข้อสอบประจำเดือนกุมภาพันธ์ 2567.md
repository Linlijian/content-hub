56. ระบบปฏิบัติการบนสมาร์ทโฟนในข้อใดนิยมใช้งานมากที่สุดในปี 2023 ก. Android ข. iOS ค. Harmony OS ง. Symbian

57. ข้อใดคือระบบปฏิบัติการแบบฝัง (Embedded OS) ก. Windows 11 ข. iOS และ iPadOS ค. Linux ง. CentOS

58. ระบบปฏิบัติการที่มีคุณสมบัติ Multitasking ได้แก่ระบบปฏิบัติการที่มีลักษณะตามข้อใด ก. สามารถรองรับการทำงานได้หลายโปรแกรมในเวลาเดียวกัน ข. รองรับผู้ใช้ให้ทำงานได้หลายคนพร้อมกัน ค. ตอบสนองได้ทันทีทันใด ง. สามารถใช้ CPU มากกว่า 1 ตัว ในการประมวลผล

59. Disk Defragmenter คือโปรแกรมจัดเรียงข้อมูลใน Hard Disk ให้เป็นระเบียบเรียบร้อย ทำให้ สามารถเข้าถึงข้อมูลได้เร็ว ส่งผลให้ระบบการทำงานของคอมพิวเตอร์โดยภาพรวมเร็วขึ้น เป็น โปรแกรมประเภทใด ก. Utility Program ข. Beta Software ค. Operating System ง. Device Driver

60. Open Source Software หมายความตามข้อใด ก. เปิดเผยรายละเอียดของผู้ใช้ ข. เปิดเผยรหัสต้นฉบับให้กับบุคคลที่สนใจพัฒนาซอฟต์แวร์ร่วมกัน ค. โปรแกรมให้ใช้งานฟรี ง. โปรแกรมที่เปิดขายให้กับบุคคลทั่วไปเพื่อซื้อและนำไปใช้งานตามวัตถุประสงค์ของตนเอง

61. ข้อใดไม่ใช่องค์ประกอบของการสื่อสาร ก. Sender ข. Repeater ค. Protocol ง. Message

62. ทิศทางการส่งข้อมูลแบบทิศทางเดียว (Simplex Transmission) มีลักษณะตามข้อใด ก. ส่งไป ไม่ต้องรอการตอบกลับ ข. ส่ง-รับข้อมูล สลับกันไปมา ค. ส่ง-รับข้อมูลในเวลาเดียวกัน ง. ส่งและรอการซิงค์ข้อมูลให้ตรงกันระหว่างต้นทางและปลายทาง

63. สัญญาณในข้อใดมีลักษณะคล้ายคลื่น (Sine Wave) ก. Digital ข. Analog

64. แอปพลิเคชันต่างๆ ที่สามารถเชื่อมต่อกับเครือข่ายภายนอก ทำงานใน Layer ใดของ OSI Model ก. 7 ข. 1 ค. 4 ง. 5

65. เลเยอร์ใดของ OSI Model ที่มีหน้าที่แปลงข้อมูล เข้ารหัสข้อมูล และบีบอัดข้อมูล ก. 7 ข. 6 ค. 5 ง. 4

66. พอร์ต (Port) ต่างๆ ใน Transport Layer ที่ระบบปฏิบัติการได้จัดสรรให้กับโปรแกรมประยุกต์ต่างๆ เพื่อใช้สื่อสาร มีลักษณะคล้ายกับข้อใด ก. ท่าเรือ หรือ ท่าเทียบเรือขนส่ง ข. บุรุษไปรษณีย์ ค. บริษัทขนส่ง ง. รถส่งของ

67. โปรโตคอลในข้อใด คือโปรโตคอลที่ส่งข้อมูลอย่างรวดเร็ว แต่ไม่รับประกันว่าข้อมูลจะถึงปลายทาง หรือไม่ หรือข้อมูลแม้จะถึงปลายทาง ก็ไม่รับประกันว่าจะมีการเรียงลำดับก่อน-หลัง ก. TCP ข. UDP

68. ผู้ให้บริการอินเทอร์เน็ตนิยมให้บริการแก่ลูกค้าโดยใช้ Protocol ชนิดใด ก. PPP ข. WiMAX ค. POP3 ง. Ethernet

69. Mac Address มีลักษณะคล้ายกับสิ่งใดในชีวิตประจำวันมากที่สุด ก. บัตรประจำตัวประชาชน ข. รหัสไวไฟ ค. รหัสนักเรียน ง. บ้านเลขที่

70. หมายเลข Port สำหรับโปรโตคอล TPC/IP ที่ OS กำหนดให้มีทั้งหมดกี่หมายเลข ก. 255

71. เครือข่ายระดับท้องถิ่น (LAN) มีบริการไร้สาย (Wireless Lan) ตามข้อใด ก. WiMAX ข. WiFi ค. Hotspot ง. Cellular

72. ข้อใดคือเครือข่ายระดับเดียวกันที่สามารถเป็นได้ทั้งผู้รับและผู้ส่งในเวลาเดียวกัน ก. LAN ข. P2P ค. Client-Sever ง. Extranet

73. Fiber Optic นิยมใช้ในเครือข่ายประเภทใด ก. LAN ข. WAN ค. MAN ง. ทุกเครือข่ายสามารถใช้ Fiber Optic ได้

74. สายคู่บิดเกลียว (Twisted Pair) ประเภท UTP ใช้ในเครือข่ายชนิดใด ก. LAN ข. MAN ค. WAN ง. ถูกทุกข้อ

75. โทโปโลยี (Topology) ในข้อใดนิยมใช้งานมากที่สุดในบ้านและสำนักงานในปัจจุบัน ก. Ring ข. Star ค. Bus ง. Ethernet

76. เมื่อใช้คำสั่ง ping จะทำให้เราทราบข้อมูลในข้อใด ก. เว็บไซต์นี้ชื่ออะไร ข. ติดต่อปลายทางได้หรือไม่ ค. ติดต่อไปยังจุดหมายต้องผ่านจุดเชื่อมต่อกี่จุด ง. อุปกรณ์ที่เชื่อมต่อรับและส่งข้อมูลไปยังเครือข่าย ใช้โปรโตคอลอะไรบ้าง และติดต่อกับใคร

77. Public IP Class ใด มีช่วงตัวเลขที่มากที่สุด ทำให้มีจำนวน IP มากที่สุด ก. A ข. B ค. C ง. D

78. สาย Coaxial นิยมใช้สำหรับทำงานในข้อใด ก. กล้องวงจรปิดและสัญญาณทีวี ข. เครือข่ายระดับเมือง (MAN) ค. การเดินสายระยะไกลจากผู้ให้บริการอินเทอร์เน็ต ง. การเดินสายลำโพง

79. สาย Twisted Pair ในข้อใดมีประสิทธิภาพในการส่งข้อมูลในระยะไม่เกิน 30 เมตร ดีที่สุด ก. CAT8 ข. CAT7 ค. CAT6 ง. CAT5
