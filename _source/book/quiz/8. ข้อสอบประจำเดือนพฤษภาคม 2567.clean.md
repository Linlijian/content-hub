**1.** OSI Model คืออะไร

- ก. รูปแบบจำลองการส่งสัญญาณระหว่างอุปกรณ์ผ่านระบบเครือข่าย
- ข. โครงสร้างของเครือข่าย
- ค. โครงสร้างของระบบการสื่อสารข้อมูล
- ง. องค์ประกอบของการสื่อสารข้อมูล

**2.** ชั้นแต่ละชั้น (Layer) ใน OSI Model ทำงานประสานกันลักษณะใด

- ก. ทำงานจากชั้นบนไปชั้นล่างสุดเท่านั้น
- ข. ทำงานจากชั้นล่างสุดไปชั้นบนสุดเท่านั้น
- ค. ทำงานร่วมกันในชั้นและชั้นที่อยู่ติดกัน
- ง. ทำงานแบบข้ามสลับไปมาแล้วแต่ความจำเป็น

**3.** โปรแกรม Web Browser ทำงานในชั้นใดของ OSI Model

- ข. Datalink Layer
- ค. Application Layer
- ง. Transport Layer
