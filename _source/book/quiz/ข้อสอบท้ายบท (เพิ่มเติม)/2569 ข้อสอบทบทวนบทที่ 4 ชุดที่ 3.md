**ข้อสอบทบทวนบทที่ 4 ซอฟต์แวร์ (ชุดที่ 3\)** 

1\. ขอใดอธิบายความหมายของ Virtual Computer ได้ถูกต้องที่สุด 

ก. คอมพิวเตอร์ที่ทำงานโดยไม่มีระบบปฏิบัติการติดตั้งอยู่  

ข. ซอฟต์แวร์ที่สร้างสภาพแวดล้อมเสมือนเพื่อให้สามารถทำงานได้เหมือนเครื่องคอมพิวเตอร์จริง  ค. อุปกรณ์ฮาร์ดแวร์ที่ใช้เพื่อเพิ่มความเร็วในการประมวลผลให้กับคอมพิวเตอร์ ง. ระบบเครือข่ายที่เชื่อมต่อเครื่องคอมพิวเตอร์หลายเครื่องเข้าด้วยกันเพื่อแบ่งปันข้อมูล 

2\. องค์ประกอบหลักที่ทำหน้าที่จัดการและแบ่งทรัพยากรฮาร์ดแวร์ของเครื่องแม่ข่าย (Host) ให้กับ เครื่องเสมือน (Guest) แต่ละเครื่องในระบบ Virtualization คืออะไร 

ก. Guest OS ข. Host OS ค. Hypervisor ง. Driver Manager 3\. Hypervisor ชนิดที่ 1 (Type 1\) หรือ Bare Metal มีลักษณะการทำงานอย่างไร ก. ติดตั้งอยู่บนระบบปฏิบัติการหลัก (Host OS) ก่อนที่จะสร้างเครื่องเสมือน  

ข. ใช้สำหรับจำลองระบบเครือข่ายเสมือน (VPN) 

ค. ทำงานผ่านเว็บเบราว์เซอร์และต้องเชื่อมต่ออินเทอร์เน็ตตลอดเวลา  

ง. ติดตั้งโดยตรงบนฮาร์ดแวร์ของเครื่องเซิร์ฟเวอร์โดยไม่ต้องอาศัยระบบปฏิบัติการ 4\. ข้อใดคือประโยชน์ของการใช้ Virtual Computer เพื่อทำการรวมเซิร์ฟเวอร์หลายเครื่องไว้ในเครื่อง เซิร์ฟเวอร์จริง (Physical Server) เพียงเครื่องเดียว 

ก. ช่วยให้สามารถนำฮาร์ดแวร์ที่เก่ามากกลับมาใช้งานใหม่ได้  

ข. ลดการใช้พลังงานไฟฟ้าและลดค่าใช้จ่ายในการบำรุงรักษาฮาร์ดแวร์ทางกายภาพ  ค. การติดตั้งโปรแกรมหรือแอปพลิเคชันบนเครื่องจำลองทำได้ง่ายและรวดเร็วกว่า ง. เพิ่มความเร็วของหน่วยประมวลผล (CPU) โดยรวมให้สูงกว่าศักยภาพของเครื่องจริง 

5\. Guest OS (ระบบปฏิบัติการของเครื่องเสมือน) มีความสัมพันธ์กับการทำงานในสภาพแวดล้อม เสมือนอย่างไร 

ก. Guest OS สามารถทำงานได้โดยไม่ต้องใช้ทรัพยากรฮาร์ดแวร์จริงใด ๆ เลย ข. Guest OS เป็นระบบปฏิบัติการที่จัดการการจัดสรรทรัพยากรฮาร์ดแวร์ได้โดยตรง ค. Guest OS ต้องเป็นระบบปฏิบัติการชนิดเดียวกับ Host OS เสมอ 

ง. Guest OS ทำงานอยู่ภายในสภาพแวดล้อมเสมือนที่ถูกสร้างและจัดการโดย Hypervisor   
6\. ในระบบ Virtualization นั้น การจัดสรรทรัพยากร เช่น CPU RAM และ Storage ให้กับ Virtual  Computer มีหลักการสำคัญอย่างไร 

ก. Hypervisor จะทำหน้าที่แบ่งปันและจัดสรรทรัพยากรจริงที่มีอยู่ให้กับเครื่องเสมือนแต่ละเครื่อง ตามการตั้งค่า  

ข. เครื่องเสมือนแต่ละเครื่องจะได้รับทรัพยากรทั้งหมดของเครื่องจริงที่เหลืออยู่ ค. ทรัพยากรสำหรับเครื่องเสมือนจะถูกสร้างขึ้นใหม่ทั้งหมดในหน่วยความจำเสมือน ง. Guest OS จะทำการจัดสรรทรัพยากรฮาร์ดแวร์โดยตรงด้วยตนเอง 

7\. Hypervisor ชนิดที่ 2 (Type 2\) มีชื่อเรียกอีกอย่างว่าอะไร และมีลักษณะการติดตั้งอย่างไร ก. Bare Metal ติดตั้งบนฮาร์ดแวร์โดยตรง  

ข. Embedded ติดตั้งในเฟิร์มแวร์ของเมนบอร์ด 

ค. Hosted ติดตั้งบนระบบปฏิบัติการหลัก (Host OS)  

ง. Cloud-based ทำงานบนแพลตฟอร์มคลาวด์ 

8\. สถานการณ์ใดที่การใช้ Virtual Computer จะให้ประโยชน์และมีความเหมาะสมมากที่สุด ก. การใช้งานโปรแกรมประมวลผลคำหรือตารางคำนวณพื้นฐาน  

ข. การเล่นเกมคอมพิวเตอร์ที่ต้องการประสิทธิภาพกราฟิกและฮาร์ดแวร์ระดับสูงสุด  ค. การทดสอบซอฟต์แวร์หรือแพตช์ระบบที่ต้องทำงานในหลายระบบปฏิบัติการที่แตกต่างกัน  ง. การสำรองข้อมูลไฟล์ส่วนตัวจำนวนมากในฮาร์ดดิสก์ภายนอก 

9\. ข้อใดไม่ใช่ Hypervisor  

ก. Linux ข. Microsoft Hyper V ค. KVM ง. VirtualBox  10\. Server Virtualization มีวัตถุประสงค์เพื่ออะไร 

ก. ลดการใช้พลังงานของอุปกรณ์ไคลเอ็นต์ปลายทาง  

ข. การสร้างเครือข่ายส่วนตัวเสมือน (VPN) สำหรับผู้ใช้ระยะไกล 

ค. การเข้ารหัสและรักษาความปลอดภัยของข้อมูลที่จัดเก็บทั้งหมด  

ง. การรวมเซิร์ฟเวอร์จริงหลายเครื่องให้เป็นเครื่องเดียวเพื่อประหยัดค่าใช้จ่ายและทรัพยากร 11\. ข้อใดอธิบายถึงแนวคิดของ Network Virtualization ได้ถูกต้องที่สุด 

ก. การใช้ฮาร์ดแวร์เครือข่ายที่มีประสิทธิภาพสูงในการประมวลผล  

ข. การสร้างเครือข่ายเสมือน (Logical Network) บนโครงสร้างพื้นฐานเดียวกันด้วยซอฟต์แวร์  ค. การจำลองระบบปฏิบัติการเครือข่าย (NOS) บนเครื่องเสมือน  

ง. การติดตั้งอุปกรณ์เครือข่ายใหม่เพื่อเพิ่มช่องสัญญาณ (Bandwidth)  
12\. Hypervisor ชนิดใดที่นิยมใช้ในการทำ Server Virtualization ในระดับศูนย์ข้อมูล (Data Center)  เนื่องจากติดตั้งบนฮาร์ดแวร์โดยไม่มีระบบปฏิบัติการหลักคั่นกลาง 

ก. Bare Metal Hypervisor (Type 1\)  

ข. Hosted Hypervisor (Type 2\) 

ค. Application Hypervisor  

ง. Virtual Appliance 

13\. ข้อใดคือเหตุผลสำคัญที่องค์กรเลือกใช้ Desktop Virtualization (VDI) แทนการใช้ PC ทั่วไป ก. เพื่อให้ผู้ใช้สามารถติดตั้งซอฟต์แวร์ของตนเองได้อย่างอิสระ  

ข. เพื่อลดความจำเป็นในการอัปเดตระบบปฏิบัติการและซอฟต์แวร์ในแต่ละเดือน 

ค. เพื่อให้ผู้ใช้สามารถทำงานแบบออฟไลน์ได้ตลอดเวลา  

ง. เพื่อให้ข้อมูลสำคัญขององค์กรถูกจัดเก็บแบบรวมศูนย์ไว้บนเซิร์ฟเวอร์เท่านั้น ทำให้การควบคุมและ การสำรองข้อมูลทำได้ง่ายขึ้น
