**ข้อสอบทบทวนบทที่ 5 ฮาร์ดแวร์(ชุดที่ 2\)** 

1\. ข้อใดคือลักษณะที่สำคัญของ Microcontroller  

ก. ประสิทธิภาพสูงมาก เหมาะกับการประมวลผลงานระดับสูง 

ข. มีส่วนประกอบได้แก่ CPU, RAM, ROM และ I/O Peripherals 

ค. เป็นส่วนประกอบของอุปกรณ์ขนาดเล็กๆ  

ง. นิยมใช้เป็นหน่วยประมวลผลใน Minicomputer  

2\. ข้อใดคือ I/O Peripherals ของไมโครคอมพิวเตอร์ (Microcomputer) 

ก. USB Port  

ข. CPU 

ค. Memory Slot  

ง. AC/DC Adapter  

3\. เพราะเหตุใด Microcontroller จึงง่ายต่อการนำไปประยุกต์ใช้งานได้หลากหลายด้าน  ก. ทำงานโดยไร้พลังงาน 

ข. มีองค์ประกอบพื้นฐานครบถ้วน 

ค. มีประสิทธิภาพด้านความเร็วสูงสุด  

ง. ต่อพ่วงได้กับทุกอุปกรณ์ 

4\. ใน PC เมื่อมีงานที่ต้องการการประมวลผลสูงสุด ควรเลือกใช้อุปกรณ์ในข้อใดเป็นหน่วยประมวลผล  ก. CPU 

ข. GPU 

ค. Microcontroller  

ง. NPU 

5\. ขั้นตอนแรกของการจัดซื้ออุปกรณ์คอมพิวเตอร์หรือจัดสเปกคอมพิวเตอร์คือข้อใด  ก. ระบุวัตถุประสงค์การใช้งาน 

ข. เลือกสเปก CPU  

ค. เลือกสเปก Motherboard  

ง. เลือกแบรนด์ของอุปกรณ์ต่อพ่วงต่างๆ   
6\. คุณสมบัติ(Specification) ของคอมพิวเตอร์ในข้อใดต้องมีพลังในการประมวลผลสูงสุด  ก. ดูหนังฟังเพลง  

ข. เล่นเกม  

ค. ทำงานด้านเอกสาร  

ง. ตัดต่อวีดีโอสั้น 

7\. อุปกรณ์ในข้อใดเมื่อมีการจัดสเปกคอมพิวเตอร์ ต้องถูกวางเป็นตัวเลือกลำดับแรกในการเลือกซื้อ  ก. RAM และ CPU  

ข. GPU และ Case  

ค. CPU และ Mainboard  

ง. Storage และ RAM  

8\. Motherboard ในปัจจุบันควรรองรับ RAM ขนาดเท่าใดเป็นอย่างต่ำจึงจะสามารถใช้งานได้อย่างมี ประสิทธิภาพ  

ก. 8 GB DDR 2 

ข. 8 GB DDR 3 

ค. 8 GB DDR 4 

ง. 8 GB DDR 5 

9\. Storage ในข้อใดมีประสิทธิภาพในการรับส่งข้อมูลสูงสุด  

ก. SSD AIC  

ข. SSD M.2 NVMe 

ค. HDD 10,000 RPM 3.5 Inch  

ง. SSD SATA III  

10\. ระบบจัดเก็บข้อมูล (ระบบไฟล์) ในข้อใดมีความเข้ากันได้กับทุกๆ ระบบปฏิบัติการ  ก. NTFS  

ข. FAT32 

ค. APFS  

ง. EXT4  
11\. หูฟังประเภท TWS คือหูฟังที่มีคุณสมบัติในข้อใด  

ก. หูฟังอัจฉริยะ 

ข. หูฟังระบบตัดเสียงรบกวน  

ค. หูฟังแยกอิสระซ้ายขวา  

ง. หูฟังไร้สายแบบครอบศีรษะ  

12\. หูฟังประเภท ANC คือหูฟังที่มีคุณสมบัติในข้อใด  

ก. หูฟังอัจฉริยะ 

ข. หูฟังระบบตัดเสียงรบกวน  

ค. หูฟังแยกอิสระซ้ายขวา  

ง. หูฟังไร้สายแบบครอบศีรษะ  

13\. ความเร็วของหน่วยความจำ RAM ตัวหนึ่ง มีความเร็วในการรับส่งข้อมูลที่ 4800 MT/s แสดงว่า RAM  นี้มีความถี่สัญญาณนาฬิกาเท่าใด  

ก. 2400 MHz 

ข. 1.2 GHz 

ค. 24 GHz  

ง. 9.6 GHz 

ใช้ตารางแสดงคุณสมบัติของ Storage นี้ตอบคำถามข้อ 14 

| ตัวที่  | คุณสมบัติ  | ความจุ |
| :---- | :---- | :---- |
| 1  | SSD SATA  | 2 TB |
| 2  | SSD M.2 NVMe  | 512 GB  |
| 3  | SSD AIC NVMe  | 256 GB |

14\. ถ้ามี Storage 2 ประเภทในคอมพิวเตอร์เครื่องเดียว ควรติดตั้งระบบปฏิบัติการไว้ที่ Storage ตัวใด  ก. 1 หรือ 3 

ข. 2 หรือ 3 

ค. 1 หรือ 2 

ง. 1 เท่านั้น   
15\. มีCore ขนาดย่อมจำนวนมากช่วยกันประมวลผลแบบขนาน (Parallel Processing) คือคำจำกัด ความหรือคุณสมบัติของหน่วยประมวลผลในข้อใด  

ก. CU 

ข. GPU 

ค. CPU  

ง. ECU  

16\. ถ้าเทียบอุปกรณ์ประมวลผลกับตำแหน่งงานในบริษัทเอกชน ผู้จัดการฝ่ายต่างๆ เช่น ผู้จัดการฝ่าย บุคคล (HR Manager) ผู้จัดการฝ่ายขาย (Sales Manager) ผู้จัดการฝ่ายการตลาด (Marketing  Manager) และผู้จัดการทั่วไป (General Manager) เปรียบเสมือนอุปกรณ์ในข้อใด  ก. CPU Core  

ข. GPU Core  

ค. RAM 

ง. Storage  

17\. เพราะเหตุใดการใช้ GPU มีความเหมาะสมกว่าการใช้ CPU เมื่อมีการประมวลผล AI (Artificial  Intelligent) 

ก. GPU มี Core ประมวลผลมากกว่า  

ข. GPU มีประสิทธิภาพต่อ Core สูงกว่า  

ค. GPU ทำงานได้หลากหลายกว่า  

ง. GPU ทำงานประมวลผลที่ซับซ้อนได้ดีกว่า  

18\. จอภาพในข้อใดมีประสิทธิภาพด้านความสว่าง (Brightness) สูงที่สุด  

ก. CRT  

ข. LCD 

ค. OLED  

ง. QLED  

19\. ความละเอียด 4 K ได้แก่ข้อใด  

ก. 1280 x 720  

ข. 1920 x 1080  

ค. 2560 x 1440  

ง. 3840 x 2160   
20\. พอร์ตในข้อใดขึ้นชื่อว่าเก่าแก่และประสิทธิภาพต่ำสุดเมื่อเชื่อมต่อกับจอภาพ  ก. Thunderbolt  

ข. Display Port  

ค. HDMI Port  

ง. DVI Port
