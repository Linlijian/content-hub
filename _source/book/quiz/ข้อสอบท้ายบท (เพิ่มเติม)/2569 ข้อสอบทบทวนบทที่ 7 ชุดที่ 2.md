**ข้อสอบทบทวนบทที่ 7 OSI Model Protocol และ Port ชุดที่ 2** 

1\. การกำหนดว่าจะใช้วิธีรับส่งข้อมูลแบบใด เช่น ส่งทางเดียว ส่งสองทิศทางสลับกัน หรือส่งแบบ สองทิศทางพร้อมกัน จะมีการกำหนดใน Layer ใดของ OSI Model  

ก. 4 ข. 5 ค. 6 ง. 7 

2\. หากผู้ใช้เปิดแอปพลิเคชัน Line บนคอมพิวเตอร์ทิ้งไว้หลายหน้าต่างเพื่อแชทกับเพื่อนหลายคนพร้อม กัน การที่ข้อมูลถูกส่งไปแสดงผลได้ถูกต้องในแต่ละหน้าต่างแชท เป็นหน้าที่หลักของ Layer ใด ก. Data Link Layer ข. Transport Layer ค. Session Layer ง. Application Layer 

3\. กลไกที่เรียกว่า Synchronization ใน Session Layer มีประโยชน์อย่างไรในขณะที่การส่งไฟล์เกิด ข้อผิดพลาดระหว่างทาง 

ก. ช่วยบีบอัดไฟล์ให้มีขนาดเล็กลงเพื่อส่งใหม่ได้เร็วขึ้น 

ข. ช่วยให้สามารถกลับไปเริ่มส่งใหม่จากจุด Checkpoint ล่าสุดได้โดยไม่ต้องเริ่มส่งตั้งแต่ต้น ค. ช่วยเข้ารหัสไฟล์เพื่อความปลอดภัยก่อนส่งใหม่ 

ง. ช่วยเปลี่ยนเส้นทางการส่งข้อมูลไปยังช่องทางที่เร็วกว่า 

4\. ในการสื่อสารข้อมูล กระบวนการ Session Management ที่ทำใน Session Layerได้แก่ การสร้าง การควบคุม และการจบการเชื่อมต่อ เปรียบได้กับเหตุการณ์ในชีวิตประจำวันของคุณครูแสนพัน ตาม ข้อใด 

ก. ครูแสนพันเขียนเนื้อความจดหมายลงในกระดาษ 

ข. ครูแสนพันจัดลำดับคิวว่าจะโทรไปหาสาวคนใดก่อนดี 

ค. ครูแสนพันขออนุญาตโทรหาสาว ยกหูโทรศัพท์ ทักทาย สนทนา และวางสายเมื่อจบการคุย ง. ครูแสนพันเขียนชื่อที่อยู่และเบอร์โทรศัพท์บนกล่องพัสดุเพื่อส่งให้สาวๆ  

5\. เมื่อแอปพลิเคชันต้องการขอเปิดเซสชัน (Session Establishment) เพื่อเริ่มรับส่งข้อมูลกับเครื่อง ปลายทาง ข้อใดคือสิ่งที่ Session Layer จะดำเนินการ 

ก. ตรวจสอบความถูกต้องของเลข IP Address 

ข. การแปลงข้อมูลเป็นสัญญาณไฟฟ้าเพื่อส่งผ่านสายแลน 

ค. การแบ่งข้อมูลออกเป็น Segment เล็กๆ 

ง. การตกลงยอมรับและสร้างช่องทางการสนทนาระหว่าง 2 แอปพลิเคชัน 

6\. เมื่อมีข้อมูลสูญหาย การกู้คืนข้อมูลใน Session Layer จะกระทำลักษณะใด  ก. กู้คืนทั้งหมด ข. กู้คืนเฉพาะบิตที่หาย 

ค. กู้คืนเฉพาะช่วงที่หาย ง. ไม่กู้คืนเพราะอาจทำให้สื่อสารล่าช้าได้  
7\. โปรโตคอลใดไม่ต้องมีการกู้คืนข้อมูล หากข้อมูลสูญหาย 

ก. TCP ข. UDP ค. HTTPS ง. SFTP 8\. ข้อมูลใดเป็นข้อมูลที่บรรจุอยู่ใน Header ของ Segment  

ก. IP Address ข. Destination port ค. Mac Address ง. Physical Address 9\. หลังข้อมูลเดินทางออกจากเครื่องที่ส่ง และก่อนจะไปถึงเครื่องปลายทางที่รับข้อมูล ข้อมูลจะอยู่ใน ระหว่างทาง ข้อใดคือข้อมูลที่จะไม่ถูกแกะออกเพื่อตรวจสอบข้อมูลระหว่างทางในการเชื่อมต่อปกติ ก. Segment ข. Packet ค. Frame ง. IP Address 10\. IP Address เมื่อเปรียบเทียบกับสิ่งที่พบเจอในชีวิตประจำวัน จะเปรียบเสมือนข้อใดมากที่สุด  ก. เลขที่ประจำตัวประชาชนคนไทย ข. ชื่อและที่อยู่สำหรับจัดส่งพัสดุ ค. ห้องที่มีหลายห้องในโรงแรมแห่งหนึ่ง ง. รปภ.รักษาความปลอดภัยที่สำนักงานบริษัท 11\. ชั้นใดที่ไม่ได้ใช้ IP Address เลย 

ก. Transport Layer ข. Data Link Layer ค. Network Layer ง. Application Layer  12\. การส่งข้อมูลระหว่างอุปกรณ์โดยอ้างอิงตำแหน่งที่อยู่ภายในเครือข่ายท้องถิ่น (Local Network)  เดียวกัน เป็นหน้าที่ของ Layer ใด 

ก. Data Link Layer ข. Transport Layer ค. Network Layer ง. Application Layer  13\. Layer ใดที่มีหน้าที่จัดการการส่งข้อมูลผ่านสื่อกลางโดยใช้ MAC Address เป็นตัวระบุผู้รับและผู้ส่ง ก. Data Link Layer ข. Transport Layer ค. Network Layer ง. Application Layer  14\. อุปกรณ์เครือข่ายประเภท Switch (L2 Switch) ทำงานอยู่ในชั้นสื่อสารใดของ OSI Model ก. Data Link Layer ข. Transport Layer ค. Network Layer ง. Application Layer  15\. เมื่อเทียบชั้น TCP Model กับ OSI Model ชั้นที่ 4 (Application Layer) ใน TCP Model  เปรียบเทียบได้กับชั้นใดของ OSI Model  

ก. 4 ข. 5-7 ค. 4-7 ง. 7 16\. เมื่อเทียบชั้น TCP Model กับ OSI Model ชั้นที่ 3 (Transport Layer) ใน TCP Model  เปรียบเทียบได้กับชั้นใดของ OSI Model  

ก. 3 ข. 4 ค. 5 ง. 6 17\. ข้อใดคือ Protocol สำหรับเรียกดู Email ที่นิยมในปัจจุบัน 

ก. IMAP ข. POP3 ค. SMTP ง. HTTPS 18\. Wi-Fi เป็น Protocol ในชั้นใดของ TCP Model
