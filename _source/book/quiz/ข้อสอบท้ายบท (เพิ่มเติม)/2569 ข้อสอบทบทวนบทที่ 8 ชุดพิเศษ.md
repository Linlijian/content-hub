**ข้อสอบทบทวนบทที่ 8 Data Communication ชุดที่ 4** 

1\. Firewall คืออะไร 

ก. ซอฟต์แวร์หรือฮาร์ดแวร์บนระบบเครือข่ายที่ตรวจสอบข้อมูลที่ผ่านเข้า-ออกระบบ ข. โปรแกรมป้องกันไวรัส ทำหน้าที่ตรวจจับไวรัสภายในเครื่องคอมพิวเตอร์ ค. อุปกรณ์จัดเก็บข้อมูลสำรอง 

ง. ระบบปฏิบัติการสำหรับเซิร์ฟเวอร์ 

2\. คำว่า Firewall เมื่อแปลเป็นไทยตรงตัวหมายถึงข้อใด 

ก. กำแพงที่หนาทึบ 

ข. กำแพงกั้นไฟ 

ค. กำแพงเมืองและประตูรักษาความปลอดภัย 

ง. ตัวกรองอันตรายจากเชื้อโรค 

3\. Firewall ทำหน้าที่คัดกรองข้อมูลโดยไม่พิจารณาจากสิ่งใด 

ก. ขนาดของไฟล์ 

ข. ชื่อของผู้ส่งข้อมูล 

ค. ที่มาที่ไปของข้อมูล 

ง. ความเร็วของอินเทอร์เน็ต 

4\. หาก Firewall ตรวจพบว่าข้อมูลไม่ผ่านกฎที่กำหนดไว้แม้เพียงข้อเดียว จะเกิดอะไรขึ้น ก. อนุญาตให้ผ่านแต่แจ้งเตือน 

ข. ปิดระบบเครือข่ายทั้งหมด 

ค. ส่งข้อมูลกลับไปแก้ไข 

ง. ไม่ให้ข้อมูลนั้นผ่านเข้าไป 

5\. หาก Firewall ตรวจพบว่าข้อมูลไม่ปลอดภัย แต่ผู้ใช้งานอนุญาตให้ผ่าน Firewall จะทำอย่างไร ก. ปล่อยให้ผ่านตามการตัดสินใจของผู้ใช้ทันที 

ข. ปฏิเสธทุกกรณี 

ค. ลบข้อมูลทิ้งทันทีและแจ้งเตือนผู้ใช้ในเครือข่ายทุกคน 

ง. ส่งข้อมูลไปยังหน่วยงานที่เกี่ยวข้อง 

6\. เหตุผลหลักที่ต้องใช้ Firewall ในองค์กรคือข้อใด 

ก. เพิ่มความเร็วอินเทอร์เน็ต 

ข. เพิ่มความปลอดภัยให้เครือข่าย LAN 

ค. ลดความเสี่ยงจากอันตรายบนอินเทอร์เน็ต 

ง. ประหยัดค่าใช้จ่ายค่าอุปกรณ์ Network   
7\. การกรองแพ็กเก็ต (Packet Filtering) ของ Firewall โดยทั่วไปทำหน้าที่อย่างไร ก. เข้ารหัสข้อมูลทั้งหมดเพื่อความปลอดภัย 

ข. ตรวจสอบและควบคุมการรับส่งข้อมูลตามกฎที่กำหนดไว้ 

ค. บีบอัดข้อมูลก่อนส่งไปยังปลายทาง 

ง. คลายการบีบอัดข้อมูลและตรวจสอบข้อมูลจนถึง Layer 7  

8\. Content Filtering ของ Firewall ทำหน้าที่อะไร 

ก. กรองเนื้อหาสำหรับผู้ใหญ่ (18+) หน้าเว็บไซต์ต่างๆ  

ข. ตรวจสอบและกรองข้อมูลที่เข้ามา เช่น บล็อกเว็บไซต์ที่ไม่เหมาะสมหรือมัลแวร์ ค. จัดเรียงข้อมูลตามลำดับเวลา 

ง. ตรวจสอบเนื้อหาในไฟล์ PDF  

9\. การตรวจจับและป้องกันการบุกรุก (Intrusion Detection and Prevention) ของ Firewall  มีหน้าที่ตามข้อใด 

ก. ตรวจจับกิจกรรมที่น่าสงสัยหรือการโจมตีและป้องกันความเสียหาย 

ข. สร้างรหัสผ่านใหม่อัตโนมัติหากเกิดการโจมตี 

ค. บันทึกวิดีโอการใช้งานขณะที่ถูกโจมตี 

ง. อัปเดตซอฟต์แวร์อัตโนมัติทั้งก่อนและหลังการถูกโจมตี 

10\. หน้าที่ของ Firewall ข้อใดเกี่ยวข้องกับการเปลี่ยนที่อยู่ IP ภายในให้เป็น IP สาธารณะ ก. Packet Filtering 

ข. Stateful Inspection 

ค. Network Address Translation 

ง. Content Filtering 

11\. ข้อใดไม่ใช่หน้าที่ของ Firewall 

ก. การกรองแพ็กเก็ต 

ข. การตรวจสอบสถานะการเชื่อมต่อ 

ค. การออกแบบหน้าเว็บไซต์ให้ปลอดภัย 

ง. การกรองเนื้อหา 

12\. Hardware Firewall มีลักษณะอย่างไร 

ก. เป็นโปรแกรมติดตั้งบนคอมพิวเตอร์ส่วนบุคคลที่มีประสิทธิภาพสูง 

ข. เป็นแอปพลิเคชันบนสมาร์ทโฟนที่ป้องกันการบุกรุก 

ค. เป็นบริการบนคลาวด์ที่สามารถทำงานได้อย่างรวดเร็ว แต่ต้องมีการเชื่อมอินเทอร์เน็ตตลอดเวลา ง. เป็นอุปกรณ์ฮาร์ดแวร์ที่มีหน้าที่เฉพาะ มีประสิทธิภาพสูงและจัดการข้อมูลได้จำนวนมาก  
13\. Software Firewall เหมาะกับการใช้งานในลักษณะใด 

ก. เครือข่ายขนาดเล็กหรือบุคคลทั่วไป 

ข. เครือข่ายขนาดใหญ่ระดับประเทศ 

ค. ศูนย์ข้อมูลขนาดใหญ่เท่านั้น 

ง. ระบบดาวเทียม 

14\. Cloud Firewall มีลักษณะเด่นอย่างไร 

ก. ต้องติดตั้งเป็นอุปกรณ์แยกต่างหาก 

ข. ใช้ได้เฉพาะกับระบบ Windows และ Linux ยกเว้น iOS และตระกูล Macintosh ค. จัดการการรับส่งข้อมูลและรักษาความปลอดภัยผ่านอินเทอร์เน็ต 

ง. ไม่สามารถอัปเดตได้หรืออัปเดตได้ยาก เพราะต้องขออนุญาตจากผู้ให้บริการ 15\. Next-Generation Firewall (NGFW) มีความสามารถพิเศษกว่า Firewall ทั่วไปอย่างไร ก. มีขนาดเล็กกว่า ราคาถูก ประหยัดทรัพยากรมากกว่า 

ข. มีฟังก์ชันตรวจสอบและป้องกันภัยคุกคามขั้นสูงกว่า 

ค. ราคาถูกกว่าแต่ความสามารถมากกว่า 

ง. ใช้ได้เฉพาะกับเครือข่ายไร้สาย (Wireless) 

16\. Firewall ประเภทใดเหมาะสำหรับองค์กรที่ต้องการประสิทธิภาพสูงในการจัดการข้อมูลจำนวนมาก ก. Hardware Firewall 

ข. Software Firewall 

ค. Cloud Firewall 

ง. Personal Firewall 

17\. Network Diagram คืออะไร 

ก. รายการราคาอุปกรณ์เครือข่าย 

ข. คู่มือการติดตั้งซอฟต์แวร์บนระบบเน็ตเวิร์ค 

ค. ซอฟต์แวร์สำหรับวาดภาพและจำลองระบบเครือข่าย 

ง. การนำเสนอภาพของระบบเครือข่ายและวิธีที่เชื่อมต่อกัน 

18\. ใน Network Diagram โซน DMZ (Demilitarized Zone) คือพื้นที่แบบใด ก. พื้นที่เก็บข้อมูลส่วนบุคคล 

ข. พื้นที่ห้อง Server สำหรับเก็บอุปกรณ์ที่มีการรักษาความปลอดภัยข้อมูลเป็นพิเศษ ค. พื้นที่ปลอดภัยกึ่งกลางระหว่างระบบภายในกับระบบอินเทอร์เน็ต 

ง. ห้องเซิร์ฟเวอร์หลักของหน่วยงาน  
19\. ภายในโซน DMZ ควรประกอบด้วยเซิร์ฟเวอร์ใดบ้าง 

ก. File Server, Print Server, DNS Server 

ข. Web Server, Mail Server, VPN Server 

ค. Database Server, Application Server, Proxy Server 

ง. Game Server, Streaming Server, Chat Server 

20\. VPN Client ในระบบเครือข่ายองค์กรมีหน้าที่อะไร 

ก. ใช้สำหรับการ Work from home  

ข. ใช้สำหรับสำรองข้อมูล 

ค. ใช้สำหรับดาวน์โหลดไฟล์อย่างปลอดภัยไร้มัลแวร์ 

ง. ใช้เพื่อให้ผู้ใช้งานภายนอกเชื่อมต่อเข้าสู่ระบบองค์กรอย่างปลอดภัย 

21\. IDS (Intrusion Detection System) ในระบบเครือข่ายทำหน้าที่ตามข้อใด ก. ตรวจจับพฤติกรรมที่เป็นภัยคุกคามจากทราฟฟิกแบบ Passive  

ข. เพิ่มความเร็วอินเทอร์เน็ต 

ค. ตรวจจับพฤติกรรมและทำลายภัยคุกคามนั้นทันทีแบบ Active  

ง. แปลง IP Address จาก Private เป็น Public 

22\. Core Switch ในระบบเครือข่ายองค์กรทำหน้าที่อะไร 

ก. เชื่อมต่ออินเทอร์เน็ตกับ ISP 

ข. ตรวจจับความไม่ปลอดภัยและสแกนหาภัยคุกคาม 

ค. กระจายข้อมูลไปยังอาคารต่างๆ และอุปกรณ์ในระบบ 

ง. สำรองข้อมูลอัตโนมัติ 

23\. ลำดับเส้นทางข้อมูลจากอุปกรณ์ในอาคารออกสู่อินเทอร์เน็ตข้อใดถูกต้อง ก. Firewall → Router → Core Switch → Switch → Internet 

ข. Access Point → Switch → Core Switch → Router → Firewall → Internet ค. Internet → Switch → Router → Firewall → Access Point ง. Core Switch → Access Point → Router → Firewall → Internet   
24\. อุปกรณ์ภายในแต่ละอาคารย่อยขององค์กรควรประกอบด้วยอุปกรณ์ใดบ้าง ก. Router และ Computer 

ข. Server, Smartphone, Switch, Router, IPS 

ค. Router, Firewall และ Access Point 

ง. Switch, Access Point, Computer, Notebook, Tablet และ Phone  
25\. Router ในระบบเครือข่ายองค์กรอยู่ระหว่างอุปกรณ์ใด 

ก. ระหว่าง Computer กับ Notebook 

ข. ระหว่าง Firewall กับ Core Switch 

ค. ระหว่าง Access Point กับ Tablet 

ง. ระหว่าง ISP กับ VPN Client 

26\. ข้อใดกล่าวถูกต้องเกี่ยวกับระบบเครือข่ายที่ปลอดภัย 

ก. ใช้เฉพาะ Firewall อย่างเดียวก็เพียงพอต่อการป้องกันภัยคุกคาม 

ข. มี Firewall \+ IDS เพื่อความปลอดภัย และ DMZ สำหรับแยกบริการ 

ค. ไม่จำเป็นต้องมี DMZ เพื่อประหยัดงบประมาณ และควรใช้ Software Firewall จะดีที่สุด ง. ใช้ Hub แทน Switch ได้เพราะเป็นเทคโนโลยีที่เทียบกันได้ พร้อมทั้งจะช่วยประหยัดงบประมาณ 27\. การเชื่อมต่อ VPN จากภายนอกจะถูกส่งผ่านช่องทางใดไปยังระบบองค์กร 

ก. ผ่านสายใยแก้วนำแสงตรงๆ และส่งไปยังปลายทาง 

ข. ผ่าน Bluetooth 

ค. ผ่านเครือข่าย Internet 

ง. ผ่านสายโทรศัพท์ 

28\. ข้อใดไม่ใช่ประเภทของ Firewall 

ก. Hardware Firewall 

ข. Software Firewall 

ค. Cloud Firewall 

ง. Bluetooth Firewall 

29\. การที่องค์กรกำหนดไม่อนุญาตให้ข้อมูลจากเว็บไซต์ที่ไม่ปลอดภัยเข้ามาในระบบ  จัดเป็นการทำงานของ Firewall ในด้านใด 

ก. Packet Filtering 

ข. NAT 

ค. Data Backup 

ง. Data Encryption and Decryption 

30\. Access Point ในระบบเครือข่ายองค์กรทำหน้าที่ตามข้อใด 

ก. กรองข้อมูลเข้า-ออก 

ข. เก็บข้อมูลในฐานข้อมูล 

ค. กระจายสัญญาณ Wi-Fi 

ง. แปลงสัญญาณดิจิทัลเป็นแอนะล็อก  
31\. ข้อใดกล่าวถูกต้องเกี่ยวกับ Firewall 

ก. Firewall สามารถป้องกันอันตรายได้ 100% โดยไม่ต้องอาศัยซอฟต์แวร์อื่นๆ ข. Firewall ทำงานโดยเปรียบเทียบข้อมูลกับกฎที่ผู้ใช้กำหนดไว้ ค. Firewall แบบซอฟต์แวร์เท่านั้นที่มีประสิทธิภาพสูงสุด ณ ปัจจุบัน ง. Firewall ไม่สามารถบล็อกเว็บไซต์ได้หากสมาชิกผู้ใช้งานเครือข่ายไม่ยินยอม
