**ข้อสอบทบทวนบทที่ 2 การเขียนโปรแกรมฯ (ชุดที่ 5\)** 

อ่านโค้ดต่อไปนี้แล้วตอบคำถามข้อ 1 – 4  

int data\[\] \= {10, 20, 30, 40, 50}; 

int i \= 0; 

int sum \= 0; 

for (i \= 0; i \< 3; i++) { 

 sum \+= data\[i\]; 

} 

1\. จากโค้ดโปรแกรมดังกล่าว ผลลัพธ์ของ sum หลังจากจบ Loop นี้คือเท่าใด ก. 60 ข. 50 ค. 150 ง. 90 

2\. โปรแกรมนี้เขียนด้วยภาษาใด 

ก. Python ข. C ค. Java ง. PHP 

3\. หากต้องการพิมพ์ค่าในอาเรย์แบบย้อนกลับ (50, 40, 30, 20, 10\) ต้องเติมเงื่อนไขอย่างไรใน for ก. for (i \= 0; i \>= 0; i--) { printf("%d ", data\[i\]); } 

ข. for (i \= 4; i \>= 0; i--) { printf("%d ", data\[i\]); } 

ค. for (i \= 5; i \>= 0; i--) { printf("%d ", data\[i\]); } 

ง. for (i \= 1; i \>= 0; i--) { printf("%d ", data\[i\]); } 

4\. โปรแกรมนี้จะเกิดข้อผิดพลาดใดหากเปลี่ยนคำสั่งวนซ้ำเป็น for (i \= 0; i \<= 5; i++) ก. ไม่มีข้อผิดพลาด โปรแกรมทำงานปกติ 

ข. Error ที่ Syntax ผิดที่ i++ 

ค. Overflow เนื่องจาก index ที่ 5 ไม่มี 

ง. Error เพราะลืมประกาศตัวแปร i  
อ่านโค้ดต่อไปนี้แล้วตอบคำถามข้อ 5

 if (data\[i\] % 20 \== 0\) {

ก. 150 ข. 120 ค. 100 ง. 60 อ่านโค้ดต่อไปนี้แล้วตอบคำถามข้อ 6 – 8

int sum \= 0;

 }

ก. แสดง 10 20 30 ข. แสดง 10 20  

ค. แสดง 30 ง. แสดง 10 20 30 40 50 7\. จะเกิดอะไรขึ้นหากลืมคำสั่ง i++ ภายในลูป while 

ก. โปรแกรมหยุดทำงานทันที ข. โปรแกรมจะพิมพ์ค่า data\[0\] ซ้ำไม่รู้จบ ค. โปรแกรมพิมพ์ค่าอาเรย์ทุกตัวแล้วหยุด ง. Syntax Error คอมไพล์ไม่ผ่าน 8\. ค่าของ sum หลังจากจบ Loop นี้คือเท่าใด
