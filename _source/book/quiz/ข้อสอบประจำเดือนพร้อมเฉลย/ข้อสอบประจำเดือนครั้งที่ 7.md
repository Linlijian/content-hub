19\. ข้อใดอธิบายความแตกต่างระหว่าง Primary Key และ Foreign Key ได้ถูกต้องที่สุด ก. Primary Key ใช้สำหรับเชื่อมตาราง ส่วน Foreign Key ใช้สำหรับจัดเรียงข้อมูล ข. Primary Key มีค่าซ้ำได้ในบางกรณี ขณะที่ Foreign Key ห้ามซ้ำเด็ดขาด

ง. Primary Key และ Foreign Key เป็นคอลัมน์ชนิดเดียวกัน และใช้งานได้สลับกัน 20\. ในกรณีที่มีการลบข้อมูลจากตารางหลัก (Primary Table) ที่มี Foreign Key อ้างถึงไปยังตารางอื่นที่ มีสถานะเป็นตารางลูก โดยไม่ได้กำหนดการจัดการกับ Foreign Key ไว้ ระบบฐานข้อมูลดำเนินการ อย่างไร
